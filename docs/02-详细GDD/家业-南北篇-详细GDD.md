## A2. 九品中正制数值化

### A2.1 品级表

| 品级 | 含义 | 出仕起点 | 官职上限 | 玩家家族定位 |
|------|------|---------|---------|------------|
| **一品** | 顶级门阀 | 直接入朝 | 三公九卿 | 王、谢、庾、桓、司马 |
| **二品** | 高级门阀 | 起步朝官 | 列卿 | 次级门阀 |
| **三品** | 中级门阀 | 起步郎官 | 尚书 | 中等家族 |
| **四品** | 普通士族上 | 起步属吏 | 刺史 | 普通士族 |
| **五品** | 普通士族中 | 起步县令 | 郡守 | 普通士族 |
| **六品** | 普通士族下 | 起步小吏 | 县令 | 普通士族 |
| **七品** | 寒门上 | 难出仕 | 县丞 | 寒门武将路线 |
| **八品** | 寒门中 | 战功可出仕 | 县尉 | 寒门武将路线 |
| **九品** | 寒门下 | 战功可出仕 | 军中小官 | 寒门武将路线 |

### A2.2 品级变动机制

**升品条件**（需全部满足）：
1. 家族有人在朝为高官（与品级匹配）
2. 家族文化成就获得官方认可
3. 跨代际积累声望（至少3代持续贡献）
4. 关键历史事件中的正确站位

**降品风险**：
- 重大过失（如谋反、被俘、投降）
- 全族被流放
- 战败导致皇帝震怒
- 卷入禅代失败方

### A2.3 联姻匹配规则

| 玩家家族品级 | 可联姻品级 | 联姻代价 |
|------------|-----------|---------|
| **一品** | 一品、二品（极难下嫁） | 无 |
| **二品** | 一品（高攀）、二品、三品 | 高攀需付出政治代价 |
| **三品** | 一品（极高攀）、二品（高攀）、三品、四品 | 需付出显著代价 |
| **四品至六品** | 同品级、三品（高攀）、七品（武将联姻） | 视情况 |
| **七品至九品** | 同品级、四品（高攀） | 需家族武将资源 |

### A2.4 文化声望与品级互动

**文化成就可加速升品**：
- 一首传世诗作：+5%升品进度
- 一幅名画：+8%升品进度
- 一场著名清谈：+10%升品进度
- 一位顶级书法家：+15%升品进度
- 一部经学著作：+20%升品进度

# Part B：核心家族剧本框架

## B1. 琅琊王氏剧本（317-339年，王导在世期间）

### B1.1 家族背景

**家族定位**：东晋第一门阀，文官系统主导者

**核心人物**：
- 王导（276-339）：东晋开国丞相，"王与马，共天下"的主角
- 王敦（266-311）：王导之兄，军事强人，曾发动叛乱
- 王羲之（303-361）：王导侄孙，书法圣人
- 王献之（344-386）：王羲之之子，书法传承者

**家族特色**：文官路线 + 书法世家 + 守成名门

### B1.2 二十二年剧本节点（317-339）

| 年份 | 事件 | 玩家选择 | 家族影响 |
|------|------|---------|---------|
| **317** | 衣冠南渡 | 跟随司马睿南渡 vs 留守北方 | 决定王氏家族存亡 |
| **318** | 王导辅政 | 支持王导主导 vs 扶持其他重臣 | 政治资本走向 |
| **319** | 侨置州郡 | 设置侨郡安置北方士族 | 文化底蕴保护 |
| **322** | 王敦之乱（第一次） | 中立 vs 支持王敦 vs 抵抗 | 家族分裂风险 |
| **324** | 王敦之乱平定 | 战后清算 vs 既往不咎 | 政治格局重塑 |
| **327** | 苏峻之乱前 | 预防策略 | 宗族防御准备 |
| **328** | 苏峻之乱 | 抵抗 vs 妥协 vs 流亡 | 家族声望危机 |
| **329** | 苏峻之乱平定 | 战后重建 | 文化复兴契机 |
| **330** | 书法世家萌芽 | 重点培养王羲之（幼年） | 长线文化投资 |
| **334** | 王导晚年 | 继承人选择 | 王氏内部分房 |
| **339** | 王导去世 | 家族走向 | 进入"后王导时代" |

### B1.3 王氏家族传承机制

**主线**：王导的辅政生涯 + 王羲之的书法成长

**支线**：
- 王敦之乱后的家族清洗
- 苏峻之乱中的应变
- 王羲之的书法成长线（与谢安家族互动）
- 与司马皇室的关系维护

**情感基调**：守成的荣耀 + 内部分裂的焦虑 + 文化传承的使命

### B1.4 玩家可参与的关键决策

1. **王敦之乱**（322-324）：玩家扮演的王氏族人如何选择？
   - 选项A：支持王敦（分裂家族，但获得军事力量）
   - 选项B：支持朝廷（维护统一，但家族可能受损）
   - 选项C：保持中立（观望，两边下注）

2. **王羲之培养**（330-350）：是否重金培养王羲之书法？
   - 选项A：全力培养（投入家族资源50%，长线文化声望）
   - 选项B：政治优先（兼顾出仕，文化次要）
   - 选项C：双线并行（资源分散）

### B2.3 谢氏家族传承机制

**支线**：
- 谢玄北府兵的创建
- 谢道韫的才女养成
- 谢氏与王氏的"王谢"并称塑造
- 淝水之战后的朝堂格局

**情感基调**：东山再起的隐忍 + 决战前的紧张 + 功成身退的智慧

### B2.4 玩家可参与的关键决策

1. **淝水之战**（383）：谢氏命运的转折点
   - 选项A：主动请战（高风险高回报，可能大胜也可能大败）
   - 选项B：坚守不战（稳守，可能错失战功）
   - 选项C：等待战机（中等风险，依赖敌方失误）
   - 战役结果：胜利→家族声望+30%，北伐主导权；失败→家族降品风险

2. **谢安功成身退**（384）：是否激流勇退？
   - 选项A：功成身退（避免猜忌，长线安全）
   - 选项B：继续掌权（短期利益，猜忌风险）

# Part D：核心机制详细设计

## D1. 联姻系统详细设计

### D1.1 联姻流程

**步骤1：对象识别**
- 系统根据玩家家族品级、郡望、需求，生成候选联姻对象
- 玩家查看候选人属性（属性、年龄、嫁妆/聘礼）

**步骤2：议亲阶段**
- 派遣使者试探
- 双方家族谈判
- 可能遇到拒绝（门不当户不对、已有婚约、关系不佳）

**步骤3：达成婚约**
- 签订婚约（双方家族声望变动）
- 设定婚礼时间
- 政治资本交换

**步骤4：婚礼举办**
- 婚礼规模（影响声望，但花费高）
- 宾客邀请（外交机会）
- 文化活动（雅集、宴会）

**步骤5：婚后影响**
- 后代属性计算（父母属性平均）
- 双方关系变化
- 政治资本落地

### D1.2 联姻类型与机制

| 联姻类型 | 政治收益 | 经济代价 | 风险 |
|---------|---------|---------|------|
| **与皇室联姻** | 极高 | 极低 | 绑定皇室命运 |
| **与顶级门阀联姻** | 高 | 中 | 卷入对方派系 |
| **与次级门阀联姻** | 中 | 中低 | 关系相对稳定 |
| **与寒门联姻** | 低（武将） | 低 | 声望下降 |

### D1.3 后代属性算法

```
后代智力 = (父智力 × 0.5 + 母智力 × 0.5) + 遗传系数 × 10 ± 随机
后代武力 = (父武力 × 0.4 + 母武力 × 0.6) + ± 随机（母方权重更高，母系影响大）
后代魅力 = (父魅力 × 0.6 + 母魅力 × 0.4) + ± 随机（父方权重更高）
后代家世 = MIN(父家族品级, 母家族品级)（就低不就高原则）
后代性格 = 父母性格各50%权重 + ±10（变异）
```

**步骤1：议题选择**

**步骤4：胜负判定**
```

    - (对方辩手清谈属性 × 0.4 + 对方辩手智力 × 0.3 + 对方辩手玄学属性 × 0.2 + 主场优势 × 0.1)
    + 随机数(±20)
```

- 胜利：家族文化声望+10-30%，与在场名士结交机会
