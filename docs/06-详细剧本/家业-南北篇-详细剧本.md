## 〇、剧本设计总则

### 0.1 剧本设计原则

**五大核心原则**：

| 原则 | 含义 | 反例 |
|------|------|------|
| **1. 历史为骨** | 尊重基本史实，不戏说 | ❌ 穿越、玄幻、不当改编 |
| **2. 文学为肉** | 文字优美，有魏晋风度 | ❌ 网络小说式口水文 |
| **3. 抉择为魂** | 玩家决策影响剧情 | ❌ 单线叙事 |
| **4. 人物为核** | 角色塑造有血有肉 | ❌ 工具人NPC |
| **5. 沉浸为神** | 营造魏晋时代氛围 | ❌ 现代感表达 |

### 0.2 剧本格式规范

#### 0.2.1 剧本段格式

```
[场景编号] 场景名称
[地点] 发生地点
[时间] 游戏内时间
[人物] 在场人物
[CG提示] 视觉/动画提示
[正文] 叙事文本
[对话] 角色对话
[选项] 玩家决策
[触发] 后续事件
```

#### 0.2.2 完整剧本段示例

```
[SC_001] 衣冠南渡·序幕
[地点] 黄河渡口
[时间] 西晋永嘉五年（311年）初
[人物] 王导（28岁）、王敦（兄）、司马睿（15岁，琅琊王）、随行士族
[CG提示] 远景：北方的烽火、奔逃的人群；近景：长江渡口的帆船
[正文]
    永嘉之乱，山河破碎。
    八王之乱的余烬未熄，五胡的铁骑又踏碎了中原的安宁。
    司马睿站在渡口的船头，回望北方的天空——
    那里的烽烟，是洛阳的方向，是长安的方向，是故国的方向。
    王导立于船侧，目光深沉。
    他知道，这一次南渡，不是归途的开始，而是新朝的起点。
[对话]
    司马睿："王公，前路茫茫，江东可还容得下我们？"
    王导："殿下，江东虽远，中原士族之心未死。只要殿下行仁义、布恩德，
           江东之民，必将归心。"
[选项]（玩家在此做第一个重大抉择）
    A. 劝司马睿早登大位
    B. 建议司马睿稳固根基
    C. 鼓励司马睿礼贤下士
    D. 保持沉默，观察局势
[触发]
    选项A → 触发"提前称帝"事件线（高风险）
    选项B → 触发"稳健立国"事件线（推荐）
    选项C → 触发"礼贤路线"事件线（稳健）
    选项D → 进入观望期
```

### 0.3 剧本分支设计

#### 0.3.1 分支层级

```
主线剧本（固定）──┬─历史事件（不可改）
                  └─家族事件（可改）
                       ├─关键抉择（重大影响）
                       ├─次要抉择（中等影响）
                       └─细节抉择（轻度影响）
```

#### 0.3.2 分支影响表

| 抉择类型 | 后续影响 |
|---------|---------|
| **大抉择** | 改变家族命运、影响主结局 |
| **中抉择** | 影响家族属性、解锁/锁定剧情线 |
| **小抉择** | 影响NPC态度、解锁隐藏对话 |

##### SC_002 家族会议·立国之争

```
[地点] 建康（南京）王氏庄园·议事厅
[时间] 东晋建武元年（317年）三月
[人物] 王导、王敦、王邃（族弟）、其他王氏族人
[CG提示] 王氏庄园庭院深深，松竹环绕；议事厅内烛火摇曳
[正文]
    建康初定，朝堂空虚。
    司马睿虽已南渡，却迟迟不登大位，
    朝野人心浮动，士族观望。
    今日王氏召开族中会议，商议是否劝进。
[对话]
    王敦（兄）："司马氏气数已尽，江南士族皆愿拥立新主。
              我看这司马睿尚可扶持，但需我等王氏主导。"
    王邃（族弟）："司马氏虽弱，仍是正统。强行另立，恐怕江东士族不服。"
    王导（族长）："此事不必急。司马睿若有心，必有明诏。
                我等只需暗中布局，待时而行。"
[关键抉择]
    A. 劝王敦克制，避免外戚嫌疑（守成路线）
    B. 支持王敦主导，加速司马睿登基（激进路线）
    C. 中立观望，等待司马睿主动表态（平衡路线）
    D. 建议王导亲赴司马睿府上，表明王氏立场（主动路线）
[触发]
    玩家选择 → 影响王导与司马睿的关系 → 影响后续政治格局
```

##### SC_005 苏峻之乱·王氏应变

```
[地点] 建康·王氏庄园
[时间] 东晋咸和二年（327年）
[人物] 王导、王彪之（王氏族人）、庾亮（当朝执政）
[CG提示] 建康城风云突变，叛军逼近；王氏庄园内气氛紧张
[正文]
    苏峻之乱，是王氏家族面临的又一大危机。
    庾亮强行征召苏峻入朝，反而激起叛乱。
    叛军直逼建康，晋成帝年幼，朝野震动。
    王导作为三朝元老，必须做出决断。
[对话]
    王彪之（紧张）："王公，苏峻叛军已至城北，庾公已逃离。
                  我们王氏该如何应对？"
    王导（沉思）："苏峻之乱，非一日之寒。
              庾公咎由自取，但皇帝年幼，不可不顾。
              我意：坚守府邸，等待援军。"
    王彪之："若苏峻强攻府邸？"
    王导（决然）："王氏与国同休。皇帝在，王氏在；
              皇帝若不保，王氏亦不保。"
[选项]
    A. 坚守府邸，保护皇帝
    B. 护送皇帝逃离
    C. 与苏峻谈判，争取和平
    D. 暗中联络其他势力反击
[家族影响]
    选项A → 王氏声望+，王导地位巩固
    选项B → 皇帝安全但王氏失去根基
    选项C → 短期和平，王氏声望受损
    选项D → 风险大，但可能成为平乱功臣
```


```
[地点] 谯国·桓氏庄园
```

## 三、关键事件详细叙事

### 3.1 衣冠南渡（永嘉之乱后，311-317年）

#### 3.1.1 事件背景

```
时间：西晋永嘉五年（311年）至建武元年（317年）
地点：中原至江南
触发原因：永嘉之乱，五胡入侵
参与人物：司马睿、王导、王敦、北方士族数十万

历史背景：
  - 八王之乱导致西晋元气大伤
  - 五胡（匈奴、羯、鲜卑、氐、羌）入侵
  - 怀帝被俘，洛阳陷落（311年）
  - 北方士族大规模南迁
  - 司马睿在王导辅佐下建立东晋（317年）
```

#### 3.1.2 完整叙事文本

```
[序幕·洛阳陷落]
永嘉五年（311年），匈奴刘聪部将刘曜攻破洛阳。
晋怀帝被俘，太尉王衍被石勒杀害。
中原大地，烽火连天，生灵涂炭。

[中段·南渡之路]
洛阳陷落后，北方士族纷纷南迁。
他们扶老携幼，渡过长江，来到江东。
这是一次文化的迁徙——
中原的典章制度、文学艺术、思想哲学，都随着这次南渡，
传到了江南。

[高潮·王导辅政]
建武元年（317年），司马睿于建康称晋王，
是为晋元帝。
王导以丞相之职，总揽朝政。
他提出了八字方针——
"王与马，共天下"。
这句话的意思是：王氏与司马氏，共同治理江东。
这不是简单的政治口号，而是：
司马氏作为皇帝，王氏作为执政，
两者共同治理南渡士族与江东士族。

[结局·江东初定]
东晋政权在江南站稳脚跟。
然而，南北士族的矛盾、门阀与皇权的博弈、
北伐与偏安的分歧……
这一切，都将在未来的103年里，
成为东晋历史的底色。

也是《家业-南北篇》的舞台。
```

### 3.2 王敦之乱（322-324年）

#### 3.2.1 事件背景

```
时间：东晋太宁元年（322年）至太宁二年（323年）
地点：荆州、建康
触发原因：王敦不满司马睿、王导兄弟
参与人物：王敦、王导、司马绍、谢鲲、戴若思

历史背景：
  - 王敦拥兵荆州，势力强大
  - 司马睿猜忌王导，导致王导地位动摇
  - 王敦以"清君侧"为名起兵
  - 第一次王敦之乱：王导坚守建康，王敦失败
  - 司马睿崩，司马绍即位
  - 第二次王敦之乱：王敦再次起兵，病死于军中
```

#### 3.2.2 完整叙事文本

```
[序幕·兄弟分歧]
王导与王敦，是琅琊王氏的两大支柱。
王导居朝辅政，王敦镇守荆州。
然而，随着司马睿的猜忌，
兄弟二人渐行渐远。

王敦以为：王氏立下不世之功，却得不到应有的地位。
王导以为：王氏的安危，不在于权势，而在于德行。

分歧，终于演变成冲突。

[第一次·王敦起兵]
太宁元年（322年），王敦以"清君侧"为名，
从武昌起兵，直指建康。
王导站在了司马氏的一边——
他宣布王敦为叛逆，与王敦断绝兄弟关系。
王敦兵至，王导坚守建康。
最终，王敦因部将背叛而失败，退回武昌。

[转折·司马绍即位]
太宁元年闰八月，司马睿崩。
太子司马绍即位，是为晋明帝。
司马绍聪明果断，王敦感到威胁。

[第二次·王敦之乱]
太宁二年（324年），王敦再次起兵。
然而，他的身体已经每况愈下。
这一次，他没有亲自率军，
而是命其兄王含为统帅。

王导再次坚守建康。
他写信给王含，晓以利害——
"王氏与司马氏，共天下。兄若退兵，
王氏尚可保全；兄若进兵，王氏必亡。"

王敦在军中听到消息，病情加重。
他叹道："我兄不及王导多矣！"
不久，王敦病死于军中。
叛乱平息。

[结局·王氏崛起]
王敦之乱后，王氏家族面临分裂。
王敦一系衰败，王导一系继续执掌朝政。
王导以三朝元老的地位，扶持晋成帝。
王氏家族，达到了权力的巅峰。

但王敦之乱的影响远未结束——
它开启了门阀与皇权博弈的新阶段。
```

```
他决定征召镇守历阳的苏峻入朝。
这一决定，埋下了苏峻之乱的种子。

[爆发·苏峻起兵]
苏峻不愿失去兵权，更不愿束手就擒。
他联合祖约，起兵叛乱。
咸和二年（327年）冬，叛军攻入建康。
庾亮仓皇出逃。
晋成帝被软禁。

[转折·勤王之师]
温峤在江州起兵勤王。
陶侃在荆州举兵响应。
两路大军合击建康。

王导作为三朝元老，留守建康。
他没有逃离，而是与叛军周旋——
保护晋成帝，等待援军。

[高潮·收复建康]
咸和四年（329年），温峤、陶侃联军收复建康。
苏峻兵败身死。
庾亮引咎辞职，退出朝堂。

王导再次成为东晋的支柱。

[结局·格局重塑]
苏峻之乱后，东晋格局重塑：
  - 皇权进一步衰落
  - 门阀政治继续主导
  - 王导三朝元老地位巩固
  - 但王氏家族内部也开始分化
```

### 3.4 淝水之战（383年）—— 标志性大事件

#### 3.4.1 事件背景

```
时间：东晋太元八年（383年）十一月
地点：淝水前线（安徽寿春附近）
触发原因：前秦苻强统一北方后挥师南下
参战方：东晋8万北府兵 vs 前秦90万大军
结果：东晋大获全胜

历史背景：
  - 前秦苻强统一北方（376年）
  - 383年率大军南下灭晋
  - 淝水之战是中国历史上最著名的以少胜多战役之一
```

#### 3.4.2 完整叙事文本

```
[序幕·风雨欲来]
太元八年（383年）秋，前秦大帝苻坚率大军南下。
史载：步骑三十万，骑兵二十七万，羽林军三万，合计近百万。
"投鞭断流"——这是苻坚的豪言。

消息传来，建康震动。
孝武帝司马曜年幼，朝臣惊慌失措。
唯有谢安、谢玄叔侄二人，镇定如常。

[中段·决战前夜]
谢安在建康统筹全局。
他命谢玄率北府兵八万，迎战秦军。

谢玄前线督师，他深知：
秦军虽众，然其兵不一——
有鲜卑人、羯人、氐人、羌人、汉人。
这些人，各怀心思，并非真正齐心。

决战之夜，谢玄召集众将。
他目光如炬：
"秦军虽众，然无谋。
 吾八万北府健儿，足以破之。
 社稷安危，系于一战！
 愿与诸君共勉！"

[决战·淝水之战]
十一月，谢玄与秦军对峙于淝水。
谢玄派人向苻强传话：
"秦军远来疲敝，请后退一步，让我军过河决战。"

苻强与众将商议：
"我军百万，晋军八万，何不退后一步，
待其半渡而击之，必获全胜！"
苻强允诺。

然而——
秦军一退，阵脚大乱。
东晋伏兵大喊：
"秦军败了！秦军败了！"

秦军大乱，自相践踏。
谢玄一马当先，率精兵冲杀——
"杀！"

淝水大捷。
北府兵斩杀秦军数万，苻强中箭，单骑逃回。

[尾声·捷报传来]
淝水大捷的消息传回建康。
谢安正与客人下棋。
他看完战报，神色如常，将战报置于一旁，继续下棋。
客人问："战况如何？"
谢安淡淡地说："小儿辈遂已破贼。"

然而，棋局终了，
客人走后，谢安独坐——
他抚摸着棋枰，心中起伏。
过了许久，他才起身，
跨过门槛时，屐齿撞在门框上折断，
他竟浑然不觉。

[历史评价]
淝水之战，保全了东晋半壁江山。
谢氏家族，达到了权力的巅峰。
谢安的"小儿辈遂已破贼"，
成为中国历史上最有名的淡定之一。
```

## 四、关键场景对话集

### 4.1 王导与司马睿·建康初定

```
[场景描述]
建康宫殿内，烛火摇曳。
司马睿坐于案前，神色凝重。
王导立于阶下，恭敬而不卑微。

[对话]
司马睿："王公，江东可保否？"
王导（微笑）："殿下，江东之保，不在兵革，而在人心。
          殿下若行仁义，江东士族之心必附；
          殿下若图私欲，则王导亦不敢留。"
司马睿沉吟良久："孤愿闻其详。"
王导："臣有三事，请殿下深思：
      一、礼遇江东士族（陆、顾、朱、张）；
      二、宽待南渡士族（王、谢、庾、桓）；
      三、不问南北之争，共御外侮。"
司马睿（起身，拱手）："愿与王公共治江东。"

[历史意义]
这段对话，定下了东晋"王与马，共天下"的政治格局。
也是王氏家族百年辉煌的开端。
```

### 4.2 谢安与谢玄·淝水前夕

```
[场景描述]
淝水决战前夕。
谢安在建康，接到谢玄的军报。
他神色凝重，但举止如常。

[对话]
谢玄（信使转述）："叔父，秦军百万，已近淝水。
              侄已率八万北府健儿，迎战秦军。
              此战若胜，则东晋存；若败，则谢氏亡。"
谢安（看完书信，神色如常）：
"告诉玄儿——
 八万虽少，足以破秦。
 但须谨记：秦军虽众，其心不一；
 我军虽少，其心专一。
 一可当十。"
信使："诺！"
谢安（继续下棋）：
"还有——
 告诉玄儿，此战之后，
 谢氏之兴，已达顶点。
 然'亢龙有悔'，盛极必衰。
 让他早作准备。"
```

### 4.3 兰亭雅集·曲水流觞

```
[场景描述]
东晋永和九年（353年）三月初三，
会稽山阴之兰亭。
王羲之、谢安、孙绰等42位名士，
列坐曲水之畔，流觞赋诗。

[对话]
王羲之（举杯）："今日天朗气清，惠风和畅。
              良辰美景，当赋诗以记。"
孙绰："如此良辰，不可无诗。
       诸君各赋诗一首，不成者罚酒三杯。"
谢安（微笑）："诸君请。"
（众人依次赋诗，气氛融洽）

[高潮·王羲之作序]
诗赋已毕，王羲之取过笔墨：
"今日之会，不可无记。
 让我为诸君作一序文。"
（王羲之挥毫疾书）
（这一挥，写下了天下第一行书）

[历史意义]
兰亭雅集，是中国文化史上的巅峰。
王羲之的《兰亭集序》，被称为"天下第一行书"。
这次雅集，是魏晋风度的极致表达——
文人雅士，寄情山水，留下了永恒的文化记忆。
```

## 五、剧本分支设计

### 5.1 主线分支图

```
[开场] 衣冠南渡
    ↓
[家族选择]
    ├─A：王氏剧本 → 王导辅政主线

    ├─历史事件触发（衣冠南渡、王敦之乱、苏峻之乱等）
    └─家族事件触发（族人成长、联姻、内政）
    
[高潮阶段]
    ├─谢氏剧本：淝水之战（核心高潮）
    ├─王氏剧本：王氏与司马氏关系演变
    └─桓氏剧本：桓温北伐与篡位
    
[结局阶段]
    ├─家族传承结局
    ├─历史功过结局
    └─家族命运结局
```

| **家族联姻选择** | 所有剧本 | 影响家族属性和关系 |

### 5.3 多结局设计

#### 5.3.1 王氏剧本结局

```
结局1：王与马，共天下（历史结局）
  王导辅政三十余年，王氏达到巅峰，
  但皇权与门阀的博弈从未停止。

结局2：王氏分裂（分支结局）
  王敦之乱后王氏内部分裂，
  王氏地位下降，但仍为顶级门阀。

结局3：王氏衰落（败局结局）
  王氏介入过深，遭遇皇帝猜忌，
  王氏被削弱，逐渐退出权力核心。
```

#### 5.3.2 谢氏剧本结局

```
结局1：淝水大捷，谢氏巅峰（历史结局）
  谢安、谢玄淝水之战大获全胜，
  谢氏达到权力巅峰，但内部矛盾加剧。

结局2：淝水小败，谢氏平稳（分支结局）
  淝水之战险胜，谢氏未能达到巅峰，
  但保存实力，长期延续。

结局3：淝水大败，谢氏衰落（败局结局）
  淝水之战失败，谢氏降品，
  东晋格局重塑。
```

#### 5.3.3 桓氏剧本结局

```
结局1：桓温篡位（枭雄结局）
  桓温成功篡位，建立新朝，
  但新朝短命，桓玄败亡。

结局2：桓温功高震主（保守结局）
  桓温未能篡位，但权倾朝野，
  桓氏延续，桓玄后续篡位。

结局3：桓温急流勇退（隐退结局）
  桓温未篡位，主动交权，
  桓氏作为门阀延续。
```

## 六、剧本生产规范

### 6.1 剧本段命名规范

```
格式：[SC_XXX] 场景名称
分类：
  - SC_MAIN：主线剧本
  - SC_BRANCH：分支剧本
  - SC_EVENT：事件剧本
  - SC_DIALOGUE：对话集
  - SC_BACKSTORY：背景叙事
```

### 6.2 剧本质量标准

| 标准 | 要求 |
|------|------|
| **历史准确性** | 符合基本史实，不戏说 |
| **文学性** | 有文采，符合魏晋风度 |
| **可玩性** | 玩家选择有意义 |
| **沉浸感** | 营造时代氛围 |
| **人物塑造** | 角色有血有肉 |

### 6.3 剧本写作流程

```
1. 历史考据阶段
   - 查阅《晋书》《世说新语》等
   - 核对关键事件和人物
   
2. 故事设计阶段
   - 提炼核心冲突
   - 设计分支结构
   
3. 剧本写作阶段
   - 按格式撰写
   - 控制节奏
   
4. 内部评审阶段
   - 历史准确性评审
   - 文学性评审
   - 可玩性评审
   
5. 修改完善阶段
   - 多轮修改
   - 最终定稿
```
