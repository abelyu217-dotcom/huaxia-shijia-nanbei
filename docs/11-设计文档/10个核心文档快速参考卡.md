## 📋 02 - 详细 GDD（数值体系 + 剧本框架）

### 族人属性（核心数值）

**5 维先天属性**：
- 智力（谋略、学术）
- 武力（战斗、统兵）
- 魅力（社交、清谈）
- 政才（治理、出仕）
- 德行（声望、品行）

**16 项后天技能**：
- 经学、文学、书法、绘画、清谈、玄学、佛学、儒学、骑射、剑术、兵法、治政、农事、医术、工匠、音乐

**5 轴性格**：
- 进取-保守、内向-外向、仁慈-严厉、聪慧-朴实、独立-从众

**4 类关系**：
- 血缘（父、母、子、女）
- 姻亲（妻、夫、岳父、岳母、婿、媳）
- 社交（友、敌、师、生）
- 政治（主君、臣下、盟友）

### 九品中正制（核心机制）

```
1品 ─ 上品 → 顶级门阀 → 出仕上限：尚书令、太尉
2品 ─ 上品 → 一流门阀 → 出仕上限：尚书、九卿
3品 ─ 中品上 → 高级门阀 → 出仕上限：刺史、太守
4品 ─ 中品上 → 中级门阀 → 出仕上限：郡守、列侯
5品 ─ 中品中 → 次级门阀 → 出仕上限：县令、郎官
6品 ─ 中品下 → 寒门士族 → 出仕上限：功曹、掾属
7品 ─ 下品上 → 平民 → 出仕上限：低级吏员
8品 ─ 下品中 → 寒人 → 出仕上限：兵户
9品 ─ 下品下 → 奴仆 → 不出仕
```

**联姻匹配规则**：
- 品级差 ≤ 2 品：可联姻
- 品级差 3-4 品：需特殊条件
- 品级差 ≥ 5 品：禁止联姻

## 📋 03 - 核心可玩原型 PRD

### 原型使命

**30-60 分钟可玩 Demo**，验证 3 个根本问题：
- Q1：玩家愿意"管一个家族"超过 30 分钟吗？
- Q2：九品中正制 + 家族养成撑得起反复游玩吗？
- Q3：魏晋南北朝差异化定位玩家买单吗？

### 5 个核心场景

| 场景 | 时长 | 验证 |
|------|------|------|
| A. 家族建立 | 3 分钟 | 时代选择、家族选择简化 |
| B. 单回合循环 | 15-20 分钟 × 3-5 轮 | **核心循环成瘾性** |
| C. 联姻决策 | 5 分钟 × 1-2 次 | 后代属性算法、外交博弈 |
| D. 清谈品评 | 3 分钟 × 1-2 次 | 文化声望系统 |
| E. 淝水之战简版 | 10 分钟 | 大事件多结局体验 |

### 技术选型

| 维度 | 方案 | 理由 |
|------|------|------|
| 引擎 | **Godot 4** | 开源免费、轻量、2D 优秀 |
| 美术 | 黑白线稿 + 关键水墨 | 低保真高质感、节省成本 |
| 数据 | JSON → SQLite | 易调试、可持久化 |
| 平台 | Windows/Mac/Linux/Web | Godot 天然支持 |

### 验收标准

**必须 100% 通过 7 项**：
✅ 家族选择、✅ 族人培养、✅ 田庄经营、✅ 联姻决策、✅ 清谈事件、✅ 淝水之战 3 种结局、✅ 存档读档

**内部测试 10 人**：
- ≥7 人愿意继续玩（70%）
- ≥8 人认为"核心玩法成立"（80%）
