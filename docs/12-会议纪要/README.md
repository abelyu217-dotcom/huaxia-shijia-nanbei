# 12-会议纪要

本目录存放团队会议纪要。

## 文件命名规范

```
YYYY-MM-DD_会议类型_主题.md
```

例如：
- `2026-09-07_启动会_项目立项.md`
- `2026-09-14_周会_M1规划.md`
- `2026-09-21_技术评审_引擎选型.md`

## 会议类型

- **启动会**：项目启动
- **周会**：每周工作同步
- **月会**：每月工作review
- **技术评审**：技术方案评审
- **里程碑评审**：M1/M2/M3 review
- **专题讨论**：某个特定主题

```markdown
- **时间**：
- **地点**：
- **主题**：
```
