> **版本**：v1.0 自建家族机制
> **日期**：2026年9月7日
> **文档定位**：作为自建家族系统的设计依据，解决"玩家自建家族如何与历史剧本融合"的核心问题
> **承接文档**：《家业-南北篇-详细剧本.md》

## 〇、核心问题

**自建家族的存在，让剧本设计面临根本性的挑战：**

```
预设家族（王、谢、桓）→ 玩家演"历史人物" → 剧本有现成路线
自建家族（玩家自创） → 玩家演"自己"      → 剧本无现成路线
                                      
   Q：自建家族如何在历史洪流中找到自己的位置？
   Q：玩家如何与历史人物互动？
   Q：剧本如何保持自由度又不过于松散？
```

这是一个**机制设计 + 剧本设计**的双重问题。

## 一、自建家族 vs 预设家族：核心差异

### 1.1 玩家角色定位差异

| 维度 | 预设家族 | 自建家族 |
|------|---------|---------|
| **扮演对象** | 历史真实人物 | 玩家自创角色 |
| **情感锚点** | "我在演王导" | "我是王（自创）" |
| **代入感来源** | 历史代入 | 创造代入 |
| **学习成本** | 低（熟悉历史） | 中（需理解机制） |
| **决策方向** | 已知结局，了解权衡 | 自由探索 |

### 1.2 剧本密度差异

| 维度 | 预设家族 | 自建家族 |
|------|---------|---------|
| **预设剧本** | 13个核心场景 | 0个预设剧本 |
| **历史事件** | 专门定制剧本 | 通用事件脚本 |
| **NPC互动** | 与真实历史人物预设关系 | 动态建立关系网 |
| **结局可能性** | 受历史约束（3种结局） | 几乎无限 |
| **重玩价值** | 中（已知道结局） | 高（每次不同） |

### 1.3 历史代入差异

| 维度 | 预设家族 | 自建家族 |
|------|---------|---------|
| **历史代入感** | ⭐⭐⭐⭐⭐ 极强 | ⭐⭐ 中等 |
| **创造感** | ⭐⭐ 弱 | ⭐⭐⭐⭐⭐ 极强 |
| **戏剧张力** | ⭐⭐⭐⭐⭐ 强 | ⭐⭐⭐ 中等 |
| **剧本丰富度** | ⭐⭐⭐⭐ 高 | ⭐⭐ 中等 |
| **自由度** | ⭐⭐ 低 | ⭐⭐⭐⭐⭐ 极高 |

## 二、自建家族的剧本定位

### 2.1 剧本定位：自建家族 ≠ 自创剧本

**关键判断**：

```
自建家族不是"凭空创造历史"
而是"在历史洪流中找到自己家族的位置"
```

**核心设计理念**：

1. **历史是舞台，玩家是演员**
   - 历史大事件（衣冠南渡、王敦之乱、淝水之战）照常发生
   - 玩家自建家族作为"小人物"或"新晋家族"参与其中
   - 玩家可以影响历史，但很难颠覆历史

2. **预设家族是剧本的主角**
   - 王、谢、桓家族按预设剧本演绎
   - 自建家族作为"旁观者"或"参与者"
   - 玩家可以与这些家族互动

3. **剧本 = 历史事件 + 玩家应对**
   - 历史事件：固定发生
   - 玩家应对：玩家决策
   - 家族命运：玩家决策决定

### 2.2 自建家族的三大剧本定位

#### 定位A：**新晋士族（推荐MVP）**

```
家族设定：
- 原本是北方寒门或中层士族
- 在永嘉之乱中南下
- 在东晋建立后跻身"次级门阀"
- 目标：从次级门阀上升到顶级门阀

玩法定位：
- 难度：⭐⭐⭐（中等）
- 戏剧张力：中
- 历史参与度：中（可参与淝水之战等大事件）
- 结局：玩家决定
```

#### 定位B：**寒门武将**

```
家族设定：
- 北方流亡武将家族
- 在东晋以武功立足
- 代表：刘牢之、何谦等北府将门的前身
- 目标：在门阀政治中走出一条寒门之路

玩法定位：
- 难度：⭐⭐⭐⭐（中高）
- 戏剧张力：高（寒门与门阀的天然矛盾）
- 历史参与度：高（参与战役）
- 结局：玩家决定
```

#### 定位C：**隐居世家**

```
家族设定：
- 战乱中避世的隐士家族
- 不参与政治纷争
- 以文化传家
- 目标：在乱世中保存家族血脉与文化

玩法定位：
- 难度：⭐⭐（中等偏低）
- 戏剧张力：低
- 历史参与度：低（主要被动应对）
- 结局：家族延续
```

## 三、自建家族的剧本设计机制

### 3.1 剧本设计三大原则

#### 原则1：**历史事件是剧本骨架**

```
历史大事件（不可改）：
  - 永嘉之乱（311年）
  - 衣冠南渡（311-317年）
  - 王敦之乱（322-324年）
  - 苏峻之乱（327-329年）
  - 桓温北伐（354-369年）
  - 淝水之战（383年）
  - 桓玄篡晋（403-404年）
  - 刘裕崛起（408-420年）

玩家家族在每个历史事件中做出选择
```

#### 原则2：**预设家族是剧本配角**

```
预设家族行为模式（预设脚本驱动）：
  - 王氏：守成路线
  - 谢氏：文武双全
  - 桓氏：枭雄路线

玩家家族可以与这些家族互动：
  - 联姻、结盟、敌对、依附
  - 玩家选择如何与历史人物相处
```

#### 原则3：**玩家决策是剧本灵魂**

```
玩家决策影响：
  - 家族命运（升品/降品/消亡）
  - 关系网络（与谁结盟）
  - 结局走向（成为顶级门阀/中等家族/消亡）
  - 历史评价（褒贬不一）
```

### 3.2 自建家族的剧本结构

```
┌─开场：家族创建（5分钟）───────────┐
│ • 自定义家族名、郡望、家学、家风     │
│ • 选择起点（次级门阀/寒门/隐居）     │
│ • 设定祖先（3-5代）               │
└─────────────────────────────────┘
                ↓
┌─主线：历史事件线（贯穿103年）─────────┐
│ • 8个核心历史事件（每个有专门剧本）    │
│ • 每个事件包含：触发/选项/后果        │
│ • 玩家决策影响家族属性              │
└─────────────────────────────────┘
                ↓
┌─支线：家族发展线（日常循环）─────────┐
│ • 族人养成                       │
│ • 联姻外交                       │
│ • 经营家业                       │
│ • 与预设家族互动                  │
└─────────────────────────────────┘
                ↓
┌─高潮：玩家主导的家族命运线───────────┐
│ • 关键节点（升品、危机、决战）        │
│ • 玩家主导剧情走向                │
│ • 影响家族未来100年              │
└─────────────────────────────────┘
                ↓
┌─结局：玩家自定义结局─────────────────┐
│ • 4种主要结局                    │
│ • 每个结局有多个变体              │
└─────────────────────────────────┘
```

## 四、自建家族的核心机制设计

### 4.1 家族创建机制

#### 4.1.1 创建流程

```
[Step 1] 命名家族（自由输入）
    - 姓氏（如"陈"、"范"、"司马"等）
    - 郡望（如"颍川陈氏"、"南阳范氏"）
    - 家族名（如"颍川陈氏家族"）

[Step 2] 选择家族类型（3选1）
    - 新晋士族（北方南下）
    - 寒门武将（武功立足）
    - 隐居世家（文化传家）

[Step 3] 设置家学传统（多选）
    - 书法、玄学、儒学、佛学、武学、医学等
    - 选择2-3个家学

[Step 4] 设置家风偏向（5维）
    - 进取/守成
    - 仁慈/冷酷
    - 诚实/狡诈
    - 奢靡/节俭
    - 刚直/柔顺

[Step 5] 设置祖先（3-5代）
    - 至少3代祖先（姓名、简要生平）
    - 自动生成属性（基于家族类型）

[Step 6] 完成创建
    - 初始家族属性
    - 初始田庄
    - 初始关系网
    - 进入游戏
```

#### 4.1.2 家族类型差异表

| 维度 | 新晋士族 | 寒门武将 | 隐居世家 |
|------|---------|---------|---------|
| **起点品级** | 三品 | 七品 | 五品 |
| **初始田庄** | 中等 | 较少 | 中等（偏园林） |
| **初始声望** | 中等 | 较低 | 中等（文化高） |
| **擅长** | 文化+外交 | 军事+武将 | 文化+玄学 |
| **短板** | 武将 | 文化 | 政治 |
| **历史角色** | 中等门阀 | 北府兵 | 名士家族 |
| **难度** | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |

### 4.2 历史事件应对机制

#### 4.2.1 历史事件触发逻辑

```
对于自建家族，历史事件以"通用脚本"形式触发：

历史事件 → 检查触发条件 → 通知玩家 → 玩家选择 → 应用结果

触发条件示例（衣冠南渡）：
  - 玩家家族在北方
  - 时间到达311年
  - 玩家家族品级 < 二品
  → 触发事件：是否南渡？

玩家选项（多选）：
  A. 立即南渡（保留文化血脉）
  B. 暂缓南渡（保守观望）
  C. 部分南渡（部分族人留下）
  D. 留守北方（风险高）

结果：
  - 选项A：家族南迁，损失部分田庄，保留文化
  - 选项B：观望后被迫南迁，损失更大
  - 选项C：家族分裂（两个支系）
  - 选项D：可能被胡人俘虏或流亡
```

#### 4.2.2 历史事件对自建家族的影响表

| 历史事件 | 自建家族应对 | 典型结果 |
|---------|------------|---------|
| **永嘉之乱** | 是否南渡 | 决定家族存亡 |
| **衣冠南渡** | 是否参与拥立司马睿 | 影响与皇室关系 |
| **王敦之乱** | 站队选择 | 影响与王氏关系 |
| **苏峻之乱** | 应对叛军 | 影响家族安全 |
| **淝水之战** | 是否参与北伐 | 影响与谢氏关系+军事声望 |
| **桓温北伐** | 是否支持 | 影响与桓氏关系 |
| **桓玄篡晋** | 应对篡位 | 影响家族命运 |
| **刘裕崛起** | 是否投靠 | 影响寒门路线可行性 |

### 4.3 与预设家族的互动机制

#### 4.3.1 关系建立机制

```
关系建立方式：
1. 联姻（最稳定）
2. 政治结盟
3. 文化交往（清谈、雅集）
4. 军事合作
5. 商业往来

关系类型：
- 盟友（互相支持）
- 姻亲（联姻关系）
- 门客（依附关系）
- 敌对（互相敌视）
- 中立（无特殊关系）
```

#### 4.3.2 预设家族的"接受度"差异

| 预设家族 | 接受新家族加入 | 难度 |
| | 琅琊王氏 | 中高（重门第） |
| | 陈郡谢氏 | 中（文武并重） |
| | 谯国桓氏 | 低（门槛较低） |

### 4.4 家族升品机制（自建家族核心）

#### 4.4.1 升品路径

```
次级门阀（三品）→ 二品 → 一品
    ↑              ↑       ↑
   联姻助力        文化成就   关键事件
   战功            朝堂站队   长期积累
```

#### 4.4.2 升品条件

```
次级门阀 → 二品：
- 至少1名族人在朝为官
- 与至少1个高级门阀建立稳定关系
- 持续3代的文化成就

二品 → 一品：
- 多名族人在朝为高官
- 与多个高级门阀有姻亲关系
- 至少1名族人达到顶级文化成就
- 关键历史事件的正确站位
- 至少5代的家族积累
```

## 五、自建家族的剧本实例

### 5.1 实例：颍川陈氏家族剧本

#### 家族设定

```
家族名：颍川陈氏
家族类型：新晋士族
品级：三品
家学：儒学、书法
家风：进取50%、仁慈70%、诚实80%、节俭60%、刚直75%
祖先：
- 陈寔（远祖，东汉名士）
- 陈纪（曾祖，西晋名士）
- 陈群（祖父，西晋重臣，九品中正制创始人）
现状：
- 永嘉之乱中幸存
- 部分族人南下，部分留守北方
- 需要重建家族
```

#### 剧本大纲（103年）

##### SC_101 家族抉择·南渡之争

```
[地点] 颍川陈氏庄园
[时间] 永嘉五年（311年）
[人物] 陈氏族长（玩家）、族中长老
[CG提示] 北方战火纷飞，庄园中族人神色紧张

[正文]
永嘉五年，刘曜攻破洛阳的消息传来。
北方陷入战火。
颍川陈氏召开族中会议，讨论是否南渡。
作为陈氏当代族长，玩家必须做出决定。

[对话]
族老甲："族长，洛阳已破，长安亦危。
          我们是南下避祸，还是留守家园？"
族老乙："南下则远离根基，前途未卜。
          留守则面临胡人铁骑，九死一生。"
玩家（族长）："此事关系家族存亡，不可轻断。
          容我三思。"
  
[关键抉择]
A. 举族南渡（推荐）
   - 损失北方田庄
   - 文化血脉保留
   - 与江东士族接触
   
B. 留守北方
   - 保留田庄
   - 面临胡人威胁
   - 可能被同化
   
C. 部分南渡
   - 家族分为两支
   - 风险分散
   - 联系困难
   
D. 暂缓决策
   - 观望局势
   - 风险增加
   - 可能被迫仓促南渡

[结果]
选项A → 家族南迁，进入东晋建康，参与历史
选项B → 家族面临胡人统治，长期挣扎
选项C → 家族分裂为南北两支
选项D → 可能在乱局中损失
```

##### SC_102 衣冠南渡·陈氏站位

```
[地点] 建康城外
[时间] 建武元年（317年）
[人物] 王导（NPC）、陈氏族长（玩家）、其他士族
[CG提示] 长江渡口，帆船点点；王导立于岸上，神色从容

[正文]
陈氏家族南渡后，来到建康城外。
此时司马睿在王导辅佐下，准备称晋王。
但江东士族（陆、顾、朱、张）对此不以为然。
陈氏作为南渡士族，必须做出选择。

[对话]
王导："陈公远来，辛苦了。
     江东初定，百废待兴。
     陈公可愿与王氏共辅司马氏？"
陈氏族长："王公所言，正合我意。
          只是江东士族……"
王导（微笑）："江东士族，自有应对之策。
          陈公但听安排便是。"

[关键抉择]
A. 主动结交王导（高调）
B. 低调观察王导（稳健）
C. 与江东士族结交（独立路线）
D. 保持中立（观望）

[结果]
选项A → 与王氏建立友好关系，可能成为王氏党羽
选项B → 与王氏保持距离，自主发展
选项C → 与江东士族（如陆氏）建立关系
选项D → 暂不介入，但可能错过机会
```

##### SC_103 淝水之战·陈氏抉择

```
[地点] 建康/淝水前线
[时间] 太元八年（383年）
[人物] 谢安（远程）、谢玄（前线）、陈氏族长（玩家）
[CG提示] 战报频传，建康城内紧张；远景淝水前线战火

[正文]
淝水之战前夕，前秦大军压境。
东晋举国震动，但谢安、谢玄叔侄镇定自若。
陈氏家族面临关键抉择：
是否参与淝水之战？是否支持谢氏？

[对话]
谢安（书信）："陈公，前秦大军南下，江东危在旦夕。
          陈公可愿助谢氏一臂之力？"
陈氏族长（玩家）："谢公之邀，敢不从命。"

[关键抉择]
A. 派族人率部曲支援淝水之战（高风险高回报）
B. 提供粮草支援（中等风险）
C. 派族人参与文官辅政（低风险）
D. 保持观望（无风险无收益）

[结果]
选项A → 家族军事声望暴涨，可能与谢氏结为同盟
选项B → 与谢氏建立稳定关系
选项C → 在朝中建立根基
选项D → 错过关键机会
```

##### SC_104 家族危机·桓玄之乱

```
[地点] 建康
[时间] 元兴元年（402年）
[人物] 桓玄、晋安帝、陈氏族长（玩家）
[CG提示] 建康城风云突变，桓玄兵马进城

[正文]
桓温之子桓玄，终于发动篡位。
他废晋安帝，自立为楚帝。
陈氏家族面临又一大考验——
是否承认桓玄？

[对话]
桓玄（召见）："陈公，孤今日登基，可愿与孤共治？"
陈氏族长（玩家）："……"

[关键抉择]
A. 支持桓玄（押注篡位者）
B. 反对桓玄（维护司马氏）
C. 表面归附，暗中观望
D. 举族避祸（逃离建康）

[历史背景]
真实历史：桓玄篡位后迅速败亡（404年）
```

## 六、自建家族的设计难点与解决方案

### 6.1 难点1：自由度 vs 引导

**问题**：
- 完全自由 =无剧本感
- 强引导 =失去自建意义

**解决方案**：

```
"剧本骨架 + 自由血肉"模式：

- 历史事件提供"骨架"（固定）
- 玩家决策填充"血肉"（自由）
- 关键节点提供"剧情高潮"（预设）
- 日常循环提供"自由度"（自主）
```

### 6.2 难点2：代入感

**问题**：
- 玩家自创家族，与历史人物的关系不明确
- 玩家很难投入不熟悉的家族

**解决方案**：

```
"祖先系统"增强代入感：

- 玩家创建家族时设定3-5代祖先
- 祖先的"性格"和"事迹"会影响后代
- 玩家可以选择"效仿祖先"或"突破祖先"
- 家族族谱成为情感锚点
```

### 6.3 难点3：平衡性

**问题**：
- 预设家族有完整剧本，玩起来爽
- 自建家族自由度大，但可能迷茫

**解决方案**：

```
"剧本密度补偿"机制：

- 自建家族享有"新手引导"包（5个核心事件）
- 自建家族享有"剧本模块"系统（可购买/解锁预设剧本）
- 自建家族享有"升品加成"（比预设家族升品略快）
```

### 6.4 难点4：剧本总量

**问题**：
- 预设家族剧本13个
- 自建家族剧本无限（不可能全做）

**解决方案**：

```
"通用剧本 + 家族定制"混合：

- 历史事件用"通用剧本"（自建家族适用）
- 关键节点用"家族定制剧本"（基于玩家设定）
- NPC互动用"动态生成"（基于关系网）
- 文化事件用"模块化"（家学、玄学等）
```

## 七、自建家族的可玩性保障

### 7.1 五大保障机制

| 机制 | 内容 | 作用 |
|------|------|------|
| **历史事件包** | 8个核心历史事件通用剧本 | 保证自建家族也有大事件 |
| **升品加成** | 自建家族升品速度+10% | 补偿剧本缺失 |
| **新手引导** | 5个核心事件详细引导 | 降低上手难度 |
| **动态NPC** | 与历史人物动态建立关系 | 增强互动性 |
| **成就系统** | 自建家族专属成就 | 增强目标感 |

## 八、自建家族的剧本生产建议

### 8.1 剧本生产优先级

| 优先级 | 剧本类型 | 工作量 |
|--------|---------|--------|
| **P0** | 8个核心历史事件通用剧本 | 1-2人月 |
| **P1** | 3个家族类型的引导剧本 | 1人月 |
| **P2** | 关键节点的定制剧本 | 2-3人月 |
| **P3** | 各种NPC互动剧本 | 持续 |

### 8.2 通用剧本模板

```
历史事件模板：
- 触发条件（自动判定）
- 事件背景（固定文本）
- 玩家选项（3-4个）
- 选项结果（影响家族属性）
- 后续触发（连锁事件）

通用剧本示例（适用于自建家族）：

衣冠南渡剧本：
  触发：北方家族 + 311年
  选项：南渡/留守/部分南渡
  结果：影响家族地理位置、初始属性
  后续：触发"建康初定"事件
  
王敦之乱剧本：
  触发：建康地区家族 + 322年
  选项：支持王敦/支持朝廷/中立
  结果：影响与王氏关系、家族声望
  后续：触发"战后清算"事件
```

### 8.3 动态NPC互动

```
NPC互动剧本（动态生成）：

基础互动：
- 求见（对方愿意见/不见）
- 拜访（互动+关系变化）
- 邀请（宴会、雅集）

深度互动：
- 结盟（关系升级）
- 联姻（具体谈判）
- 敌对（关系破裂）

互动剧本生成逻辑：
  - 基于双方关系
  - 基于历史背景
  - 基于玩家行动
  - 基于随机因素
```

## 九、自建家族的多结局设计

### 9.1 四大基础结局

```
结局1：成为顶级门阀
  条件：
  - 家族升到一品
  - 与多个高级门阀建立姻亲关系
  - 持续5代以上的积累
  
  结局描述：
  "陈氏家族，经过103年的不懈努力，
   终于从次级门阀晋升为顶级门阀。
   你的家族，与王、谢、庾、桓并列于世。
   这是数百年来从未有过的寒门奇迹。"
```

```
结局2：成为文化世家
  条件：
  - 家族文化声望达到顶级
  - 多名族人达到顶级文化成就
  - 家学传承完整
  
  结局描述：
  "陈氏家族不以政治显赫，而以文化传家。
   你的族人，在书法、玄学、文学上各有建树。
   百年之后，世人谈起陈氏，仍以文化为尊。"
```

```
结局3：成为武将世家
  条件：
  - 家族军事力量达到顶级
  - 多名族人成为著名将领
  - 与北府兵等军事集团关联
  
  结局描述：
  "陈氏家族，在门阀政治中走出一条武家之路。
   你的族人，在历次战役中立下赫赫战功。
   然而，武将的命运，往往与时代紧紧相连……"
```

```
结局4：家族衰败
  条件：
  - 家族降品
  - 主要族人死亡
  - 政治站位错误
  
  结局描述：
  "陈氏家族，在历史的洪流中沉沦。
   也许是因为站位错误，也许是因为时运不济。
   但家族的基因、文化的血脉，仍在某个角落延续。"
```

### 9.2 结局变体

每个基础结局都有3-5种变体：

```
"成为顶级门阀"的变体：
- A1：通过联姻实现（姻亲路线）
- A2：通过战功实现（军事路线）
- A3：通过文化实现（文化路线）
- A4：通过站队实现（政治路线）
- A5：通过长期积累实现（稳健路线）
```

## 十一、结语

自建家族系统是《家业-南北篇》的重要组成部分，其设计解决了三个核心问题：

✅ **历史代入 vs 创造自由**：通过"剧本骨架 + 自由血肉"模式平衡
✅ **剧本密度 vs 重玩价值**：通过"通用剧本 + 动态生成"补充
✅ **预设家族 vs 自建家族**：通过"自建家族加成"机制平衡

**核心信念**：
> **好的自建家族系统，不是让玩家脱离历史，而是让玩家在历史中找到自己的位置。**
