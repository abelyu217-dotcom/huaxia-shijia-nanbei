## 〇、美术总则

### 0.1 美术使命

**用魏晋南北朝的视觉语言，构建一个让玩家"愿意沉浸其中"的古代家族世界。**

具体而言：
1. **传递文化感** —— 让玩家第一眼就感受到"这是中国古典文化，不是日韩风"
2. **强化家族传承** —— 每个家族有独特的视觉标识
3. **体现时代差异** —— 不同阶层、不同时期的视觉风格有明显差异
4. **支撑长线审美** —— 玩家玩100小时不会审美疲劳

### 0.2 核心美学（五条不可动摇的原则）

| 原则 | 核心 | 反例 |
|------|------|------|
| **1. 魏晋风度** | 清瘦有骨、宽衣博带、飘逸含蓄 | ❌ 网红脸、肌肉武将 |
| **2. 水墨意境** | 留白悠远、墨分五色、计白当黑 | ❌ 浓墨重彩、过度饱和 |
| **3. 历史准确** | 服饰、器物、建筑符合南北朝 | ❌ 唐宋明清元素混入 |
| **4. 阶层分明** | 士族vs寒门、皇室vs平民有视觉差异 | ❌ 全员华服 |
| **5. 静中有动** | 静态画面为主，少量动态点缀 | ❌ 满屏特效 |

## 一、核心美学体系

### 1.1 魏晋风度的视觉化

#### 1.1.1 视觉关键词

```
飘逸 / 含蓄 / 雅致 / 空灵 / 风骨 / 清瘦 / 博带 / 长袍
抚琴 / 兰亭 / 竹林 / 佛寺 / 扪虱 / 清谈 / 醉卧
```

#### 1.1.2 视觉反关键词（避免）

```
❌ 网红脸 / 锥子脸 / 大眼萌 / 浓妆艳抹
❌ 肌肉猛男 / 铠甲闪耀 / 浮夸披风
❌ 日韩风 / 欧美奇幻 / 仙侠修真
❌ 浓墨重彩 / 高饱和度 / 霓虹色
❌ 二次元 / 卡通化 / Q版萌系
```

#### 1.1.3 魏晋风度的视觉特征

| 特征 | 具体表现 | 来源 |
|------|---------|------|
| **清瘦** | 人物面部清瘦、身形修长 | 竹林七贤砖画 |
| **宽衣** | 博带长袍、衣袖宽大 | 顾恺之《女史箴图》 |
| **飘逸** | 衣袂飘飘、动感柔和 | 《洛神赋图》 |
| **风骨** | 眼神深邃、姿态从容 | 魏晋人物画 |
| **素雅** | 色调清淡、装饰简朴 | 南朝审美 |

### 1.2 水墨意境

#### 1.2.1 墨分五色

| 墨色 | 应用场景 | 视觉特征 |
|------|---------|---------|
| **焦墨** | 重点强调 | 黑而浓 |
| **浓墨** | 主要轮廓 | 厚重 |
| **淡墨** | 次要元素 | 柔和 |
| **清墨** | 远景、留白 | 极淡 |
| **水** | 渲染、过渡 | 几乎透明 |

#### 1.2.2 留白艺术

**核心原则**："计白当黑"——空白本身是构图的一部分

**应用场景**：
- 玄谈场景：80%留白，人物点缀
- 田庄场景：大量天空留白
- UI界面：留白 ≥ 40%
- 文字：行距、字距宽松

### 1.3 工笔重彩

#### 1.3.1 工笔技法应用

| 元素 | 应用 | 程度 |
|------|------|------|
| **人物面部** | 工笔细描 | 100% |
| **服饰纹样** | 工笔勾勒 | 80% |
| **场景细节** | 工笔点缀 | 50% |
| **背景远景** | 写意挥洒 | 20% |

#### 1.3.2 重彩应用

**原则**：重彩只用于关键部位（如服饰点缀、关键场景），整体仍以清淡为主。

| 重彩应用 | 不重彩应用 |
|---------|----------|
| 皇室服饰（局部） | 士族日常 |
| 重要宴会 | 田庄日常 |
| 战役关键场景 | 普通对话 |
| 兰亭雅集 | 家族会议 |

### 1.4 青绿山水

#### 1.4.1 应用范围

- 田庄场景背景
- 江南地域
- 雅集场景
- 道家仙境

#### 1.4.2 代表色系

| 颜色 | Hex | 应用 |
|------|-----|------|
| **石青** | #4A7C7E | 远山 |
| **石绿** | #5D8B6F | 山林 |
| **赭石** | #A75D40 | 山石 |

## 三、光影与构图原则

### 3.1 光影原则

**核心原则**：自然光、柔和光、避免戏剧化光影

#### 3.1.1 光影应用表

| 场景 | 光源 | 强度 | 阴影 |
|------|------|------|------|
| **朝廷** | 顶部柔光 | 中等 | 适度 |
| **田庄** | 阳光 | 中等偏弱 | 轻盈 |
| **玄谈** | 侧光/天光 | 弱 | 几乎无 |
| **战场** | 阴沉天光 | 强 | 浓重 |
| **佛寺** | 烛光/天光 | 弱 | 柔和 |
| **夜晚** | 月光/烛光 | 极弱 | 朦胧 |

#### 3.1.2 光影禁忌

- ❌ 戏剧化的明暗对比（"伦勃朗光"）
- ❌ 高光反射、金属反光
- ❌ 边缘光、轮廓光（动漫风）
- ❌ 纯黑阴影

### 3.2 构图原则

#### 3.2.1 黄金构图

**原则**：画面中心可偏离几何中心，常用黄金分割点

```
┌─────────────────────────────┐
│   留白                       │
│                              │
│        ╔═══════╗              │
│        ║  主体  ║   ←─ 黄金点 │
│        ╚═══════╝              │
│                              │
│       留白                    │
└─────────────────────────────┘
```

#### 3.2.2 常用构图法

| 构图 | 应用场景 | 视觉特征 |
|------|---------|---------|
| **S形构图** | 田庄、园林 | 流畅、自然 |
| **三角构图** | 群体场景 | 稳定、平衡 |
| **对角构图** | 战场、冲突 | 张力 |
| **散点构图** | 雅集、宴会 | 自由、轻松 |
| **留白构图** | 玄谈、独白 | 空灵 |

### 3.3 留白艺术

**原则**：留白率 ≥ 30%

#### 3.3.1 不同场景留白率

| 场景 | 留白率 |
|------|--------|
| 玄谈 | 60-70% |
| 田庄远景 | 50% |
| 朝廷大殿 | 20% |
| 战役场面 | 10% |
| UI界面 | 40% |

### 3.4 景深与透视

**原则**：使用散点透视（国画传统），而非单点透视

| 应用 | 透视方式 |
|------|---------|
| 建筑 | 散点透视（可同时看到多个面） |
| 田庄 | 散点透视 + 高视点 |
| 朝廷大殿 | 对称透视 |
| 玄谈 | 近景特写，远景虚化 |
| 战场 | 浅景深，焦点在中景 |

## 四、角色设计规范

### 4.1 角色设计原则

**七大原则**：
1. **清瘦有骨** —— 不画网红脸，画有故事的脸
3. **气质为上** —— 容貌其次，气质为上
4. **阶层分明** —— 服饰一眼能看出阶层
5. **时代准确** —— 符合南北朝服饰规范
6. **性格外化** —— 通过姿态、表情表现性格
7. **细节统一** —— 同一家族成员有共同识别元素

### 4.2 角色设计系统

#### 4.2.1 基础比例

| 角色类型 | 头身比 | 备注 |
|---------|--------|------|
| 士族男性 | 1:7-1:8 | 清瘦修长 |
| 士族女性 | 1:6-1:7 | 优雅纤细 |
| 寒门武将 | 1:7-1:8 | 精壮有力 |
| 胡人家族 | 1:7-1:8 | 强壮 |
| 皇室成员 | 1:7-1:8 | 高贵气质 |
| 僧人道士 | 1:7-1:8 | 超凡 |

#### 4.2.2 面部特征

**统一原则**：
- **脸型**：长脸、椭圆、略瘦
- **眼睛**：细长、含蓄、内敛
- **眉毛**：平直、稍浓
- **鼻子**：挺直、不夸张
- **嘴唇**：薄、自然
- **胡须**（男性）：飘逸、有型

**禁忌**：
- ❌ 大眼、双眼皮（现代审美）
- ❌ 锥子脸、V字脸
- ❌ 浓密假睫毛
- ❌ 丰满嘴唇
- ❌ 夸张表情

### 4.3 士族男性设计规范

#### 4.3.1 总体特征

```
身形：清瘦修长，如松如竹
气质：飘逸从容，举止端庄
服饰：宽衣博带，素色为主
发型：束发戴冠（进贤冠/笼冠）

## 六、UI设计规范

### 6.1 UI设计原则

**七大原则**：
1. **古朴质感** —— 仿古纸、卷轴、典籍样式
2. **简洁明了** —— 不堆砌元素
3. **水墨为主** —— 黑白灰为主，少量朱砂红
4. **留白充足** —— UI元素之间间距宽松
5. **字体考究** —— 使用书法字体
6. **层次分明** —— 主次清晰
7. **文化感** —— 避免现代UI元素

### 6.2 UI结构总览

```
┌──────────────────────────────┐

## 十、美术生产规范

### 10.1 文件命名规范

```
[项目前缀]_[类型]_[内容]_[状态]_[版本]
示例：
- HJ_NS_CHARACTER_WANGDAO_FINAL_V1.png（王导最终立绘）
- HJ_NS_SCENE_LANTING_CONCEPT_V1.png（兰亭场景概念图）

- HJ_NS_ICON_CULTURE_FINAL_V1.png（文化图标最终版）

类型代码：
- CHARACTER：角色
- SCENE：场景
- UI：界面
- ICON：图标
- EFFECT：特效
- CONCEPT：概念图
- KEYART：关键艺术图
```

## 十一、关键禁忌（绝对避免）

### 11.1 视觉禁忌

| 禁忌 | 原因 |
|------|------|
| ❌ **网红脸、锥子脸、大眼萌** | 时代不符、气质不符 |
| ❌ **肌肉猛男、铠甲闪耀** | 不符合士族审美 |
| ❌ **浓妆艳抹** | 不符合南北朝审美 |
| ❌ **网红滤镜、高饱和度** | 不符合水墨意境 |
| ❌ **日韩风、欧美奇幻** | 不是中国古典 |
| ❌ **二次元、卡通化、Q版** | 不符合历史题材 |
| ❌ **现代元素（眼镜、手机等）** | 时代穿越 |
| ❌ **唐代以后的服饰元素** | 时代超限 |
| ❌ **网红表情包风格** | 破坏沉浸感 |

### 11.2 时代准确性禁忌

| 元素 | 错误 | 正确 |
|------|------|------|
| **茶** | ❌ 唐代煎茶 | ✅ 魏晋煮茶（早期） |
| **椅子** | ❌ 高椅（宋代后普及） | ✅ 席地而坐、矮榻 |
| **纸张** | ❌ 唐式纸张 | ✅ 早期麻纸、帛书 |
| **瓷器** | ❌ 青花瓷（元代） | ✅ 早期青瓷 |
| **发型** | ❌ 唐代高髻 | ✅ 魏晋低髻、束发 |
| **建筑** | ❌ 飞檐斗拱（成熟期） | ✅ 早期斗拱、平直 |

### 11.3 文化敏感性禁忌

| 禁忌 | 原因 |
|------|------|
| ❌ **戏说历史人物、丑化历史人物** | 历史敏感性 |
| ❌ **违背基本史实** | 历史考据要求 |
| ❌ **宗教符号错乱** | 佛道元素需准确 |
| ❌ **民族符号错乱** | 胡汉服饰需准确 |
