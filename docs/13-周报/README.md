# 13-周报

本目录存放个人/团队周报。

## 文件命名规范

```
YYYY-WXX_角色.md
```

例如：
- `2026-W37_主程.md`
- `2026-W37_策划.md`
- `2026-W37_团队.md`（整体周报）

## 个人周报模板

```markdown
# YYYY-WXX XX（角色）周报

## 本周完成
- [x] 任务1
- [x] 任务2
- [x] 任务3

## 下周计划
- [ ] 任务A
- [ ] 任务B
- [ ] 任务C

## 风险与问题
1. 问题1
   - 现状：
   - 影响：
   - 需要支持：

2. 问题2
   - 现状：
   - 影响：
   - 需要支持：

## 学习与分享
- 学习内容
- 分享内容

## 数据指标（如适用）
- 完成率：X%
- Bug数：X
- 测试覆盖率：X%
```

```markdown
# YYYY-WXX 团队周报

## 本周亮点

2. 重点2

- 本周Bug：X 个
- 测试覆盖率：X%
```
