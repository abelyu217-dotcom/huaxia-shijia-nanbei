# 《家业-南北篇》自建家族称王/称帝设计

**文档定位**：补充设计盲点 - 自建家族的"帝王之路"
**版本**：v1.0
**日期**：2026-09-07

---

## 〇、设计背景与问题

### 之前的盲点

之前的文档体系已经覆盖了：
- ✅ 预设家族（王、谢、桓）的门阀剧本
- ✅ 自建家族（次级门阀）的晋升剧本
- ✅ 自建家族的文化/武将/隐居路线

**但缺少一条关键路线**：**割据 → 称王 → 称帝**

这是设计盲点，因为：
1. **魏晋南北朝是中国历史上"称王称帝最频繁"的时期**
   - 短短369年间：魏→晋→宋→齐→梁→陈 五次禅代
   - 五胡十六国 + 北朝：超过20个政权
2. **玩家情感的必然要求**
   - "从门阀到帝王"是史诗感的核心
   - 《十字军之王》的核心吸引力就是"建立王朝"
3. **历史逻辑的必然延伸**
   - 既然允许玩家"建立藩镇"，就必然允许"称王"
   - 既然允许"称王"，就必然允许"称帝"

### 本文的设计目标

1. **提供完整的"帝王之路"**：从门阀基础 → 权臣 → 势力 → 称王 → 称帝
2. **遵循历史逻辑**：不是无门槛称帝，而是严密的五阶段路线
3. **多结局设计**：成功 / 失败 / 藩镇 / 权臣身退 / 多代积累
4. **与历史剧本融合**：玩家可以与历史人物竞争或合作

## 一、设计目标与哲学

### 1.1 三大设计目标

| 目标 | 内容 |
|------|------|
| **史诗感** | 让玩家体验"从寒门到帝王"的完整王朝建立过程 |
| **历史感** | 严格遵循魏晋南北朝的政治逻辑（不是无门槛称帝） |
| **多结局** | 可以成功、可以失败、可以选择不称帝、可以藩镇割据 |

### 1.2 核心哲学

> **"门阀是开局，帝王是结局。但帝王不是终点——开创、传承、守成、衰亡，才是一个王朝的完整史诗。"**

### 1.3 与现有系统的关系

```
家族系统 → 基础
关系系统 → 政治资本
经济系统 → 势力基础
文化系统 → 舆论
军事系统 → 武力基础
派系系统 → 政治基础
时间轴系统 → 多代积累
事件系统 → 称帝剧本
```

## 二、魏晋南北朝"称王称帝"的史实逻辑

### 2.1 五次禅代的总览

| 朝代 | 篡位者 | 原职 | 建立年份 |
|------|--------|------|---------|
| 曹魏 | 司马炎 | 太傅、相国、晋王 | 265年 |
| 刘宋 | 刘裕 | 相国、宋王 | 420年 |
| 萧齐 | 萧道成 | 骠骑大将军、齐王 | 479年 |
| 萧梁 | 萧衍 | 大司马、豫章王 | 502年 |
| 陈陈 | 陈霸先 | 司空、陈王 | 557年 |

**共同规律**：
1. 全是**权臣**出身
2. 全是**藩镇**起家
3. 全是**封王**之后
4. 全是**禅让**（或被禅让）
5. 至少需要**数十年**积累

### 2.2 司马氏代魏：典型剧本

```
阶段1：司马懿（151-251）
 - 发动高平陵之变，掌握曹魏大权
 - 奠定司马氏崛起的基础

阶段2：司马师（208-255）
 - 巩固权力，平定叛乱（毋丘俭之乱）
 - 进一步削弱曹魏皇室

阶段3：司马昭（211-265）
 - "司马昭之心，路人皆知"
 - 灭蜀汉（263年），立下不世之功

阶段4：司马炎（236-290）
 - 受封晋王
 - 265年逼曹奂禅让，建立晋朝
```

**关键节点**：
- 高平陵之变（249年）→ 权力基础
- 灭蜀汉（263年）→ 不世之功
- 受九锡 → 禅让前奏
- 265年禅代 → 建立新朝

### 2.3 刘裕代晋：寒门逆袭典范

```
起点：贫寒（卖草鞋的刘备同款）

阶段1：刘牢之（？-402）
 - 北府兵名将
 - 镇压孙恩卢循起义

阶段2：刘裕（363-422）
 - 北府兵出身，南征北战
 - 灭南燕（410年）
 - 灭后秦（417年）
 - 收复长安

阶段3：积累功业
 - 受封宋王
 - 420年禅代，建立刘宋
```

**关键启示**：
- 寒门可以通过军功崛起
- 但仍需要门阀社会的认可
- 刘裕最终仍要"禅让"以获得合法性

### 2.4 北朝特殊路径：胡汉融合

```
拓跋珪（371-409）
 - 代国遗民，建立北魏（386年）

拓跋焘（408-452）
 - 灭北凉，统一北方
 - 受佛教影响（后灭佛）

拓跋宏（467-499）
 - 孝文帝改革（汉化）
 - 迁都洛阳、改姓、说汉话

分裂 → 东魏/西魏 → 北齐/北周 → 隋朝
```

**启示**：
- 北朝是另一条路径（胡汉融合）
- 玩家可以选择"汉化"或"保持胡俗"
- 北朝的"称帝"门槛与南朝不同

## 四、各阶段详细机制设计

### 4.1 阶段1：门阀基础（0-30年）

#### 目标
建立家族根基

#### 核心任务
- 培养3-5位有出仕资格的族人
- 经营田庄、积累财富
- 与顶级门阀建立联姻
- 参与重大历史事件（如衣冠南渡）

#### 关键属性
- 家族品级 ≥ 3品
- 文化成就 ≥ 3项
- 田庄 ≥ 2个

#### 失败风险
- 家族被顶级门阀吞并
- 重大决策错误导致降品
- 继承人危机

### 4.2 阶段2：权臣之路（30-50年）

#### 目标
成为朝廷重臣

#### 核心任务
- 出任九卿、尚书级别官职
- 与皇帝建立关系（不一定亲密）
- 在派系斗争中站队胜利
- 培养下一代继承人

#### 关键机制

**派系选择系统**：
- 皇党 vs 后党 vs 外戚 vs 门阀党 vs 北伐派

**政治资本**：
- 皇帝的"信任度"
- 朝中支持者数量

**派系站队**：
- 每个大事件都需要选择派系
- 站队错误可能身死族灭

#### 触发条件
- 担任过 ≥ 2个核心官职
- 家族品级 ≥ 2品
- ≥ 3名族人在朝中任职

### 4.3 阶段3：势力建立（50-80年）

#### 目标
建立自己的势力范围

#### 核心任务
- 获得地方长官职务（刺史、太守）
- 在任地建立自己的势力网络
- 培养私人部曲
- 与地方豪族建立联姻或结盟

#### 关键机制

**藩镇系统**：
- 玩家作为地方长官，可以经营自己的"根据地"
- 地方长官拥有独立的人事、财政、军事权

**部曲扩张**：
- 从家族部曲 → 私人军队 → 独立势力
- 数量、装备、训练度影响战斗力

**豪族网络**：
- 与地方豪族联姻、结盟、施压
- 豪族支持度决定地方控制力

#### 触发条件
- 担任过 ≥ 2个地方长官
- 私人部曲 ≥ 1000人
- ≥ 5个地方豪族支持

### 4.4 阶段4：称王之路（80-100年）

#### 目标
受封王爵（魏王、晋王、宋王等）

#### 核心任务
- 立下**巨大功业**（灭国、平叛、北伐）
- 收买朝廷重臣
- 清除反对势力
- 获得"九锡"（九种器物的赏赐，是禅让前的最后一步）

#### 关键机制

**功业系统**（分等级）：
- 一等功业：灭一国（如刘裕灭南燕）
- 二等功业：击退强敌（如淝水之战）
- 三等功业：镇压叛乱
- 四等功业：讨伐蛮夷

**九锡系统**：
受九锡 = 离皇位一步之遥
九锡包括：
1. 车马（象征出行）
2. 衣服（象征荣耀）
3. 乐器（象征教化）
4. 朱户（红门，象征特权）
5. 纳陛（可以走的台阶，象征尊崇）
6. 虎贲（300名勇士，象征武力）
7. 弓矢（红色弓箭，象征征伐）
8. 斧钺（象征刑罚）
9. 秬鬯（祭祀用的酒，象征祭祀）

**舆论系统**：
- 清议（名士评价）
- 玄谈（文化圈评价）
- 民间声望（百姓评价）

#### 触发条件
- 立下一等功业 ≥ 1次
- 受九锡（必须）
- 朝中支持者 ≥ 70%

### 4.5 阶段5：禅让称帝（100-120年）

#### 目标
建立新王朝

#### 核心任务
- 逼迫前朝皇帝禅让
- 镇压反对势力
- 举行禅让大典
- 建立新王朝（国号、年号）

#### 关键机制

**禅让大典**：
仪式化呈现：
1. 群臣劝进（演戏般的"劝进"）
2. 前朝皇帝"自愿"禅让
3. 三次推让（假意推辞）
4. 最终接受，建立新朝
5. 改元、大赦、封赏

**反对势力**：
必须清除或妥协：
- 前朝皇族（必须清除）
- 反对派大臣（必须镇压）
- 地方叛乱（必须平定）
- 异己势力（必须怀柔或消灭）

**新王朝系统**：
- 独立的国号、年号
- 独立的官制
- 独立的宗庙、社稷

#### 触发条件
- 受九锡 ≥ 6个月
- 朝中支持者 ≥ 90%
- 军事力量占绝对优势
- 前朝皇帝昏庸或年幼（**重要**）

## 五、称帝路径与条件（详细数值化）

### 5.1 关键指标（必须全部满足）

| 指标 | 阈值 | 说明 |
|------|------|------|
| **家族品级** | 1品 | 必须顶级门阀 |
| **当朝官职** | 相国/太傅/大将军 | 三公级别 |
| **爵位** | 郡公 → 王 | 必须封王 |
| **功业** | 一等 ≥ 1次 | 灭国级 |
| **九锡** | 已受 | 必须受九锡 |
| **朝中支持** | ≥ 80% | 朝廷大臣支持率 |
| **军事力量** | 占全国 ≥ 50% | 掌握军权 |
| **皇帝状态** | 昏庸/幼年/孤寡 | 容易禅代 |
| **继承人** | ≥ 2位成年 | 确保王朝延续 |
| **舆论** | "天命在我" | 清议支持 |

### 5.2 禅让路线选择

#### 路线A：和平禅让

**条件**：
- 皇帝识时务
- 朝中无人反对
- 民心所向

**过程**：
- 皇帝"自愿"禅让
- 大臣"劝进"
- 三让三辞（演戏）
- 正式登基

**风险**：低
**范例**：曹丕代汉、司马炎代魏

#### 路线B：武力禅让

**条件**：
- 皇帝不愿禅让
- 但无力反抗
- 玩家军事占优

**过程**：
- 军事威胁
- 逼迫禅让
- 清除异己

**风险**：中
**范例**：刘裕代晋、萧道成代宋

#### 路线C：自立为帝

**条件**：
- 皇室已绝
- 地方割据
- 中央权威崩溃

**过程**：
- 直接称帝
- 不用禅让
- 自立为开国皇帝

**风险**：高
**范例**：五胡十六国各国君主

#### 路线D：被拥立为帝

**条件**：
- 朝中大臣"拥立"
- 皇帝暴毙或被废
- 玩家威望极高

**过程**：
- 群臣拥立
- 假装推辞
- 最终接受

**风险**：中（可能被当成傀儡）
**范例**：唐高祖李渊

### 5.3 关键指标的数值化公式

```
称帝条件检查函数：
function check_emperor_conditions(family):
    return (
        family.rank >= 1 and                    # 1品
        family.office in ["太傅", "相国", "大将军"] and
        family.princely_title is not None and    # 已封王
        family.merits.count("first_class") >= 1 and
        family.nine_bestowals == true and
        family.court_support >= 0.8 and
        family.military_control >= 0.5 and
        current_emperor.status in ["昏庸", "幼年", "孤寡"] and
        len(family.heirs_adult) >= 2 and
        family.public_opinion >= 0.7
    )
```

## 六、多结局设计（自建家族完整结局树）

### 6.1 结局1：成功建立王朝

```
条件：全部条件满足 + 禅让成功
结果：建立新王朝

变体：
  - 强盛王朝（继承良好 + 国运昌盛）
  - 普通王朝（平稳过渡）
  - 短命王朝（继承危机）

描述："陈氏历经数代积累，从次级门阀崛起，
      最终登上九五之尊，建立新的王朝。
      史称'陈氏王朝'，延续XXX年。"
```

### 6.2 结局2：称帝失败身死

```
条件：强行称帝但被镇压
结果：身死族灭

描述："陈氏急于称帝，但时机未到。
      反抗势力联合镇压，陈氏满门抄斩。
      史书评价：'陈氏之乱'。"
```

### 6.3 结局3：藩镇割据（称王不称帝）

```
条件：受封王爵，但未称帝
结果：建立独立藩镇

描述："陈氏受封XX王，建立自己的藩镇，
      实际独立于中央，但名义上仍尊皇帝。
      这是长期割据的开始。"
```

### 6.4 结局4：权臣身退

```
条件：成为权臣，但选择不称帝
结果：功成身退，家族延续

描述："陈氏辅政多年，但选择急流勇退。
      家族保留门阀地位，长盛不衰。
      世称'知机'。"
```

### 6.5 结局5：多代积累失败

```
条件：单代积累不足，靠多代
结果：第N代继承人最终成功（或失败）

描述：见具体剧本
```

### 6.6 结局6：王朝覆灭

```
条件：成功建立王朝但迅速覆灭
结果：王朝短命

范例：陈氏建立王朝 → 继承人昏庸 → 5代而亡

描述："陈氏虽建立王朝，但继承者多昏庸。
      王朝仅传X代，便被其他权臣取代。
      史称'昙花一现'。"
```

### 6.7 结局概率分布

| 结局 | 概率 | 触发条件 |
|------|------|---------|
| 成功建立王朝 | 15-20% | 全部条件 + 运气好 |
| 藩镇割据 | 20-25% | 受封王但选择不称帝 |
| 权臣身退 | 20-25% | 玩家主动选择 |
| 称帝失败身死 | 10-15% | 强行称帝 |
| 多代积累 | 10-15% | 单代不够 |
| 王朝覆灭 | 5-10% | 建立后衰败 |
| 其他结局 | 5-10% | - |

## 七、与历史剧本的融合设计

### 7.1 历史剧本与自建剧本的并行

```
历史剧本（王、谢、桓）
  按真实历史演绎
    ↓
  同时提供"剧情节点"给自建家族
    ↓
自建剧本（玩家家族）
  按历史事件穿插
    ↓
  与历史人物互动
```

### 7.2 历史剧本的关键节点

| 历史节点 | 自建家族可参与方式 |
|---------|------------------|
| **王敦之乱**（322-324） | 支持王敦 / 支持朝廷 / 中立观望 |
| **苏峻之乱**（327-329） | 参与平叛 / 趁机扩张 / 观望 |
| **桓温北伐**（354-369） | 随军北伐 / 资助后勤 / 阻挠北伐 |
| **淝水之战**（383） | 派武将参战 / 资助后勤 / 旁观 |
| **桓玄篡位**（403-404） | 支持桓玄 / 反对桓玄 / 趁机自立 |
| **刘裕崛起**（408-420） | 与刘裕合作 / 与刘裕对抗 / 竞争 |

### 7.3 替代历史人物的玩法

玩家可以选择：

- **成为"第二个桓温"**（权臣路线）
  - 学习桓温的枭雄之路
  - 但可选择不同的结局

- **成为"第二个刘裕"**（武将路线）
  - 学习刘裕的寒门逆袭
  - 通过军功崛起

- **成为"第二个司马氏"**（世族路线）
  - 学习司马氏的多代积累
  - 通过文化+政治崛起

- **成为"第二个拓跋氏"**（胡汉路线，仅北朝）
  - 走胡汉融合之路
  - 北朝特有的剧本

- **成为"开创新历史"**（创新路线）
  - 完全自创的剧本
  - 不跟随任何历史模板

### 7.4 历史剧本与自建剧本的冲突处理

**场景**：玩家想称帝，但历史剧本要求桓玄代晋

```
情况A：玩家早于桓玄称帝
 - 玩家家族成为"刘裕+桓玄的合体"
 - 桓玄篡位剧本被替换
 - 历史剧本进入"分支A"
 - 历史评价：玩家改变了历史

情况B：玩家晚于桓玄称帝
 - 玩家可以取代刘裕
 - 刘裕崛起剧本被替换
 - 历史剧本进入"分支B"
 - 历史评价：玩家接替了刘裕的位置

情况C：玩家与桓玄/刘裕竞争
 - 玩家与历史人物对峙
 - 双线剧本展开
 - 历史评价：多方竞争

情况D：玩家选择不称帝
 - 历史剧本按原轨迹进行
 - 玩家作为旁观者或参与者
 - 历史评价：玩家选择了稳健路线
```

### 7.5 北朝剧本的特殊设计

北朝玩家可选择：

- **汉化路线**（如孝文帝）
  - 全盘汉化
  - 改姓、说汉话、与汉族通婚
  - 与南朝争夺华夏正统

- **胡化路线**（如某些北朝君主）
  - 保持胡俗
  - 维护胡族传统
  - 民族身份认同

- **胡汉融合路线**
  - 选择性汉化
  - 保留部分胡俗
  - 建立多元文化王朝

## 八、风险与平衡设计

### 8.1 五大风险机制

| 风险 | 触发条件 | 后果 |
|------|---------|------|
| **称帝失败身死** | 称帝条件未满足强行称帝 | 身死族灭 |
| **继承人危机** | 继承人不肖/无后 | 王朝覆灭 |
| **权臣反噬** | 朝中反对派联合 | 政变失败 |
| **地方叛乱** | 地方豪族不满 | 战乱四起 |
| **外敌入侵** | 北伐/南征时机错误 | 功亏一篑 |

### 8.2 平衡性原则

#### 原则1：称帝难度

- **普通难度**：5-7代积累
- **困难难度**：10-15代积累
- **极难**：需要多支线同时成功

#### 原则2：成功率

- 满足全部条件：70-80%成功率
- 部分条件：30-50%
- 强行称帝：10-20%

#### 原则3：风险收益

- 称帝成功：游戏可继续（新王朝模式）
- 称帝失败：游戏失败，需要读档

### 8.3 反作弊机制

```
1. 品级限制
 - 未达1品禁止触发称帝剧本
 - 未达2品禁止触发"称王"剧本

2. 功业要求
 - 无巨大功业禁止触发
 - 功业必须是真实积累（非刷）

3. 继承人要求
 - 无继承人禁止触发
 - 必须有 ≥ 2位成年继承人

4. 舆论限制
 - "天命不在我"禁止触发
 - 必须有"天命在我"的舆论基础

6. 皇帝状态
 - 皇帝英明时强行称帝难度+100%
 - 皇帝昏庸时难度-50%
```

### 8.4 平衡性参数表

| 参数 | 数值 | 说明 |
|------|------|------|
| **称帝最低代数** | 3代 | 防止过快 |
| **称王最低代数** | 2代 | 防止过快 |
| **受九锡难度** | 80 | 0-100难度值 |
| **禅让成功率** | 70% | 全部条件满足 |
| **强行称帝成功率** | 10-20% | 未满足条件 |
| **王朝寿命均值** | 50-100年 | NPC王朝 |
| **玩家王朝寿命** | 视决策 | 由玩家决定 |

## 十、关键决策点（玩家实际遇到的选择）

### 决策1：派系选择（开局）

```
选项A：加入王导阵营
 - 优势：稳健、获主流支持
 - 劣势：发展慢

选项B：加入庾亮阵营
 - 优势：与皇族亲近
 - 劣势：得罪王导一系

选项C：观望，等待局势明朗
 - 优势：安全
 - 劣势：错过早期红利

选项D：投靠北伐派（桓温）
 - 优势：可能快速崛起
 - 劣势：被主流猜忌
```

### 决策2：是否参与王敦之乱

```
选项A：支持王敦
 - 风险：王敦可能失败
 - 收益：王敦成功则家族崛起

选项B：支持朝廷
 - 风险：被王敦报复
 - 收益：被朝廷信任

选项C：保持中立
 - 风险：双方都不信任
 - 收益：安全

选项D：两面下注
 - 风险：被发现则身死
 - 收益：无论谁胜都有利
```

### 决策3：是否参与淝水之战

```
选项A：派家族武将参战
 - 风险：武将战死
 - 收益：立下大功

选项B：资助后勤
 - 风险：可能被敌国报复
 - 收益：经济回报

选项C：观望
 - 风险：战后清算
 - 收益：保存实力

选项D：暗中与前秦联络
 - 风险：被发现则身死族灭
 - 收益：可能获得更大利益
```

### 决策4：是否支持桓玄篡位

```
选项A：支持桓玄
 - 风险：可能被刘裕清算
 - 收益：可能成为新朝重臣

选项B：反对桓玄
 - 风险：被桓玄镇压
 - 收益：被刘裕信任

选项C：趁乱自立
 - 风险：腹背受敌
 - 收益：可能开创新朝

选项D：旁观，等待时机
 - 风险：错过机会
 - 收益：安全观望
```

### 决策5：是否称帝（最终决策）

```
选项A：等待时机（继续积累）
 - 风险：错过机会或被人抢先
 - 收益：成功率更高

选项B：武力胁迫禅让
 - 风险：可能引发战争
 - 收益：快速登顶

选项C：自立为帝
 - 风险：合法性受质疑
 - 收益：完全自主

选项D：放弃称帝计划
 - 风险：功亏一篑
 - 收益：家族安全传承

选项E：让儿子称帝，自己做太上皇
 - 风险：被儿子架空
 - 收益：避免直接承担风险
```

### 11.1 设计的优劣势

#### 优势
- ✅ 严格遵循历史逻辑
- ✅ 提供完整的"帝王之路"

- 只实现"称王"分支

- 提供1-2个"称王"剧本示例

## 十三、最终建议

### 13.1 MVP优先级

如果时间/资源有限，建议MVP按以下顺序实现：

1. **门阀基础 → 顶级门阀**（阶段1）
   - 这是大部分玩家能达到的
   - 提供完整的游戏循环

2. **权臣之路**（阶段2）
   - 让玩家体验"进入权力核心"
   - 与历史人物互动

3. **势力建立**（阶段3）
   - 独立的藩镇系统
   - 提供"称王"的可能性

4. **称王 + 称帝**（阶段4-5）
   - 这是后期DLC内容
   - 完善长线游戏价值

### 13.2 设计哲学总结

> **"门阀是开局，权臣是过程，帝王是结局。但更重要的是玩家在这个过程中的情感体验。"**

设计目标不是"让所有玩家都能称帝"，而是：
- 让玩家**体验**称帝的艰辛
- 让玩家**理解**门阀政治
- 让玩家**感受**魏晋风度
- 让玩家**传承**自己的家族
