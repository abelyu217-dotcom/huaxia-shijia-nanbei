## 一、开发启动的5个核心决策

### 决策1：技术选型

**已确定**：Godot 4.3 LTS

```
为什么Godot？
 - 开源免费（成本0）
 - 2D能力强（符合需求）
 - 体积小（几十MB vs Unity几个GB）
 - 学习曲线短（1-2周 vs Unity 1-3月）
 - 跨平台（Windows/Mac/Linux/Web）
```

**配套技术栈**：

| 层级 | 技术 | 备注 |
|------|------|------|
| **引擎** | Godot 4.3 LTS | 主开发环境 |
| **脚本语言** | GDScript + C# | GDScript主写，C#性能关键 |
| **数据存储** | JSON → SQLite | 开发期JSON，发布期SQLite |
| **版本控制** | Git + GitHub | 主仓库 |
| **CI/CD** | GitHub Actions | 自动化构建 |
| **IDE** | VSCode + Godot Tools | 推荐组合 |
| **美术** | Aseprite + Krita | 像素/位图 |
| **音频** | Audacity | 音频编辑 |
| **文档** | Markdown + Notion | 文档协作 |

### 决策2：MVP范围

**已确定**：东晋103年（317-420年）

**MVP核心交付**：

```
✅ 1个时代（东晋）
✅ 3个预设家族（王、谢、桓）
✅ 5个核心场景（家族建立/单回合/联姻/清谈/淝水之战）
✅ 30-60分钟可玩Demo
✅ 黑白线稿 + 关键水墨
✅ 5个核心UI屏幕
```

**MVP不做**：

```
❌ 24个时代
❌ 200+家族
❌ 完整经济系统
❌ 完整战争系统
❌ 联机功能
❌ 完整美术
❌ 北朝剧本
❌ 女性视角
```

### 决策3：团队规模

**已确定**：MVP阶段 3 人（含外包）

```
核心团队（3人）：
 1. 主程（Godot开发 + 数据架构）
 2. 策划/UI（数值 + UI设计 + 测试）
 3. 美术外包（兼职，黑白线稿）

扩展期（5-7人）：
 + 客户端开发（UI系统）
 + 测试工程师
 + 编剧（剧本）
```

### 决策4：预算

**已确定**：MVP ¥10万

```
预算分配：
 - 程序员 3个月：¥4.5万
 - 策划 3个月：¥3万

 - 其他（工具、服务器等）：¥1万

完整版（参考）：

```

### 决策5：时间

**已确定**：MVP 3-4个月（23周）

W1-2: Godot搭建

## 十、风险预案（10大风险）

### 风险1：招不到合适的主程

**等级**：🔴 高
**应对**：
- 优先招聘接受Godot学习的候选人
- 接受Unity开发者转Godot
- 外包主程（按项目计费）
- 与Godot官方培训机构合作

### 风险2：核心循环不成立

**等级**：🔴 高
**应对**：
- 早期Playtest（10人测试）
- 每周迭代反馈
- 准备"备用循环"（参考已有游戏）
- 接受"砍功能"（不恋战）

### 风险3：美术成本失控

**等级**：🟡 中
**应对**：
- MVP用黑白线稿 + 关键元素水墨
- 严格外包预算
- 美术风格指南严格执行
- 准备好降级方案
