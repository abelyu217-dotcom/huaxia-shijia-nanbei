# 《家业-南北篇》深化概念方案

> **版本**：v1.0 概念方案
> **日期**：2026年9月7日
> **作者**：资深游戏开发团队
> **文档定位**：基于《华夏世家》11份原始策划案的时代聚焦版深化，作为项目立项与开发启动的战略依据

---

## 〇、前言：为何聚焦魏晋南北朝

经过对《华夏世家》原始策划案的系统评估，我们得出的核心判断是：

**魏晋南北朝与"家族传承"玩法的契合度，远高于任何其他历史时期。**

| 维度 | 三国 | 魏晋南北朝 |
|------|------|-----------|
| 玩法契合度 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 文化资本 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 美术空间 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 差异化价值 | 红海 | **蓝海** |
| 长线IP价值 | 高 | **极高** |

本方案在不否定原《华夏世家》整体规划的前提下，**将时代聚焦到魏晋南北朝**，输出可执行的MVP概念方案。

## 一、概念定位（Concept）

### 1.1 游戏命名

- **正式名**：《家业-南北篇》
- **系列名**：《家业》—— 华夏历史家族养成游戏系列首部
- **副标题**：门阀兴衰，世家浮沉
- **Slogan**：演绎属于你的魏晋南北朝家族史诗

> 命名逻辑：
> - "**家业**"：直击"家族传承+家产继承"双重主题，避免"三国X野"式的时代词汇绑架
> - "**南北篇**"：明示时代范围，暗示未来可扩展"隋唐篇""宋元篇"等系列作品
> - 整体品牌感：稳重、有底蕴、有传承感，区别于市面三国SLG的"乱世枭雄"调性

### 1.2 一句话定位

**"以家族为视角，重走369年华夏裂变史——你的选择，决定家族是千古流芳还是湮灭无闻。"**

### 1.3 核心情感锚点

| 锚点 | 内容 | 玩家情感 |
|------|------|---------|
| **家族传承** | 从奠基到延续，每一代人都为下一代铺路 | 责任感、归属感 |
| **文化风度** | 魏晋风度的视觉化、机制化呈现 | 美学享受、文化认同 |
| **历史沉浸** | 让玩家"活过"一个时代 | 时代代入感 |
| **抉择与命运** | 乱世中没有最优解 | 焦虑、共鸣、反思 |

### 1.4 差异化定位

| 维度 | 三国游戏 | 《家业-南北篇》 |
|------|---------|---------------|
| 视角 | 王朝/英雄 | 家族/血脉 |
| 玩法核心 | 攻城略地 | 教养联姻 |
| 情感基调 | 英雄气概 | 世家风度 |
| 文化深度 | 中 | 极深 |
| 时间跨度 | 几十年 | 三百年 |
| 玩家扮演 | 君主/武将 | 家长/族人 |
| 美术风格 | 战场/武将 | 雅集/文人 |
| 音乐风格 | 战鼓/金戈 | 古琴/笛箫 |

## 二、时代背景（Setting）

### 2.1 时代总览

- **时间跨度**：220年（曹丕代汉）— 589年（隋灭陈），共369年
- **核心矛盾**：
  - 胡汉冲突（五胡入华）
  - 南北对峙（南北朝分立）
  - 门阀与皇权博弈
  - 文化思想转型（玄学、佛教兴起）
- **文化基调**：玄学兴盛、清谈成风、佛教东传、艺术突破、士族风度

### 2.2 四大历史阶段

**第一阶段：曹魏西晋（220-317）—— 家族崛起与禅代**

- 关键事件：曹丕代汉、八王之乱、永嘉之乱、衣冠南渡
- 家族玩法核心：军阀家族转型为门阀家族，参与禅代博弈
- 关键词：禅代、权臣、内乱、永嘉

**第二阶段：东晋（317-420）—— 门阀巅峰与北伐**

- 关键事件：王导辅政、苏峻之乱、庾亮专政、桓温北伐、淝水之战、桓玄篡晋、刘裕崛起
- 家族玩法核心：与皇权共治，四大家族轮流坐庄
- 关键词：**清谈、北伐、玄学、兰亭**
- **【推荐作为MVP首发时代】**

**第三阶段：南朝（420-589）—— 文化鼎盛与禅代高频**

- 关键事件：宋齐梁陈更迭、侯景之乱、陈亡
- 家族玩法核心：寒门武将崛起，门阀逐渐式微
- 关键词：禅代、佛教、江南开发、侯景之乱

**第四阶段：北朝（386-581）—— 胡汉融合与汉化**

- 关键事件：北魏统一北方、孝文帝汉化、六镇起义、北周改革、隋代北周
- 家族玩法核心：胡人家族汉化、汉人家族胡化、双线命运
- 关键词：胡化、汉化、双姓、佛教石窟

### 2.3 时间跨度建议

| 版本 | 时代范围 | 时间跨度 | 适合阶段 |
|------|---------|---------|---------|
| **MVP版本** | 东晋 | 317-420（103年） | 阶段0-1 |
| **完整首发** | 东晋+南朝 | 317-589（272年） | 阶段2 |
| **终极版本** | 完整魏晋南北朝 | 220-589（369年） | 长线目标 |

## 四、核心系统设计（Core Systems）

### 4.1 家族系统（最核心）

#### 4.1.1 家族结构

```
家族（最高层）
├── 族长（玩家主控角色）
├── 房支（按兄弟分房，独立发展方向）
│   ├── 长房
│   ├── 次房
│   └── 三房...
├── 族人（按辈分排列）
│   ├── 父辈
│   ├── 同辈
│   └── 子辈
└── 外戚/姻亲（关联家族）
```

#### 4.1.2 家族核心属性

- **门第等级**（1-9品）：九品中正制下的家族地位，**最核心属性**
- **郡望声望**：家族在全国士族中的排名（琅琊王 vs 陈郡谢的声望对比）
- **家学传承**：家族专精的学术/艺术领域（书法、玄学、儒学、佛学）
- **家风偏向**：进取 / 守成 / 中立 / 隐逸
- **经济基础**：田庄规模、矿产、特许经营
- **政治资本**：在朝官员数、与皇帝关系、与权臣关系

#### 4.1.3 家族升级路径

| 路径 | 难度 | 方式 |
|------|------|------|
| **乡品提升** | 中 | 通过族人出仕、战功、文化成就 |
| **郡望升级** | 中高 | 跨地域联姻、获得封爵、迁移 |
| **家族升格** | 极难 | 数代积累 + 关键事件推动 |
| **降等风险** | — | 族人流放、谋反、战败、获罪 |

### 4.2 族人养成系统

#### 4.2.1 族人属性体系

**先天属性**（受父母血统影响）
- 智力、武力、魅力、健康、家世（取决于父母门第）

**后天属性**（可培养）
- **文化类**：清谈、玄学、佛学、儒学、文学、书法、绘画、音乐
- **政治类**：政事、谋略、人际
- **军事类**：武艺、骑射、统兵
- **隐性属性**：家风认同、家族忠诚度

**性格属性**（影响决策倾向）
- 进取/守成、刚直/柔顺、仁慈/冷酷、奢靡/节俭、忠君/野心

#### 4.2.2 九品中正制数值化

| 品级 | 含义 | 玩家家族定位 | 出仕上限 |
|------|------|-------------|---------|
| **一品** | 顶级门阀 | 王、谢、庾、桓、司马 | 可任三公九卿 |
| **二品** | 高级门阀 | 次级门阀 | 可任高官 |
| **三品** | 中级门阀 | 中等家族 | 中层官员 |
| **四品至六品** | 普通士族 | 普通家族 | 基层官员 |
| **七品至九品** | 寒门 | 寒门子弟 | 难以出仕，需战功 |

**机制核心**：
- **高品压制低品**：高品家族对低品有天然压制（出仕机会、联姻对象）
- **联姻门第限制**：门不当户不对的联姻有惩罚
- **降品危机**：重大过失可导致家族降品（极难恢复）

#### 4.2.3 培养路径（5条）

| 路径 | 关键技能 | 典型人物原型 |
|------|---------|------------|
| **文化名士路线** | 清谈+玄学+文学 | 阮籍、嵇康、王羲之 |
| **政治名臣路线** | 政事+人际+儒学 | 王导、谢安 |
| **军事统帅路线** | 武艺+统兵+骑射 | 谢玄、桓温、刘裕 |
| **艺术宗师路线** | 书法+绘画+文学 | 王羲之、顾恺之 |
| **隐逸高士路线** | 玄学/佛学+清谈+道家 | 陶渊明、慧远 |

### 4.3 联姻外交系统

#### 4.3.1 联姻机制

**门当户对约束**（核心规则）
- 高品家族"下嫁"低品家族：损失声望但获得武将或政治支持
- 低品家族"高攀"高品家族：获得声望但需付出代价
- 同级联姻：相对平稳

**联姻类型**
| 类型 | 利益 | 风险 |
|------|------|------|
| **政治联姻**（与皇室/顶级门阀） | 极高政治资本 | 绑定命运、被迫站队 |
| **门阀联姻**（同级门阀） | 巩固地位、声望提升 | 卷入对方派系斗争 |
| **寒门联姻** | 获得武将资源 | 声望下降、门第污染 |
| **跨地域联姻** | 拓展人脉 | 距离管理困难 |

#### 4.3.2 外交矩阵

- 同盟关系：共同应对威胁
- 敌对关系：争夺利益
- 中立关系：观望
- 姻亲关系：复杂博弈
- 朝贡关系：地方势力对中央

### 4.4 势力与政治系统

#### 4.4.1 三层政治结构

```
皇帝（皇权）—— 弱势，依赖门阀支持
    ↓
门阀（相权/权臣）—— 实际政治主导
    ↓
寒门/百姓（基层）—— 武将/学者来源
```

#### 4.4.2 朝堂玩法

- **派系站队**：主战派 / 主和派 / 清流派 / 务实派 / 隐逸派
- **官职升迁**：从属吏 → 郎官 → 朝官 → 三公九卿
- **权力斗争**：弹劾、政变、禅代
- **北伐决策**：决定是否参与北伐，影响极大
- **废立皇帝**：在权臣路线下可发动废立

### 4.5 经济系统

#### 4.5.1 田庄经济（核心）

- **田庄类型**：自耕田、佃户田、屯田、园林、矿山
- **产出**：粮食、丝绸、瓷器、漆器、纸墨
- **经营机制**：招佃户、修水利、抗灾荒、土地买卖
- **特殊经济**：依附人口（部曲、佃客）的人身依附

#### 4.5.2 文化商品化（差异化）

- **书画交易**：家族艺术品的市场流通与赞助
- **教育产业**：家族私塾招生（培养寒门子弟换人脉）
- **文化赞助**：赞助玄学聚会、清谈雅集换声望
- **寺院经济**（南朝）：与佛寺合作经营土地

### 4.6 文化系统（**核心差异化**）

#### 4.6.1 魏晋风度可视化

**视觉系统**：
- 宽衣博带、飘逸风度的服饰
- 清瘦有骨的人物造型
- 扪虱而谈、醉卧山林的姿态

**互动系统**：
- **清谈系统**：选择议题、组队辩手、声望结算
- **雅集系统**：兰亭集会、竹林七贤聚会
- **佛道互动**：与高僧道士论道

#### 4.6.2 玄佛选择机制

| 路线 | 核心收益 | 核心代价 |
|------|---------|---------|
| **玄学路线** | 文化声望、与名士结交 | 远离实务、政权参与度低 |
| **佛教路线** | 寺院经济、信仰声望 | 出家人不婚不育（血脉风险） |
| **儒家路线** | 政治资本、务实治国 | 文化声望偏低 |
| **混合路线** | 灵活适应 | 路线摇摆代价 |

#### 4.6.3 文化艺术机制

- **书法系统**：书法造诣影响家族声望，可临摹/创作
- **绘画系统**：绘画交易产生文化资本
- **诗歌系统**：诗歌创作参与文学雅集
- **音乐系统**：古琴、笛箫等乐器技能

### 4.7 战争系统

#### 4.7.1 核心战役

| 战役 | 时间 | 玩家参与方式 |
|------|------|------------|
| **淝水之战** | 383年 | 标志性大事件，多结局 |
| **桓温北伐** | 354-369 | 三次北伐，难度递增 |
| **刘裕北伐** | 409-417 | 灭南燕、后秦，枭雄路线 |
| **侯景之乱** | 548-552 | 南朝转折点，破坏极大 |
| **八王之乱** | 291-306 | 早期家族内斗 |
| **永嘉之乱** | 311 | 衣冠南渡触发事件 |

#### 4.7.2 战争机制

- **战略层**：是否参战、投入多少资源
- **战术层**：阵法选择、兵力配置、将领调度
- **结局层**：胜利→家族声望暴涨；失败→家族可能衰败
- **武将系统**：培养专属家族武将（区别于门阀玩法）

### 4.8 时代跨越系统（长线玩法）

当家族延续跨越朝代时：
- **家风延续**：家族传统在时代变迁中的保留或转型
- **门第变迁**：从顶级门阀到衰落门阀的剧情张力
- **跨时代大事件**：如"南北朝终结→隋朝统一"作为长线结局

## 五、玩家开局设计（Opening）

### 5.1 开局时代选择

| 选项 | 时代 | 难度 | 玩法定位 |
|------|------|------|---------|
| **A. 曹魏末年** | 260年 | ⭐⭐⭐⭐ | 八王之乱前夕，军阀转型 |
| **B. 东晋初年** | 317年 | ⭐⭐⭐ | 衣冠南渡，参与建立东晋 |
| **C. 东晋中期** | 357年 | ⭐⭐⭐⭐ | 桓温专政前，权力斗争 |
| **D. 刘宋初年** | 420年 | ⭐⭐⭐⭐⭐ | 寒门武将崛起时代，逆袭路线 |
| **E. 北魏中期** | 471年 | ⭐⭐⭐⭐ | 孝文帝汉化，胡人家族视角 |

**推荐默认**：**B. 东晋初年（317年）**——最具史诗感、最适合做核心叙事

### 5.2 开局家族选择（核心六族）

| 家族 | 品级 | 优势 | 难度 | 玩法定位 |
|------|------|------|------|---------|
| **琅琊王氏** | 一品 | 文官优势、文化资源、王羲之传承 | 中 | 守成名门路线 |

## 十、技术与开发建议（Tech Notes）

### 10.1 技术选型建议

| 维度 | 推荐方案 | 理由 |
|------|---------|------|
| **引擎** | **Godot 4** 或 Unity 2D | 适合回合制策略，开发效率高 |
| **数据库** | SQLite（单机）/ PostgreSQL（联机） | 族谱数据管理 |
| **UI框架** | 自研（水墨风格定制） | 避免通用UI风格 |
| **存档机制** | 分代存档 + 跨代继承 | 应对长跨度叙事 |
| **AI系统** | 行为树 + 效用AI（不用ML） | 稳定可控 |

**重要建议**：放弃3D，专注2D。理由——
- 美术成本大幅降低
- 性能优化更简单
- 适合回合制策略的呈现
- 与水墨/工笔美术风格更契合

### 10.2 开发重点难点

| 模块 | 难度 | 应对 |
|------|------|------|
| **族谱系统** | 中 | 数据库设计要稳定可靠 |
| **时间轴系统** | 高 | 369年跨度的世代管理需专门设计 |
| **AI家族系统** | 高 | 20-30个NPC家族的行为逻辑 |
| **历史事件触发器** | 中 | 50+核心事件的剧本管理 |
| **文化系统机制化** | 高 | 清谈、玄学、书画的玩法化设计 |

## 十二、风险评估与对策（Risks）

### 12.1 主要风险矩阵

| 风险 | 等级 | 影响 | 应对策略 |
|------|------|------|---------|
| **大众认知度低** | 🔴 高 | 首发热度可能不足 | 文化IP锚定、影视联动、长线口碑 |
| **Scope过大** | 🟡 中 | 开发延期、超预算 | MVP聚焦东晋、严格控制范围 |
| **AI家族复杂度** | 🟡 中 | 体验差、成本高 | 剧本式AI + 简化决策树 |
| **美术文化门槛** | 🟡 中 | 美术成本失控 | 顶级美术外包 + 风格统一 |
| **市场竞争** | 🟢 低 | 三国红海压力小 | 差异化优势，避实击虚 |
| **团队文化素养** | 🟡 中 | 历史细节出错 | 聘请历史顾问 + 文化考据 |
| **政策合规** | 🟢 低 | 历史题材风险低 | 避免过度戏说、尊重史实 |

### 12.2 关键成功因素（CSF）

1. **美术水准必须达到国产S级**——对冲认知度低的劣势
2. **文化沉浸必须做到极致**——避免变成"三国SLG换皮"
3. **口碑运营必须长期投入**——前6个月靠口碑而非首发热度
4. **与文化IP深度联动**——借势扩大影响力
5. **历史细节的准确性**——赢取核心历史圈的口碑
6. **音乐与音效的文化感**——古琴、笛箫的氛围营造

### 12.3 失败案例警示

避免重蹈以下覆辙：
- **《三国志14》之外的国产三国SLG**：玩法缺乏差异化，被光荣碾压
- **历史题材游戏的"网红脸"角色设计**：被玩家吐槽审美
- **AI家族的"伪智能"**：玩家一眼看穿，体验差
- **Scope过大导致发售延期**：玩家预期疲劳，错过窗口期

## 十三、结语

《家业-南北篇》不是又一款三国游戏的跟随者，而是**基于独特历史时期的差异化创新**。

魏晋南北朝是华夏文明的"分水岭"——既是低谷（乱世、割据），也是高峰（文化、艺术、思想）。这种复杂性为家族养成游戏提供了**前所未有的玩法空间**：

> **一款真正深入中国历史与文化的策略游戏，不应只关注"打天下"，更应关注"传家业"。**

我们的长期愿景是：
> **将《家业》打造为华夏家族养成游戏的标杆品牌，从魏晋南北朝一路延展到隋唐、宋元、明清……**
