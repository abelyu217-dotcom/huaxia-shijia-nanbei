3. 联赛系统：国际 32 / 国内 12 + 升降级

3.1 联赛层级

赛事球队数赛制晋级/降级
国内 L112双循环主客场（22 轮）+ 季后赛前 8后 2 降级到 L2
国内 L212双循环（22 轮）+ 季后赛前 8前 2 升级到 L1
国内杯赛24（L1+L2）单败淘汰冠军获国际外卡资格
国际冠军杯328 组小组赛 → 淘汰赛各国 L1 前 2 + 杯赛冠军 + 外卡

3.2 赛程规则

  • 赛季周期：现实时间 1 天 = 游戏内 1 轮（可配置）。一个完整赛季约 36~40 轮。
  • 国内联赛常规赛：12 队双循环主客场 = 22 轮。每周二、四、六进行（L1 与 L2 同日不同时段）。
  • 季后赛：常规赛前 8 进入季后赛，单败淘汰三局两胜制，共 3 轮（八强→四强→决赛），约 3 周。
  • 国内杯赛：24 队（L1+L2）单败淘汰，穿插在联赛周中（周三），共 5 轮。
  • 国际冠军杯：国内联赛休赛期进行（赛季末 4 周），不与国内赛事冲突。
  • 双线作战排程：同一球队同时参加国内+国际赛事时，系统自动排程避免同日冲突，必要时安排背靠背。

3.3 升降级规则（完整）

升级规则

  1. L2 常规赛前 2 名直接升级到 L1。
  2. L2 季后赛冠军（若不是常规赛前 2）获得升级附加赛资格。
  3. 升级附加赛：L2 季后赛冠军 vs L1 常规赛倒数第 3，三局两胜，胜者留/升 L1。

降级规则

  1. L1 常规赛排名最后 2 名直接降入 L2。
  2. L1 常规赛倒数第 3 名参加降级附加赛（见上）。
  3. 升级/降级在下赛季开赛前完成，球队保留球员与职员，但联赛身份、预算、声望相应调整。

降级连锁效果

  • 球队声望 -15，球迷满意度 -20。
  • 下赛季预算削减 30%，赞助收入下降。
  • 职员士气下降，核心球员可能触发离队条款。
  • 升级则相反：声望 +10，预算提升 25%。

3.4 国际冠军杯资格分配（32 队）

5 国 × L1 冠军    = 5 队（种子队，分入不同小组）
5 国 × L1 亚军    = 5 队
5 国 × 杯赛冠军   = 5 队
外卡（按国际积分排名） = 17 队
─────────────────────────────
合计              = 32 队

赛制：32 队分 8 组（每组 4 队），小组双循环（6 轮），前 2 出线。16 强淘汰赛单败淘汰（中立场），直至决出冠军。

3.5 联赛积分与排名

结果积分说明
胜2 分常规时间获胜
负1 分（若引入加时赛，加时负得 1 分）
负0 分常规时间失利

排名优先级：积分 → 净胜分 → 相互战绩 → 总得分。

4.4 玩法闭环

  1. 经理查看职员市场，雇佣教练组。
  2. 主教练设定战术偏好，影响比赛模拟加成。
  3. 训练师/队医在后台持续影响球员状态（每轮结算）。
  4. 球探派往目标球员，产出探查报告。
  5. 职员士气影响效率；战绩差 → 士气降 → 效率降 → 恶性循环，经理需及时调整。
  6. 玩家的 Professional 身份可应聘某球队岗位，领取薪资 + 积累声望。

5. 经纪人系统

5.1 定位

经纪人是球员与球队之间的中介。每名球员可有一名经纪人（也可无）。经纪人代表球员谈判合同，抽取佣金。

5.2 数据模型

Agent {
  id              String   PK
  name            String
  reputation      Int      0-100（声望越高，能吸引的球员质量越高）
  commissionRate  Float    0.02~0.10（佣金比例）
  specialty       String?  擅长领域（新秀/巨星/国际球员）
  isUserControlled Boolean
  professionalId  String?  FK → Professional（若由玩家担任）
}

AgentContract {
  id          String PK
  agentId     String FK → Agent
  playerId    String FK → Player
  startYear   Int
  endYear     Int
  commissionRate Float
  status      Enum active|expired|terminated
}

5.3 核心接口

方法路径说明
GET/api/agents经纪人列表
GET/api/players/:id/agent球员当前经纪人
POST/api/agents/:id/sign-player经纪人签约球员（玩家 agent 职业）
POST/api/players/:id/negotiate经纪人代表球员发起合同谈判
POST/api/contracts/:id/negotiate经理与经纪人谈判（经纪人提高/降低要价）

5.4 玩法闭环

  1. 球员生成时，AI 经纪人按声望自动分配（或无经纪人）。
  2. 经理签约球员时，若球员有经纪人，需与经纪人谈判（经纪人会加价）。
  3. 经纪人声望越高，要价越强硬，但球员更愿意签约。
  4. 玩家 Professional(agent) 可主动招揽球员为客户，谈判成功抽取佣金。
  5. 经纪人-球员关系随时间变化，球员可在合同到期后更换经纪人。

6.2 关键机制：雇佣打通

Professional.employmentStatus 不再是死字段。玩家职业可通过 /api/professional/:id/employ 受雇于某球队的对应 Staff 岗位，实现"身份 → 岗位"打通。受雇后：

  • 领取球队发放的薪资
  • 执行该岗位的日常行动
  • 战绩/绩效影响续约与声望
  • 可主动辞职或被解雇

6.3 职业独立玩法（无需受雇）

部分职业（经纪人、记者、解说员、商人）无需受雇于球队即可开展业务，自由接单获利。

7. 核心球员定义修正

7.1 定义

核心球员 = 球员化身（Avatar），即玩家自创并控制的球员，以及联盟中其他玩家的化身。它是"人"的概念，不是"队内能力最强"的概念。

7.2 实现

  • CorePlayersPage 改为展示全联盟玩家 Avatar 列表。
  • 支持按球队、国籍、位置、是否自己的化身筛选。
  • 展示化身的控制模式（手动/自动）、成长轨迹、当前球队、赛季数据。
  • 原"OVR Top5"改名为"主力阵容"或"关键球员"，与"核心球员"概念分离。

9.2 家庭成员生成算法

function generateFamily(player):
  members = []
  // 父母（90% 概率双亲，10% 单亲）
  father = { name: randomMaleName(player.nationality), relation: "father",
             age: player.age + 25~35, occupation: randomOccupation() }
  mother = { name: randomFemaleName(player.nationality), relation: "mother",
             age: player.age + 23~33, occupation: randomOccupation() }
  if background == "single_parent":
    members.push(random([father, mother]))  // 只保留一方
  else:
    members.push(father, mother)

  // 兄弟姐妹（40% 概率有 1 个，15% 有 2 个）
  siblingCount = weightedRandom([0:45%, 1:40%, 2:15%])
  for i in 1..siblingCount:
    sibling = { name: randomName(player.nationality), relation: "sibling",
                age: player.age + (-5~+5), occupation: randomOccupation() }
    members.push(sibling)

  // 配偶（仅 28 岁以上球员，60% 概率已婚）
  if player.age >= 28 and random() < 0.6:
    spouse = { name: randomName(player.nationality), relation: "spouse",
               age: player.age + (-3~+3), occupation: randomOccupation() }
    members.push(spouse)

  return members

随机从以下职业中选取：教师、医生、工程师、工人、商人、农民、公务员、自由职业、退休、运动员、教练、家庭主妇。

9.5 家庭背景对球员的连锁影响

  • 属性初始化：按背景类型给予初始属性加成（见 9.1 表）。
  • 性格生成：背景类型影响性格概率分布，如体育世家更易出"勤奋/领袖"型。
  • 潜力值：体育世家 +5 潜力，富裕家庭 +3 人气。
  • 忠诚度：单亲家庭球员忠诚度基因 +10（更珍惜机会）。
  • 故事文本：生成时自动产生一段家庭背景简介，显示在球员档案页。

9.6 与化身的区别

  • 化身：玩家可手动选择家庭背景（不选则随机），家庭成员也可自定义。
  • 普通球员：完全由系统随机生成，玩家不可干预，确保联盟生态多样性。

10.3 综合评分（OVR）计算公式


OVR = Σ(属性权重 × 属性值) / Σ权重

权重按位置差异化：
  PG：passing(0.15) handle(0.15) speed(0.12) threePoint(0.10) drive(0.10) ...
  C ：interiorD(0.15) close(0.15) strength(0.12) block(0.10) rebound...



OVR 范围 0-99，每 5 分一个颜色档位（红/橙/黄/绿/蓝）。



10.4 属性成长机制


    
  
  • 年龄曲线：18-22 岁快速成长期，23-28 巅峰期，29+ 缓慢下降，33+ 加速下降。
    • 
  
  • 训练影响：敬业度越高、训练师效率越高，每周属性成长越快。
    • 
  
  • 比赛经验：出场时间越多，球商/关键球/精神属性增长越快。
    • 
  
  • 伤病影响：重大伤病可能导致属性永久下降 1-3 点。
    • 
  
  • 潜力上限：属性不能超过 潜力值，潜力由选秀/球探评估。
