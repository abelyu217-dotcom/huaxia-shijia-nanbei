1深化方向与原则

深化定位：经济系统 §6-8 已建立财务与球馆的数值骨架——收入分解占比、球馆 Lv1-5 等级表、财务面板、赛季财报。本系统不重复这些数值表，而是补全其"决策维度"：球迷热情如何动态变化、球馆何时升级才值得、重复奢侈税如何运作、FFP 如何约束、财务健康如何评分、收入如何优化博弈。数值沿用经济系统，本系统聚焦"怎么做财务决策"。

1.2 深化原则

① 决策而非记账 玩法
财务不是被动记账，而是主动博弈——票价定多高？球馆何时升级？接受奢侈税换冠军值不值？每个决策都有取舍。
② 长期 vs 短期 张力
高票价短期赚钱但伤球迷热情→长期上座率下降；球馆升级长期回本但短期吃现金流。财务的核心张力是时间。
③ 健康可持续 约束
FFP 与财务健康评分防止"烧钱夺冠后破产"——可持续经营是底线，不是可选。
④ 联动而非孤立 耦合
财务是所有系统的下游约束——签约转会受薪资空间约束、训练受运营预算约束、球探受球探预算约束。

3球迷热情引擎

球迷热情（FanPassion）被经济系统多处引用（球票上座率、周边销量、赞助商满意度、球馆效果），但未完整定义。本节补全。

3.1 球迷热情值

每支球队有 FanPassion 值（0-100），反映球迷对球队的热情程度：

0-20 冰点
21-40 低谷
41-60 平稳
61-80 热潮
81-100 狂热

3.2 球迷热情影响因素

因素影响频率
战绩连胜 +3/场；连败 -2/场；夺冠 +15（一次性）每场
票价高价 -1~3/季；低价 +1~2/季每季
球星 Fame队中有 Fame ≥70 球星 +5/季；球星离队 -5~10每季/事件
球馆档次Lv2 +1；Lv3 +3；Lv4 +5；Lv5 +8（每季）每季
社区活动投入预算办活动 +2~5/次可选
丑闻球员丑闻/更衣室内讧 -5~15事件
王朝传奇王朝持续期间 +10/季（底蕴）每季

自然衰减-2/季（若无正向因素）每季

3.3 球迷热情对收入的影响

── 球迷热情对收入的放大/缩减 ── fanMultiplier = 0.5 + fanPassion / 100 * 1.0 // fanPassion=0 → ×0.5（冰点，收入减半） // fanPassion=50 → ×1.0（平稳，基准） // fanPassion=100 → ×1.5（狂热，收入放大50%） actualTicketRevenue = baseTicketRevenue * fanMultiplier actualMerchRevenue = baseMerchRevenue * fanMultiplier * 1.2 // 周边更受热情影响 sponsorSatisfaction = baseSatisfaction * fanMultiplier

3.4 球迷热情的博弈

核心博弈：球迷热情是"长期资产"——高价票短期赚钱但热情下降→长期上座率和周边收入缩减。低价票短期少赚但热情上升→长期收入放大。战绩是热情的最大驱动力——连败会让一切恶化（热情↓→上座率↓→收入↓→没钱签好球员→继续输）。这是"赢球循环"与"输球循环"的财务表达。

4.4 球馆的非收入效应

球馆不只影响收入，还影响：

  • 自由球员吸引力（签约转会 §4.2 DestinationScore）：豪华球馆 +25%，地标馆 +40%——"基建吸引人才"。
  • 球迷热情（§3.2）：每季被动 +1~8。
  • 冠名赞助资格（经济系统 §6.3）：Lv4+ 才能申请冠名赞助。
  • 球衣退役展示（王朝系统 §8）：退役球衣悬挂于球馆，作为文化资产。
  • 队史名人墙（王朝系统 §8.3）：球馆内展示，提升球市吸引力。

5收入优化博弈

经济系统 §6 已给出收入公式。本节定义收入优化的策略博弈——不是"收入越多越好"，而是各收入源的取舍。

5.1 票价定价博弈

策略短期长期适用
高价票单场收入高球迷热情 -1~3/季→上座率↓→长期收入↓争冠队（球迷愿付高价）
平价票基准球迷热情稳定中游队
低价票单场收入低球迷热情 +1~2/季→上座率↑→长期收入↑重建队（培养球迷基础）
博弈核心：高价票在争冠期合理（球迷热情高不怕小幅下降），但在重建期是自杀（本就没人看，高价更赶人走）。票价应随球队周期动态调整——争冠期高价收割，重建期低价养粉。

5.2 赞助商续约博弈

赞助商类型年收入续约条件博弈
冠名赞助（顶级）800-1,500Fame ≥60 + 顶级联赛 + Lv4 球馆高收入但门槛高；降级即失去
主赞助商400-800Fame ≥40 + 次级以上中等收入；较稳定
普通赞助商100-300无硬性条件保底收入；但金额低

续约博弈：高等级赞助商收入高但续约条件苛刻——降级/战绩下滑可能导致赞助商不续约，收入骤降。经理需在"冲高等级赞助（高收入高风险）"与"保普通赞助（低收入低风险）"间权衡。

5.3 周边商品博弈

  • 球星效应：核心球员 Fame ≥70 时周边销量 ×1.5~2.0——球星离队/退役周边销量骤降。
  • 冠军效应：夺冠赛季周边销量 ×2.0~3.0——冠军周边是爆发性收入。
  • 商业团队：投资商业团队（经济系统 §7.6）提升周边销量 +10~35%。
  • 球迷热情：周边销量受 fanMultiplier ×1.2 放大——热情比球票更影响周边。

5.4 转会收入

  • 卖出球员的转会费/解约金计入转会收入（经济系统 §6.1 占比 5%）。
  • 交易特例（签约转会 §11.2）不计入收入（仅配平用）。
  • 转会收入波动大——不定期，不可作为预算依赖。

6重复奢侈税深化

经济系统 §5 定义了基础奢侈税。本节深化"重复奢侈税"——连续多年超帽的递进惩罚。

6.1 基础奢侈税（回顾）

  • 薪资超过工资帽的部分，按 1:1 缴纳奢侈税（每超 1 单位薪资，缴 1 单位税）。
  • 奢侈税不占薪资空间，但从现金流扣除——直接减少净利润。

6.2 重复奢侈税

连续超帽的球队，奢侈税税率递进上升：

连续超帽年数税率说明
第 1 年1:1基础奢侈税
第 2 年1:1.5递进 50%
第 3 年1:2递进 100%
第 4 年1:2.5递进 150%
第 5 年+1:3上限封顶

6.3 重复奢侈税的博弈

核心约束：重复奢侈税让"长期烧钱争冠"成本递增——第 1 年超帽缴 1:1 可接受，但第 5 年 1:3 几乎不可持续。这迫使争冠球队在"烧钱期"后必须"降帽喘息"——清空部分高薪合同，回到帽下，重置奢侈税计数器。这模拟现实 NBA 的"避税年"策略，防止超级球队无限堆积。

6.4 税款分配

  • 奢侈税款不消失——分配给帽下球队（"穷人税"返还）。
  • 这形成财富再分配：超帽强队补贴帽下弱队，缩小贫富差距。
  • 帽下球队每季可获得 50-200 的奢侈税返还（视全联盟超帽总额）。

7财务公平竞赛 FFP

经济系统 §8 提及 FFP 风险预警。本节定义完整 FFP 规则与处罚。

7.1 FFP 原则

FFP 核心原则：球队的"足球相关支出"（球员薪资+运营成本）不得超过"足球相关收入"（球票+转播+赞助+周边）的一定比例。防止球队靠外部注资（如富老板注资）无限烧钱，破坏竞争平衡。

7.2 FFP 计算

── FFP 合规判定 ── footballRevenue = ticket + broadcast + sponsorship + merch + prize footballExpense = playerSalaries + staffSalaries + arenaMaint + operations ffpRatio = footballExpense / footballRevenue // 合规阈值 ffpRatio <= 0.9 → "HEALTHY" // 健康（支出≤收入90%） ffpRatio <= 1.0 → "WARNING" // 警告（收支平衡） ffpRatio <= 1.1 → "AT_RISK" // 风险（轻度亏损） ffpRatio > 1.1 → "VIOLATION" // 违规（严重亏损）

7.3 FFP 处罚

状态处罚
HEALTHY无；可获奢侈税返还（如帽下）
WARNING系统预警；无处罚
AT_RISK限制：下季转会窗口签约受限（不可签顶薪）；青训学院投入上限
VIOLATION处罚：扣联赛积分（-5）；禁止转会窗口签约；严重者降级风险

7.4 FFP 修复

  • 违规球队需在 2 季内将 ffpRatio 降至 1.0 以下。
  • 修复手段：裁员/买断高薪球员（签约转会 §9）；降低运营投入；提升收入（升级球馆/提升战绩）。
  • 持续违规 3 季：强制降级（世界结构 §7）。

8财务健康评分

综合评估球队财务状况的多维评分，给经理一个"我的财务健康吗"的直观指标。

8.1 评分维度

维度权重评分依据
现金流25%当前现金储备 vs 预计支出；是否够撑 1 季
FFP 合规25%ffpRatio 状态
薪资结构20%是否有烂合同/超帽/重复奢侈税
收入稳定性15%赞助商续约风险/球迷热情趋势
投资回报15%运营模块投入产出比

8.2 健康等级

A · 健康 (≥80)
现金流充裕；FFP 合规；薪资结构合理；收入稳定。可大胆投资争冠。
B · 良好 (60-79)
基本健康；个别维度需关注。正常运营。
C · 警告 (40-59)
有风险维度；需主动修复。避免大额签约。
D · 危险 (<40)
严重财务问题；FFP 违规风险；需紧急裁员/降本。

8.3 财务健康预警

当评分降至 C 或 D 时，系统发出预警并建议修复动作：

  • 现金流不足 → "建议裁员释放薪资空间"
  • FFP 风险 → "建议降低运营投入或提升战绩增加收入"
  • 烂合同 → "建议买断高薪低能球员（签约转会 §9）"
  • 球迷热情低谷 → "建议降低票价/办社区活动"

10与签约转会联动

10.1 薪资空间作为签约约束

  • 签约转会的所有报价/交易需先通过薪资空间校验（签约转会 §3.2 三查之一）。
  • 薪资空间 = 工资帽 - 当前合同薪资 - 运营投入预算 - 奢侈税预估。
  • 薪资空间不足 → 报价被系统拒绝（签约转会 §16.1）。

10.2 球馆影响自由球员吸引力

  • 球馆 Lv3+ → 签约转会 §4.2 DestinationScore +10~40%。
  • "基建吸引人才"——豪华球馆让球星更愿来，弱队可折价签。
  • 这是基建流建队的核心逻辑：先建馆再签人。

10.3 重复奢侈税与签约策略

  • 已连续超帽 3 年的球队，再签顶薪 → 重复奢侈税 1:2 → 财务健康降至 D。
  • 系统在签约前预警："此签约将导致重复奢侈税升级，是否继续？"
  • 这迫使争冠球队在"烧钱期"与"避税年"间轮换。

11.2 投资取舍

核心取舍：薪资空间有限——花在球员身上的每一块钱=别处少花一块。球星流把钱花在球员身上但教练/球探/青训弱；青训流把钱花在青训/球探身上但球员薪资低。没有"全都要"——财务是零和博弈。

12与王朝世界联动

12.1 王朝的财务加成

  • 王朝球迷热情加成（§3.2）：传奇王朝期间球迷热情 +10/季——王朝底蕴持续吸引球迷。
  • 冠军奖金（经济系统 §6.6）：夺冠 2,000 奖金——争冠的直接财务回报。
  • 球衣退役/名人墙（王朝系统 §8）：作为球馆文化资产，小幅提升球市吸引力。

12.2 世界结构联动

  • 联赛层级影响收入（经济系统 §5）：T1 转播分成 ×3.0，T4 ×1.0——升级=收入翻倍，这是升降级赌注的财务动力。
  • 降级重击：降级 → 球迷热情 -20 + 收入骤降 → 财务健康暴跌 → 可能触发 FFP 风险。
  • 世界迁移：迁移后财务重置——新世界起始薪资空间按联赛层级计算；历史财务档案保留但不影响新世界。

12.3 经理传奇档案的财务维度

  • 王朝系统 §4.2 的 legacyScore 纳入 financialHealth 维度——财务健康的王朝比"烧钱夺冠后破产"的王朝评分更高。
  • 可持续经营是王朝评分的加分项——鼓励"健康夺冠"而非"负债夺冠"。
