1.2 趋势

  • 异步每日制（daily-turn）经理品类被验证：适配成年玩家碎片时间，低单日时长、高长留。
  • 公平非 P2W 成为经理品类的信任底线（Rim Attack 明确"Credits/VIP 均不影响比赛结果与球员强度"）。
  • 浏览器即玩 + 移动 PWA 降低获客与回流门槛。

1.3 机会缺口

  1. 中文/亚洲篮球主题缺位：现有作品均以 NBA 或欧洲为轴；CBA、日本 B 联赛、菲律宾 PBA、台湾 P. League+ 的热度无对应经理产品承接。
  2. 联机异步赛道可复制且未饱和：Rim Attack 已跑通模型，但主题窄、移动端体验薄弱、战术层偏浅——存在系统性超越空间。
  3. 亚洲篮球叙事红利：联赛职业化、归化潮、亚冠联赛（BAL）等话题持续升温，是天然的"王朝叙事"土壤。

2逆向研究结论：Rim Attack 系统拆解

研究来源：playrimattack.com 首页 + 官方 14 章 Guide（重点拆解第 3、4 章）。

2.1 产品哲学（四句话）

  1. 信息不对称是玩法核心：球员的 27 项能力、Peak、特质在"不熟悉"时都带误差区间（The Fog），球探/探针/观看/对阵逐步收窄。
  2. 战术是方向，不是遥控器：球员依据自身能力、情境、防守自行决策；战术只调"倾向"。
  3. 节奏由日历驱动：异步、低单日粘性、高长留。
  4. 公平商业化：不卖比赛结果，不卖球员强度。

2.2 核心系统清单（11 项）

① 每日结算周期（Daily Settlement）

10:00 UTC 比赛结算，16:00 UTC 资源/天翻页。玩家提交的是"下一场"的安排，不能改写已发生结果。
设计意图：异步 PvP、防沉迷、确定性节奏、所有人都同一时钟。

② 球员能力模型（27 项，5 组）

  • Physical(7)：Wingspan / Standing Reach / Speed / Vertical / Strength / Agility / Endurance
  • Shooting(5)：Mid-Range / Three-Point / Inside Shooting / Rim Attack / Free Throw
  • Defense & Rebounding(6)：Steal / Perimeter D / Interior D / Off Rebound / Def Rebound / Lateral Speed
  • Ball Handling(4)：Dribbling / Catching / Passing / Post Move
  • Mental(5)：Offensive IQ / Defensive IQ / Aggression / Leadership / Draw Foul

能力"相互作用而非独立裁决"：好的终结者还需控运/体格/决策配合。球员另有：Peak（成长空间估值）、Condition（疲劳驱动状态）、Fame（联盟声望）、Stats、Contract。

③ The Fog（迷雾）

不熟悉的球员，能力/Peak/特质均带 margin of error。球探报告"收窄"区间，不是"保证"真值；探针槽位与预算有限 → 资源分配博弈。

④ 战术与轮换（Tactics as Direction）

  • 基础设置：进攻倾向 / 防守倾向 / 节奏 三选即可用。
  • 高级编辑器：保存多套战术；设定首发与轮换逻辑；给球员分配战术槽位与角色；写"仅特定阵容/情境触发"的条件规则；设换人逻辑。
  • Per-game tactics：可对任意赛程指定一次性战术，对手看不到你的私有设置。

⑤ 训练 / 成长 / 生涯曲线

身体天赋先达峰、先衰退；技术更持久；经验只增不减。训练是延迟回报的投资。

⑥ 球探 / 探针 / Watchlist

Scout Report 收窄候选，不是保证；探针槽与预算有限，花在"能改变决策"的地方。

⑦ 选秀 + 传闻中心（Rumor Mill）

试训、接近新秀、运作传闻、经理间博弈抢人。

⑧ 自由市场 / 合同 / 工资帽

报价=带价格的承诺，不是无限试探；下单前三查：位置缺口 / 薪资空间 / 情报。

⑨ 财务 / 球馆 / 投资

健康的财务不是"少花"，而是"每一笔长约都有明确职责"。

⑩ 联盟金字塔 + 升降级

分层联赛（Alpha / Beta / Next Wave）；季末升降级；季后赛 top/bottom 16。

⑪ 王朝 / 传承 / 名人堂

围绕一名核心建一代，生涯结束交棒；Credits（账号资源）+ VIP（订阅）均不影响比赛结果/球员强度。

2.3 玩家日循环

日循环：登录 → 看 Alerts → 训练/球探/市场/战术 → 提交 → 10:00 结算看比赛（文字 PBP）→ 复盘 box score / PBP → 16:00 翻天 → 次日

2.4 可借鉴 / 可超越

  • 借鉴：每日结算时钟、The Fog、战术即方向、公平商业化、升降级金字塔。
  • 超越点：移动端体验、战术纵深（半场调整/关键时刻）、叙事与王朝感、亚洲主题与中文本地化、实时观战每日 sim。

3本作产品定位与差异化

3.1 定位

面向中文玩家的异步每日制篮球经理：每日一赛、固定时钟结算；以"亚洲联赛金字塔 + 真实信息迷雾 + 战术方向感"为核心；公平非 P2W；移动优先 PWA。

3.2 差异化四板斧

🌏
亚洲篮球主题与中文本地化
虚构的亚洲联赛金字塔（致敬 CBA / B 联赛 / PBA / P. League+ 风格，规避版权），中文球员/球队/报纸叙事。玩家从次级联赛起步，逐级冲击顶级联赛与洲际冠军（拟态 BAL 亚冠）。
🎯
更深的战术层
在 Rim Attack"基础三选 + 高级条件规则"之上，增加半场调整与关键时刻（Clutch）战术卡。引入对位针对性：针对对手核心的防守策略（包夹/护筐/换防）作为可指定战术槽。
📜
更强叙事与王朝感
"时代标签"系统：核心球员退役后留下可继承的时代遗产（战术偏好、青训血脉、球迷文化）。拟态报纸 + 社媒流，把每日 sim 与赛季事件转化为可读叙事。
📱
移动优先 PWA + 实时观战
移动端为第一体验；每日 10:00 结算时支持实时推送 PBP 观战（WebSocket/SSE），把"等结果"变成"看直播"。

5系统设计（首版范围）

5.1 球员能力模型

沿用 5 组结构，合并冗余项至 约 20 项（如 Lateral Speed 并入 Perimeter D 的子维度，Catching 弱化为隐含属性），降低新手认知负荷，保留迷雾深度。

  • 每项能力含：可见估值（带误差）/ 真实值（隐藏）/ Peak（成长上限估值，带误差）。
  • 球探等级决定：估值偏差幅度、不确定区间宽度、可见特质数量。

5.2 比赛模拟引擎

  • 文字 PBP 为主，关键回合（lead change / clutch / 关键犯规）高亮。
  • 每回合由：球员能力 × 战术倾向 × 对位 × 情境（比分/时间/疲劳）× 随机 → 决策树生成出手选择与结果。
  • 新增：半场调整——中场可依 box score 调整下半场倾向（限 2 处）。
  • 新增：Clutch 战术卡——第四节最后 3 分钟 / 加时，可指定一套关键回合战术。

5.3 球探与选秀

探针槽位 + 预算制；Scout Report 收窄区间，Probe 提高精度，Watchlist 持续跟踪。选秀：试训 → 接近新秀（好感度）→ 传闻中心博弈 → 选秀日抢人。

5.4 自由市场与合同

报价即承诺；三查（位置缺口/薪资空间/情报）；长约带"明确职责"才能签。合同类型：底薪/中产/顶薪/新秀红利/老将底薪。

5.5 训练与生涯曲线

身体天赋先达峰先衰退；技术持久；经验只增。训练为延迟投资；过劳伤状态与 condition。

5.6 联盟与升降级

三层金字塔（顶级 / 次级 / 入门）；每季末升降级；季后赛 top/bottom 16。冷启动用 AI 经理填充，随真实玩家增加逐步替换。

5.7 王朝与传承

时代标签：核心球员退役留下可继承遗产（战术偏好、青训血脉、球迷文化 buff）。名人堂：跨存档的成就沉淀。

7技术方案

7.1 架构

  • 前端：React + Vite + TypeScript + PWA（移动优先，离线可查看阵容/战术）。
  • 后端：Node 服务 + 关系型 DB（球员/联盟/合同）+ 缓存（每日 sim 队列）。
  • 结算调度：Cron 每日 10:00（UTC+8）触发 sim，16:00 翻天。
  • 实时观战：sim 运行时通过 WebSocket/SSE 推送 PBP，玩家可"看直播"。
  • 反作弊：sim 在服务端权威执行，前端只读结果。

7.2 关键模块

sim-engine
回合级 PBP 生成（纯函数，可单测、可回放）。
scouting
fog 偏差与收窄逻辑。
league-scheduler
赛程 + 升降级 + 季后赛种子。
daily-settler
每日结算编排。

8美术与 UI 方向

  • 风格：运动杂志 × 数据仪表盘；暗色为主，强对比、高可读性；移动端单列流式。
  • 关键界面：首页 Dashboard（Alerts）/ 阵容 / 球员卡（迷雾态）/ 战术编辑器 / 比赛直播页（PBP 流）/ 联盟排名 / 选秀中心 / 报纸流。
  • 核心反馈：迷雾用"???"与区间条表达不确定性；Clutch 回合用高亮卡片。

11立项结论与下一步
