1设计原则与定位

核心定位：王朝与传承系统是 HWO 的"收束系统"。前面的系统各自解决"怎么比赛、怎么建队、怎么获取球员、怎么训练、怎么流动"——本系统解决"这一切的意义是什么"。它把单赛季的胜负、单名球员的生涯、单支球队的兴衰，汇聚为跨越代际的世界历史，让玩家的每一个决策都有长线回响。
① 收束而非新增 聚合
本系统不新增核心玩法循环，而是聚合已有系统的长线产出——成长线的传承、关系系统的跨代、三身份的名人堂、世界结构的年代循环——把它们编织为可感知的"王朝叙事"。
② 跨代情感 留存
王朝的价值不在单次夺冠，而在"我打造的球队十年后还在影响联赛""我培养的球星退役后他的儿子又来了"。跨代情感是 HWO 区别于一次性经理游戏的核心留存钩子。
③ 留痕可追溯 档案
所有王朝成就、时代标签、传承遗产永久存入世界历史档案。即使球员退役、球队降级、经理退游，历史不可篡改。这是"我来过，我征服过"的证据。
④ 涌现而非强求 自然
王朝不靠任务清单驱动，而是从比赛结果、球员生涯、球队兴衰中自然涌现。系统只负责"识别并记录"，不强制玩家追求王朝。

1.2 不做什么

  • 不做强制任务：王朝不是成就清单——不要求"赢 5 次冠军才能解锁"。王朝是自然涌现并被记录的结果。
  • 不做数值碾压：传承遗产是"小幅加成+叙事钩子"，不是"二代球员碾压一代"。随机性确保不会"名将必出名将"。
  • 不做跨世界传承：传承世界内封闭。世界迁移时传承档案跟随，但不影响新世界。
  • 不做付费传承：传承不可付费购买或加速。它是时间与决策的回报。

3.3 赛季时代标签

赛季级标签标记"这个赛季发生了什么"：

  • 惊天冷门赛季：季后赛出现 ≥2 次 lowSeed 击败 highSeed。
  • 得分爆炸赛季：联盟场均得分创历史新高。
  • 新王登基赛季：新夺冠球队（此前无冠）。
  • 王朝终结赛季：连冠被终结。
  • 选秀大年：该届选秀出现 ≥3 名未来全明星。

4.3 王朝的兴衰

崛起 → 白银王朝 → 黄金王朝 → 传奇王朝 → 衰退 → 王朝终结
  • 王朝延续条件：每季末重新判定。连续 2 季未进季后赛 → 王朝降级；连续 3 季未进季后赛 → 王朝终结。

  • 王朝复兴：终结后若再次满足白银以上条件，标记"王朝复兴"（罕见叙事）。

5球员传承遗产

深化成长线 §10 的传承遗产框架。球员退役时，其生涯积累以"传承遗产"形式传递给后人。

5.1 传承类型

类型传承目标传承内容触发条件
血脉传承子女（二代球员）Peak 继承、特质倾向、训练侧重偏好有适龄子女（关系系统 §2）
师承传承指定徒弟技术熟练度加成、特质觉醒概率有师徒关系（关系系统 v1 §6）
精神传承全队/接班人MentalFortitude 加成、时代标签继承legacyScore ≥15
纪录传承队史档案队史纪录写入；后人破纪录触发叙事持有队史纪录

5.2 血脉传承深化

关系系统 §2.4 已定义二代球员天赋继承公式。本节定义退役时的"血脉传承"触发：

── 退役血脉传承触发 ── function triggerBloodlineLegacy(retiringPlayer): children = getChildren(retiringPlayer) for child in children: // 传承强度按父/母 legacyScore legacyStrength = clamp(retiringPlayer.legacyScore / 30, 0.5, 2.0) // 子女已存在的 Peak 基础值 + 血脉传承加成 child.peak += legacyStrength * 3 // 最高 +6 // 特质倾向继承（非直接获得，是觉醒概率提升） if (retiringPlayer.hasTrait("clutch_killer")): child.traitAwakenBonus["clutch_killer"] += 0.1 * legacyStrength // 训练侧重偏好继承（关系系统 §2.5 已部分定义） child.inheritedFocus = retiringPlayer.careerFocus
── 精神传承（全队/接班人） ──
function triggerSpiritLegacy(retiringPlayer, team): if (retiringPlayer.legacyScore < 15): return // 不够格 // 接班人：同位置能力最高的年轻球员 successor = findSuccessor(team, retiringPlayer.position) if (successor): successor.mentalFortitude += 3 // 精神传承 successor.eraTags.append("XX的接班人") // 全队精神传承（王朝核心退役） if (retiringPlayer.legacyScore >= 30): for p in team.players: p.mentalFortitude += 1 // 全队小幅精神加成 team.eraTags.append("后XX时代")

5.3 师承传承

  • 触发：退役球员有明确师徒关系（关系系统 v1 §6）的徒弟。
  • 效果：徒弟获得师父的"技术熟练度"加成——师父精通的技术（熟练度 ≥80），徒弟训练响应 +0.05~0.10。
  • 特质觉醒：师父拥有的特质，徒弟觉醒概率 +5~15%（按 legacyScore）。
  • 叙事：生成"师承一脉"标签——"XX 的技术传给了 YY"。

6名人堂

补全三身份 §3.6 的名人堂概念。名人堂是世界级的荣誉殿堂，退役球员的最高荣誉。

6.1 入选标准

层级名称条件权益
第一档传奇名人堂legacyScore ≥50 且 ≥3 冠世界级铜像；名字载入世界年代史首页；子女血脉传承 ×1.5
第二档名人堂legacyScore ≥30 且 ≥1 冠世界级牌匾；子女血脉传承 ×1.2
第三档荣誉堂legacyScore ≥20球队级荣誉；子女血脉传承 ×1.0

6.2 入选流程

球员退役 → legacyScore 计算 → 入选判定 → 入选仪式（新赛季首场） → 档案永久写入

6.3 名人堂权益

  • 血脉传承强化：名人堂球员的子女天赋继承系数提升（×1.2~1.5）。
  • 球衣退役：名人堂球员的球衣号码在该队退役（§8）。
  • 世界年代史：名字载入世界年代史，永久可查询。
  • 转岗优先：名人堂球员退役后转任教练/球探/管理层时，起始等级更高（§7）。
  • 叙事资源：成为后世叙事的引用素材——"下一个 XX""XX 再现"。
设计意图：名人堂是"我来过，我征服过"的终极证明。它让球员生涯的意义超越单次夺冠——一名球员退役后，他的名字永远留在世界历史中，他的血脉可能产生下一代球星，他的精神传承给接班人。这是 HWO 最深的情感锚点。

7退役球员转岗

退役不是终点——优秀球员退役后可转任教练/球探/管理层/青训导师，以职业人身份延续生涯。

7.1 转岗类型

转岗起始等级核心技能继承适用
教练按 legacyScore：名人堂→Lv4，荣誉堂→Lv2teaching 能力（训练系统 §9）；战术理解（战术系统）高 IQ 球员
球探按 legacyScore 起始等级位置经验（同位置探查 fog ×1.1）经验丰富的老将
青训导师按 teaching 倾向teaching 训练日效果（训练系统 §13）有师徒关系的球员
管理层按 legacyScore + 经济素养签约谈判加成；薪资空间规划高 Fame 球员
媒体人按 MediaRapport媒体事件生成；舆论影响媒体关系好的球员

7.2 转岗与三身份系统联动

  • 退役球员转岗后成为三身份系统的"职业人"（三身份 §5）。
  • 若退役球员是玩家化身，玩家可选择该化身转岗为何种职业人——化身的职业人身份可被经理身份雇佣。
  • 反套利：经理不可直接雇佣自己化身转岗的职业人担任要职（三身份 §10 反套利）。

7.3 教练传承

名人堂球员转任教练后，其球员时代的时代标签部分转化为"教练风格标签"：

  • "三分之王" → "投射体系教练"（球队三分出手 +10%）
  • "铁闸" → "防守型教练"（球队防守效率 +5%）
  • "大心脏" → "clutch 教练"（球队 clutch 表现 +10%）

这让退役球星的"篮球哲学"以教练身份延续——又一个跨代传承的维度。

8球衣退役与队史纪念

8.1 球衣退役

  • 条件：名人堂球员 + 效力该队 ≥5 季。
  • 效果：该号码在该队永久退役，不可被新球员选用。
  • 仪式：新赛季首场主场比赛前举行球衣退役仪式——心理 +10 全队；Fame +5 退役球员。
  • 球馆展示：退役球衣悬挂于球馆（经济系统 §8 球馆），作为球馆文化资产，小幅提升球市吸引力。

8.2 队史纪录

纪录类型记录内容破纪录触发
队史得分王效力期间总得分破纪录时生成"超越传奇"叙事
队史助攻王效力期间总助攻同上
队史篮板王效力期间总篮板同上
队史三分王效力期间总三分同上
单场纪录单场得分/助攻/篮板破纪录时生成"神迹再现"叙事
连冠纪录连续夺冠次数追平/超越时生成"比肩传奇"叙事

8.3 队史名人墙

  • 球队球馆内设"队史名人墙"，展示该队所有名人堂/荣誉堂球员。
  • 名人墙是球馆文化资产，提升球市吸引力与球员心仪目的地（签约转会 §4.2 DestinationScore）。
  • 新援加盟时，名人墙展示作为签约叙事素材。

9跨代传承闭环

整合成长线 §10、关系系统 §2/§12、本系统 §5/§6/§7，定义王朝视角的完整跨代闭环。

9.1 闭环全貌

一代球星崛起 → 建功立业（时代标签累积） → 退役（传承遗产触发） → 名人堂入选 → 血脉传承（子女加成） → 师承传承（徒弟加成） → 转岗（教练/球探/导师） → 二代球员成长 → 二代建功立业 → 再传承（第三代）

9.2 传承衰减与随机性

关键设计：传承会衰减且含随机性，确保不会"名将必出名将"无限滚雪球。一代 legacyScore 50 → 子女 Peak 加成 +6，但随机 ±15 仍可能出庸才。三代后传承加成衰减至 ×0.5。这让王朝自然兴衰——没有永远的王者，只有新的挑战者。

9.3 王朝传承的特殊机制

机制说明
王朝遗产传奇王朝终结后，球队获得"王朝遗产"标签——青训产出 ×1.2 持续 3 季（底蕴犹存）

11.3 经理退游与传承

  • 退游：经理退游时档案存入年代史，永久可查询。
  • 新世界传承：传奇经理在新世界开局时获得起始声望加成——这是"前世积累"的回报。
  • 不传承数值：不传承球队/球员/薪资——每世界独立。只传承声望与档案。

12传承奖励与解锁

12.1 传承奖励原则

原则：传承奖励是"小幅加成+叙事钩子"，不是数值碾压。目的是让长线玩家有回报感，而非让新玩家无法追赶。所有传承加成可被随机性抵消。

12.2 解锁内容

成就解锁
首个冠军冠军戒指展示（球馆）；"冠军教头"经理标签
传奇王朝王朝铜像（球馆）；"王朝缔造者"经理标签
培养名人堂球员"名帅"标签；青训学院 +1 等级上限
二代球员进全明星"虎父无犬子"叙事标签；血脉传承 ×1.1
一人一城球员退役球衣退役；"忠诚"队史标签
传奇经理新世界起始声望 +20；年代史首页留名

12.3 不解锁什么

  • 不解锁数值优势：不解锁更高工资帽、更多选秀权、更强球员——保持竞技公平。
  • 不解锁付费内容：传承是时间回报，非付费门槛。
  • 不解锁跨世界优势：传承世界内封闭，不污染新世界经济。

13王朝叙事自动生成

深化关系系统 §12 的事件链机制。王朝叙事是"大时间尺度"的叙事弧线。

13.1 叙事弧线类型

弧线触发叙事节点
崛起弧T4 球队首进季后赛低谷→重建→选秀淘金→崛起→首进季后赛
王朝弧首冠崛起→核心成型→首冠→卫冕→王朝
衰落弧王朝终结核心老化→战绩下滑→王朝终结→重建
复兴弧王朝终结后再次夺冠衰落→蛰伏→二代崛起→复兴
传承弧二代球员进全明星一代退役→二代成长→二代建功→"将门虎子"
宿敌弧两队连续季后赛相遇首次相遇→互有胜负→宿敌成型→史诗对决

13.2 叙事生成原则

  • 数据驱动：叙事从比赛数据与生涯事件中提取，非虚构。
  • 关系锚定：所有叙事以球员/球队关系为情感锚点。
  • 留痕档案：完成的叙事弧线存入年代史，成为世界历史的一部分。
  • 引用前史：新生代叙事可引用历史——"下一个 XX""比肩 XX 王朝"。

14AI 王朝行为

14.1 AI 球队的王朝周期

AI 球队按"崛起→巅峰→衰落→重建"周期运作，模拟真实联赛的王朝更替：

阶段AI 行为持续
重建期交易老将换选秀权；囤薪资空间；青训投入3-5 季
崛起期新秀成熟；针对性签约补强；冲击季后赛2-3 季
巅峰期顶薪续核心；交易补最后拼图；冲击冠军3-5 季
衰落期核心老化；薪资锁死；战绩下滑2-3 季

14.2 AI 等级与王朝能力

  • 精英 AI（T1）：能维持长期王朝（5-8 季）；善用伯德条款续核心；精明交易。
  • 强 AI（T2）：能打造短期王朝（2-4 季）；偶有失误。
  • 中 AI（T3）：难以形成王朝；偶尔黑马。
  • 弱 AI（T4）：常年鱼腩；偶尔崛起。

15异常处理与边界规则

15.1 退役异常

异常处理
球员无子女退役无血脉传承；仅有师承/精神/纪录传承
球员无师徒退役无师承传承
球员 legacyScore 不足无精神传承；不入选名人堂
球员因伤提前退役传承遗产按已积累 legacyScore 计算（可能较低）
多人同年退役按 legacyScore 排序依次处理；互不影响

15.2 王朝异常

异常处理
球队降级（世界结构 §7）王朝自动终结；记入"降级终结"标签
球队迁移（世界结构 §11）王朝档案跟随；但新世界不继承王朝等级
经理退游球队王朝延续（AI 接手）；经理档案存入年代史
世界合并（世界结构 §9）各世界年代史独立保留；不合并

15.3 跨世界隔离

  • 传承世界内封闭——二代球员、师承传承、精神传承均不跨世界。
  • 世界迁移时，传承档案跟随但不影响新世界。
  • 名人堂世界内独立——A 世界的名人堂在 B 世界无效。
  • 唯一跨世界传承：经理传奇档案→新世界起始声望加成（§11.3）。
