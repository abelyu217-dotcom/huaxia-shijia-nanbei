1设计原则

核心定位：签约与转会系统是球员流动的操作引擎，深化经济系统 §3-4 的框架。它把"球员如何进出球队"从简单的数值交换，提升为融合 fog 信息战、心仪目的地、薪资空间博弈、谈判心理战的复合决策系统。
① 信息不对称 核心
交易中双方 fog 独立——你可能用 fog 未收窄的球员换对方明星，结果发现是水货。fog 是签约转会的第一风险源。
② 球员意志 拟真
自由球员有心仪目的地倾向，并非价高者得。弱队需溢价，强队可折价。这模拟现实"球星投奔强队"并给弱队重建出路。
③ 薪资约束 经济
工资帽、奢侈税、薪资平衡校验让每笔签约转会有真实经济代价。空间是稀缺资源，花在 A 身上=不能花在 B 身上。
④ 节奏与窗口 体验
签约转会按窗口节奏运作（自由市场期/交易窗口/续约窗口/截止日），避免无节奏的随机操作，让操作有决策重量。

1.1 与经济系统的关系

本系统是经济系统 §3（球员薪资）与 §4（转会交易）的深化实现：

  • 经济系统定义合同类型、薪资公式、工资帽规则（供给侧规则）。
  • 本系统定义球员流动的操作流程、决策模型、博弈机制（操作侧实现）。
  • 数值参数沿用经济系统，不重复定义；本系统聚焦"怎么做决策"而非"算多少钱"。

1.2 不做什么

  • 不做纯竞价：自由球员签约不是拍卖——球员有心仪目的地，最高报价不一定赢。
  • 不做无风险交易：交易中 fog 独立，"换来的可能是水货"是核心风险。
  • 不做即时交易：跨经理交易有 48 小时响应窗口+最多 3 轮还价，模拟谈判节奏。
  • 不做无约束裁员：裁员按合同保障条款付违约金；全保障合同裁不掉（除非买断）。

2系统总览与架构

2.1 球员流动的五大通道

① 自由市场签约 竞价
自由球员池球员；多队报价；球员按 AcceptChance 决策；原队可匹配
② 跨经理交易 谈判
同世界两经理球员/选秀权互换；薪资平衡校验；fog 不对称风险
③ 选秀签约 独占
选秀选中即签约新秀合同；不可拒签（选秀系统 §10）
④ 续约 留人
提前续约/到期续约/伯德条款；原队留住自己养出来的核心
⑤ 青训提拔 内部
青训苗子达龄提拔进名单；成本最低的球员获取（成长线 §9）

2.2 球员生命周期中的流动节点

青训苗子 → 青训提拔/选秀 → 新秀合同(4年) → 续约/自由市场 → 多份合同流转 → 裁员/退役

2.3 三层架构

层名称职责
L1操作层 Action经理发起报价/交易/续约/裁员；提交提案
L2决策层 Decision球员 AcceptChance 计算；AI 经理交易评估；原队匹配判定；系统复核
L3结算层 Settlement薪资空间校验/扣除/释放；合同生成；名单更新；fog 揭晓；确定性 PRNG

2.4 核心数据结构

── 签约提案（自由市场） ── SignOffer = { offerId: u64, teamId: TeamId, playerId: PlayerId, contractType: ContractType, // 底薪/中产/顶薪/新秀红利 years: u8, annualSalary:u32, // 由服务端按能力锚定，经理选档次 guarantee: GuaranteeType, // 全保障/部分保障/无保障 role: RolePromise, // 角色承诺（首发/核心/轮换）影响 AcceptChance submittedAt:Timestamp, status: "pending"|"accepted"|"rejected"|"matched", } ── 交易提案（跨经理） ── TradeProposal = { proposalId: u64, fromTeam: TeamId, toTeam: TeamId, fromSide: [TradeAsset], // 球员/选秀权/薪资空间 toSide: [TradeAsset], round: u8, // 谈判轮次（最多3） status: "pending"|"countered"|"accepted"|"rejected"|"flagged", expiresAt: Timestamp, // 48小时 } TradeAsset = PlayerAsset | PickAsset | CapSpaceAsset | TradeException

3自由市场签约

自由市场签约是赛季末球员获取的主要通道，承接球探系统的 fog 探查产出。

3.1 自由市场五阶段流程

阶段 1 · 3 天
球探评估期
自由球员名单公布。经理花球探预算收窄目标球员 fog。未收窄 fog 的球员报价=盲赌。
阶段 2 · 3 天
报价窗口
经理对心仪球员提交报价（合同类型+年限+年薪+角色承诺）。报价即承诺——提交后不可撤回，球员接受则薪资空间立即冻结。
阶段 3 · 1 天
球员决策
系统按 AcceptChance 公式计算球员对所有报价的接受概率。多队报价时按概率加权选择。
阶段 4 · 1 天
原队匹配（如有优先续约权）
若球员原球队持有优先续约权，可匹配报价留住球员。不匹配则球员转会。
阶段 5
签约生效
合同生效，薪资空间扣除。未签约球员进入"剩余自由球员池"，赛季中可随时签约。

3.2 报价的三查

提交报价前，经理需完成"三查"，否则可能签错或签不下：

查项内容忽略后果
查位置缺口球队是否缺该位置？签约后化学反应影响？签来无位置→化学反应下降→资源浪费
查薪资空间报价是否在薪资空间内？是否触发奢侈税？报价被系统拒绝；或触发奢侈税惩罚
查情报 fog该球员 fog 是否收窄？Peak/能力/特质是否探清？盲赌签来发现是水货→合同占空间多年

3.3 报价档次

年薪由服务端按能力锚定（经济系统 §3.1），经理选择合同档次：

档次年薪水平适用
底薪联盟最低（30-50/季）名单末端填充、短期补缺
中产市场价（200-400/季）主力轮换、首发级
顶薪市场价上限（500+/季）核心球星
溢价市场价 ×1.3+弱队签球星的必要代价
折价市场价 ×0.7-0.9强队签愿降薪争冠的球星

3.4 角色承诺

报价可附带角色承诺，影响 AcceptChance但占用未来战术灵活性：

  • 承诺首发：AcceptChance +15%；但锁定未来首发位置，违约影响球员士气。
  • 承诺核心：AcceptChance +25%；战术围绕该球员设计，交易需其同意（事实否决权）。
  • 承诺轮换：AcceptChance +5%；保证出场时间下限。
  • 无承诺：AcceptChance 无加成；最灵活。

4球员决策模型

深化经济系统 §3.5 的 AcceptChance 公式，定义球员如何选择报价。

4.1 AcceptChance 完整公式

AcceptChance = base(offer.salary / marketPrice) * DestinationScore * LoyaltyFactor * RolePromiseMod * ChemistryMod * AgentMod // 经纪人介入（§14） // base: 报价/市场价比的映射 base(ratio): ratio < 0.7 → 0.05 // 远低于市场价，几乎必拒 ratio = 1.0 → 0.50 // 市场价，五五开 ratio = 1.3 → 0.85 // 溢价30%，大概率接受 ratio >= 1.5 → 0.98 // 重溢价，几乎必接受 // DestinationScore 见经济系统 §3.5 // LoyaltyFactor: 效力年限越长，忠诚度越高（0.8-1.3）

4.2 DestinationScore 因素详解

因素影响权重
球市规模大球市 +，小球市 -高
球队战绩强队 +，弱队 -高
联赛层级T1 顶级 +，T4 入门 -高
球馆档次豪华球馆 +（经济系统 §8）中
家乡偏好球员家乡 +（部分球员有）中
核心地位承诺承诺首发/核心 +中
同乡球员队中有同乡队友 +低
教练声望高声望教练 +低

4.3 多队报价的选择

── 多队报价时的球员选择 ── // 球员对所有报价计算 AcceptChance chances = [calcAcceptChance(offer, player) for offer in allOffers] // 按概率加权随机选择（非取最高） chosenOffer = weightedRandom(allOffers, chances, seed) // 球员可能拒绝所有报价（AcceptChance 都低） if (sum(chances) < 0.1): player.rejectAll() // 留在剩余自由球员池等更好报价

4.4 球员性格影响

球员性格特质（成长线 §4.2）影响决策权重：

性格特质决策偏好
忠诚型LoyaltyFactor ×1.5；倾向留在原队
逐利型base(报价/市场价) 权重 ×1.3；价高者得
争冠型DestinationScore 中战绩权重 ×2.0；倾向强队
大市场型球市规模权重 ×2.0；倾向大球市
回家型家乡偏好权重 ×3.0；强烈倾向家乡球队

5优先续约权与匹配

5.1 优先续约权（受限制自由球员）

  • 触发条件：新秀合同第 4 年结束后，原球队可发出"资质报价"，使球员成为受限制自由球员（RFA）。
  • 权利：原球队有 24 小时匹配任何报价留住球员。
  • 不匹配：球员转会，原队无补偿（不同于选秀权补偿）。
  • 战略价值：RFA 让原队可"等他队报价再决定匹配"，降低续约成本风险。

5.2 伯德条款（超帽续约）

条款条件效果
伯德条款效力 3+ 年可超帽续约本队球员；代价是占用更多未来空间
早伯德条款效力 2 年可超帽续约但涨幅受限（前一年薪资 ×1.75 上限）
非伯德条款效力 1 年仅可按前一年薪资 ×1.2 续约
设计意图：伯德条款让"自己养出来的核心"比"挖来的球星"更值——超帽续约是给长期培养的回报。这鼓励青训+选秀建队流派，而非纯自由市场扫荡。

5.3 匹配流程

球员接受他队报价 → 原队收到匹配通知 → 24 小时决策 → 匹配→留队
不匹配→转会

6跨经理交易

跨经理交易是同世界内两经理之间的球员/选秀权互换，是阵容调整的核心手段。

6.1 交易资产类型

资产说明交易价值
球员签约中球员（含合同）；fog 双方独立按能力/Peak/年龄/合同
选秀权未来 3 年内的首轮/次轮首轮高顺位=高价值（选秀系统 §9.2）
薪资空间当季可用空间用于配平；不可单独交易
交易特例裁员产生的薪资额度，1 年内可用于配平仅配平用
现金有限额度（防套利）上限为薪资空间的一定比例

6.2 交易核心风险：fog 不对称

核心风险：交易中涉及的球员，双方看到的 fog 独立。你可能用 fog 未收窄的球员换对方的明星，结果发现是水货；也可能用自己探得 Peak 实际很低（但对方 fog 宽不知道）的球员换到好资产。fog 信息差是交易的博弈核心——"我知道一些你不知道的"。

6.3 薪资平衡校验

── 薪资平衡校验 ── salaryDiff = abs(sum(fromSide.salary) - sum(toSide.salary)) if (salaryDiff > max(fromSide.salary, toSide.salary) * 0.25): // 差值超过 25%，需用交易特例配平，否则拒绝 if (!canCoverWithException(salaryDiff)): return "REJECTED_SALARY_IMBALANCE" // 特殊：底薪球员互换无需平衡校验 // 特殊：交易特例可吸收差值（1年内有效）

6.4 交易窗口

窗口时间允许操作
休赛期交易窗口赛季间隔期自由交易
赛季中交易窗口常规赛 DAY 1 - 第 25 场自由交易
交易截止日第 25 场后关闭交易窗口
季后赛季后赛期间禁止交易

7交易谈判机制

7.1 谈判流程

轮次 1
A 发起提案
A 向 B 提交交易提案（球员/选秀权/薪资互换）
48 小时内
B 响应
B 可接受/还价/拒绝；超时=拒绝
轮次 2（如还价）
B 还价
B 修改提案发回 A；A 可接受/再还价/拒绝
轮次 3（如再还价）
最终轮
最多 3 轮还价；第 3 轮必须接受或拒绝，不可再还
达成后
系统校验与复核
薪资平衡校验 + fog 揭晓 + 否决权检查 + 失衡复核

7.2 谈判心理战

  • 锚定效应：首轮提案设定锚点，影响后续还价范围。
  • 信息隐瞒：A 不透露为何要某球员（可能因 fog 探得 Peak 高），B 需推测。
  • 时间压力：48 小时响应窗口制造紧迫感；临近截止日时间压力更大。
  • 多队竞争：B 可同时与多队谈判，用 A 的报价压 C 加码。

7.3 AI 经理交易评估

function aiEvaluateTrade(proposal, myTeam): // 1. 价值评估 valueGain = assessValue(proposal.toSide) - assessValue(proposal.fromSide) // 2. 需求匹配 needFit = checkRosterNeed(proposal.toSide, myTeam) // 3. fog 风险评估 fogRisk = assessFogRisk(proposal.fromSide) // 送出的球员 fog 窄=风险低 // 4. 薪资影响 capImpact = checkCapSpace(proposal, myTeam) score = valueGain * 0.4 + needFit * 0.3 + fogRisk * 0.2 + capImpact * 0.1 if (score > 0.6): return "ACCEPT" elif (score > 0.3): return "COUNTER" else: return "REJECT"

8续约系统

续约是留住本队球员的核心手段，成本低于自由市场重新签约。

8.1 续约类型

类型时机价格特点
提前续约合同最后一年中途按当前能力锚定可能比到期后便宜（若球员还在上升期）；锁定避免竞价
到期续约合同到期后按到期时能力锚定原队有优先续约权（RFA）或伯德条款
新秀合同续约新秀第 3 年末按表现锚定球队选项：提前续长约或放走第 4 年
超帽续约伯德条款市场价可超帽续约效力 3+ 年的本队球员

8.2 续约决策博弈

提前续约 vs 到期再签 时机
提前续约锁定低价（若球员上升期），但若球员停滞则合同偏高；到期再签可看清最终表现，但面临竞价风险。
长约 vs 短约 年限
长约锁定核心（5年顶薪）；短约保留灵活性但有流失风险。
核心 vs 角色球员 优先级
核心球员值得顶薪长约+伯德；角色球员短约中产，随时可替代。
薪资空间规划 全局
续约 A 占用空间=不能签 B。需规划未来 3 年薪资结构，避免多份长约同时到期。

8.3 续约的球员意愿

球员是否接受续约也受 AcceptChance 影响（但通常高于自由市场，因 LoyaltyFactor 高）：

  • 本队效力 3+ 年：LoyaltyFactor ×1.3，续约接受率高。
  • 球队战绩好/球市大：DestinationScore 高，续约接受率高。
  • 角色满意（首发/核心）：接受率高。
  • 若球员想离队（战绩差/角色不满）：可能拒绝续约，进入自由市场。

9裁员与买断

裁员与买断是释放薪资空间的手段，但有真实代价。

9.1 裁员

  • 随时可裁：但按合同保障条款支付违约金。
  • 全保障合同：裁人仍需支付剩余全部薪资——顶薪合同裁不掉（除非买断）。
  • 部分保障合同：裁人付 50% 买断费。
  • 无保障合同：裁员即释放空间，无代价（底薪合同）。
  • 被裁球员：进入自由市场，其他球队可低价签（底薪），原队继续支付买断费用。

9.2 买断

  • 协商降价解约：与球员协商，球员可能接受 60-80% 剩余薪资一次性买断。
  • 球员性格影响：随和型球员易买断；固执型球员难谈（可能要求全额）。
  • 延期支付：买断费用可分 3 季摊销，缓解当季薪资压力（总成本不变）。
  • 买断后：球员成为自由球员；原队薪资空间释放（扣除买断费后）。

9.3 裁员/买断的战略用途

场景手段代价
名单满需腾位签新秀裁无保障底薪球员0

10签约转会窗口

签约转会按赛季节奏运作，不同窗口开放不同操作。

10.1 赛季周期中的窗口

窗口时间开放操作
选秀后签约期DAY 11-12新秀自动签约；落选秀可签双向合同
自由市场期休赛期（选秀后 3-5 天）自由市场五阶段流程（§3）
休赛期交易窗口赛季间隔期自由交易
续约窗口合同最后一年中途提前续约
赛季中交易窗口常规赛 DAY 1 - 第 25 场自由交易
交易截止日第 25 场后关闭交易；剩余自由球员仍可签
季后赛季后赛禁止交易/签约（仅底薪补充伤病）

10.2 剩余自由球员池

  • 自由市场期未签约的球员进入"剩余自由球员池"。
  • 赛季中可随时签约剩余自由球员（底薪为主）。
  • 选择越来越少——好球员在自由市场期已被签走。
  • 伤病潮时从剩余池紧急签人补充。

11薪资平衡与交易特例

11.1 薪资平衡规则

  • 25% 规则：双方交换薪资差值 ≤ 较高一方的 25%，否则需交易特例配平。
  • 底薪豁免：底薪球员互换无需平衡校验。
  • 新秀合同豁免：新秀合同球员交易有更宽松的平衡规则。
  • 工资帽下球队：薪资空间充足的球队可吸收更多薪资（无需严格平衡）。

11.2 交易特例

  • 产生：裁员（非买断）时产生等于该球员薪资的交易特例。
  • 有效期：1 年内可用于交易配平。
  • 用途：吸收交易中的薪资差值，使不平衡交易通过校验。
  • 不可单独交易：交易特例只能用于配平，不可单独换资产。

11.3 特殊签约特例

特例效果限制
中产特例每季可签 1 个中产合同，不计入帽已超帽球队可用
底薪特例底薪签约不计入工资帽无限制
伤病特例球员赛季报销时可额外签 1 人需医疗证明；签约额≤报废球员薪资的50%
伯德特例超帽续约本队效力 3+ 年球员仅原队

12交易否决与系统复核

12.1 球员交易否决权

  • 合同条款：顶薪+高 Fame 球员可在合同中加入交易否决权。
  • 效果：球员可否决被交易到指定球队（通常是弱队/敌对球队）。
  • 限制交易灵活性：含否决权的球员交易难度上升。
  • 需在签约时接受：否决权是签约谈判的筹码，非默认条款。

12.2 系统复核机制

为防套利与默契交易，系统对明显失衡交易标记人工复核：

触发条件处理
新秀换空气（无对等回报）标记复核，24 小时审核
多换一明显套利（如 3 名轮换换 1 名饮水机）标记复核
同 IP/关联账号间交易强制复核（防默契）
连续多笔小交易累积套利系统监控，触发复核
复核未通过交易撤销；记录违规；严重者处罚

12.3 三身份反套利

三身份系统（§10 反套利机制）在签约转会中的延伸：

  • 化身合同：经理不能给自己化身开高薪合同（FLAG_REVIEW）。
  • 经纪人代表：经理不能以经纪人身份代表自己化身谈判（BLOCK）。
  • 仲裁回避：涉及本账号的合同纠纷转交他人仲裁（REASSIGN）。

13签约与化学反应

13.1 新援加盟的化学反应冲击

事件chem 影响恢复
新援加盟-0.15团队训练恢复（训练系统 §14）
主力交易离队-0.20团队训练恢复（较慢）
核心球员裁员-0.10（更衣室震动）心理训练+团队训练
多笔交易同窗口累积下降需更长磨合期

13.2 化学反应考量

  • 签约前评估：经理需考虑新援与现有阵容的化学反应匹配度（如"球权占用者"叠加=chem 下降更多）。
  • 同乡/前队友加成：新援与队中同乡/前队友有 chem 加成恢复速度。
  • 性格匹配：性格互补的球员 chem 恢复快；性格冲突的球员 chem 恢复慢。
  • 磨合期：新援加盟后 2-3 周为磨合期，期间 chem 低于正常水平。

14经纪人职业人介入

经纪人是三身份系统（§5.2 商业线）中的职业人，可介入签约转会。

14.1 经纪人的作用

  • 代表球员谈判：经纪人可代表球员（含玩家化身）与球队谈判，提升 AcceptChance。
  • AgentMod：有经纪人代表的球员，AcceptChance ×1.1-1.3（按经纪人等级）。
  • 情报优势：高等级经纪人可获知他队报价底线，优化谈判策略。
  • 佣金：经纪人从球员合同中抽取佣金（5-10%）。

14.2 经纪人介入流程

球员（含化身）雇佣经纪人 → 经纪人评估报价 → AgentMod 提升 AcceptChance → 球员决策时加权 → 签约后抽佣

14.3 反套利

  • 经理不能以经纪人身份代表自己化身（三身份 §10 BLOCK）。
  • 经纪人代表球员时，签约需经仲裁审查（防自我交易）。
