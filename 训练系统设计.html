1设计原则

核心定位：训练系统是成长线引擎在"每日循环"中的操作接口。经理每天 09:30 前提交训练安排，10:00 结算后产生成长增量、Condition 变化与伤病风险判定。它是"养成"玩法的把手，而非 sim 背景数据。
① 有后果的决策 核心
每次训练安排都是投入产出博弈：高强度=快成长但高伤病+高疲劳；低强度=安全但成长慢。没有"免费午餐"。
② 与成长线对齐 约束
训练不绕过 Peak 天花板、不绕过 Trainability 衰减、不绕过技术熟练度定型。训练是"逼近天花板"的手段，不是"打破天花板"的捷径。
③ 负荷可见可控 体验
球员负荷（Load）是独立可见指标，累积影响伤病概率与 Condition 恢复。经理能直观看到"红灯球员"。
④ 异步与确定性 架构
训练结算在世界时钟 10:00 统一执行，使用确定性 PRNG（mulberry32 + seed），同输入同输出。支持回放与审计。

1.1 不做什么

  • 不做即时训练：训练不是点击立即生效的数值泵，而是每日结算的异步系统，与比赛 sim 共享时钟节奏。
  • 不做无脑最高强度最优：高强度训练有明确的伤病风险与 Condition 代价，让"科学轮换+恢复训练"成为合理策略。
  • 不做忽略年龄的训练：老将训练效率天然衰减（ageDecay），强行高压训练只会加速衰退而非逆生长。
  • 不做脱离场景的训练：训练侧重需与球队战术、球员特质、赛程密度联动——背靠背赛程不该安排极限强度。

2系统总览与架构

2.1 训练系统在游戏循环中的位置

球探/选秀/签约 → 制定训练计划（侧重+强度+类型） → 09:30 提交截止 → 10:00 训练结算 → 成长增量 / Condition / 伤病判定 → 10:00 比赛结算 → 16:00 翻天（Condition 恢复 / 事件）

训练结算与比赛结算共享同一结算窗口（10:00）。训练先于比赛执行——意味着当日训练产生的 Condition 变化会直接影响当日比赛 sim。

2.2 四层架构

层名称职责
L1输入层 Input Layer经理提交训练计划（训练侧重 / 强度 / 类型 / 目标球员）；青训学院默认计划
L2结算层 Settlement Layer每日 10:00 执行：计算成长增量、Condition 消耗、Load 累积、伤病判定。纯函数 + 确定性 PRNG
L3反馈层 Feedback Layer生成训练报告（成长变化、负荷状态、伤病预警、教练评语）
L4修正层 Modifier Layer设施等级、教练组、teaching、青训血脉等加成注入 L2 计算

2.3 核心数据结构

── 训练计划（经理每日提交） ── TrainingPlan = { teamId: TeamId, seasonDay: u8, // 赛季日（1-180） focus: TrainingFocus, // 均衡/单项侧重/双项侧重/防守专精/体能恢复 focusTarget: [AbilityKey?], // 侧重目标能力（单项/双项时必填） intensity: Intensity, // light / normal / heavy /极限 sessionType: SessionType, // 个人/团队/专项/恢复（§3） targetPlayers: [PlayerId], // 该计划适用球员列表 submittedAt: Timestamp, } ── 球员训练状态（每日结算后更新） ── TrainingState = { playerId: PlayerId, load: f32, // 累积负荷 0-100（§5） loadTrend: [f32], // 近 7 日负荷序列 lastGrowth: Map<AbilityKey, f32>, // 上次训练成长增量 fatigueRisk: f32, // 当前疲劳伤病风险系数 0-1 trainingStreak:u8, // 连续训练日数（影响 bonus/penalty） recoveryStreak:u8, // 连续恢复日数 }

3训练类型体系

训练按 SessionType 分为四大类，每类有不同的成长侧重、Condition 消耗与伤病风险特征。经理可针对不同球员组合安排不同类型。

Individual		指定能力值成长（受 TrainingFocus 调控）中（-8~-15）中日常培养主力轮换，针对性补短板
团队训练
Team		战术执行度↑、化学反应↑、团队篮板/助攻熟练度↑低（-5~-10）低新援融入、战术磨合、连败后提振

3.2 个人训练的侧重模式

个人训练继承成长线 §9.1 的 TrainingFocus 体系：

3.3 专项训练的技术目录

专项训练针对技术熟练度（成长线 §4.6）进行突破，与能力值成长正交。每项技术有独立的熟练度上限（受少年期定型影响）。

进攻专项
三分投射 / 中距离 / 突破上篮 / 低位单打 / 挡拆持球 / 挡拆顺下 / 罚球
防守专项
单防 / 协防 / 护筐 / 抢断 / 篮板卡位 / 挡拆挤过
组织专项
传球视野 / 推进节奏 / 阵地组织 / 快攻发起
体能专项
耐力 / 爆发力 / 横移速度 / 弹跳
专项训练与个人训练的区别：个人训练提升能力值（如 ThreePT rating），受 Trainability 和 Peak 限制；专项训练提升技术熟练度（如三分熟练度 1-10），影响能力值转化为实际表现的效率。两者可同日安排给不同球员，但同一球员同日只能选一种。

3.4 训练类型组合规则

  • 同日单一：同一球员每日只能安排一种训练类型（个人/团队/专项/恢复四选一）。
  • 队内混排：经理可为不同球员安排不同类型——如主力安排团队训练磨合战术，替补安排个人训练补短板，老将安排恢复训练。
  • 青训苗子：青训苗子的训练独立于职业队，由青训学院默认计划驱动（§10）。
  • 比赛日限制：当日有比赛的球员，训练强度上限自动锁定为 normal（不可 heavy/极限），防止赛前过劳。

4训练计划与日程

4.1 训练计划的生命周期

制定计划（任意时间） → 09:30 提交截止 → 锁定不可改 → 10:00 结算执行 → 生成报告

训练计划可在赛季日内的任意时间制定和修改，但 09:30 为提交截止（与世界时钟对齐）。截止后当日计划锁定，不可再改。10:00 结算时统一执行。

4.2 默认计划与继承

为降低每日操作负担，系统支持默认计划继承：

  • 首次设置：经理首次进入训练界面时设置默认计划（如"全队个人训练·均衡·normal"）。
  • 自动继承：若某日经理未手动修改，系统自动继承前一日的计划。
  • 智能提醒：当赛程出现背靠背、伤病潮、新援加盟等情况时，系统弹出提醒建议调整。
  • 青训学院：青训苗子使用学院级默认计划，经理可整体调档但无需逐人设置。

4.3 训练计划模板

经理可保存常用计划为模板，一键应用到全队或指定分组：

模板名类型侧重强度适用场景
常规赛日常个人均衡normal常规比赛日，稳定成长
背靠背恢复恢复—light连续比赛日，保护主力
战术磨合期团队—normal新援加盟后 2-3 周
季后赛冲刺专项针对对手弱点heavy季后赛前针对性补强

5.1 四档训练强度

5.2 负荷 Load 系统

Load 是球员累积疲劳的独立指标（0–100），与 Condition（单日体力）不同——Condition 每日恢复，Load 是多日累积。

── Load 计算 ── load[p] = load[p] * 0.92 + dailyLoadGain[p] // 每日衰减8% + 新增量 dailyLoadGain[p] = intensityLoad[session] * durabilityMod[p] // Durability高→负荷累积慢 * ageMod[p] // 老将负荷累积快 + gameLoad[p] // 当日比赛消耗追加 // Load 影响 load > 70 → injuryRisk * 1.5, Condition 恢复 * 0.8 load > 85 → injuryRisk * 2.0, Condition 恢复 * 0.6, 训练效率 * 0.7 load > 95 → injuryRisk * 3.0, 强制 rest（系统自动安排恢复）

5.4 负荷管理策略

设计意图：Load 系统让"负荷管理"成为真实可玩的策略——经理需要在"冲击战绩（主力多打多练）"与"保护球员（轮休+恢复训练）"间权衡。忽视 Load 的经理会遭遇伤病潮，过度保护 Load 的经理则成长缓慢。这是训练系统最核心的博弈点。

6训练效果计算引擎

训练结算在每日 10:00 执行，纯函数 + 确定性 PRNG，同输入同输出。

6.1 个人训练成长计算

── 个人训练每日成长增量 ── growthDelta[ability] = baseGrowthRate[ability] * EffectiveTrainability[p] // 成长线§9.2 ageDecay * TrainingFocus[ability] // 侧重倍率 0.5~2.0 * intensityGrowthMod[session] // light×0.5 ~ 极限×2.0 * facilityMod // 设施等级加成 §9 * coachMod // 教练组加成 §9 * teachingMod // 老将 teaching 加成 * loadEfficiencyMod[p] // Load过高→效率下降 * streakBonus[p] // 连续训练奖励 // Peak 限制：成长不可超过 Peak newRating = min(currentRating + growthDelta, Peak[ability]) // 接近 Peak 时成长递减（最后10点慢速逼近） proximityMod = (Peak - newRating) < 10 ? (Peak - newRating) / 10 : 1.0

6.2 团队训练效果

── 团队训练每日效果 ── chemGrowth = baseChemRate * intensityMod * coachMod // 化学反应 +chemGrowth（受 Sim Engine §11 化学修正上限约束） tacticFamiliarity += baseFamRate * intensityMod // 当前预设战术的执行度 +（影响 Sim Engine 战术修正强度） teamSkillGrowth = { teamRebound: +val, // 团队篮板熟练度 teamAssist: +val, // 团队传导熟练度 defenseSync: +val, // 防守协同度 } // 团队训练不提升个人能力值，但提升团队级修正 // 化学反应、战术执行度、团队熟练度 → Sim Engine Modifier Layer

6.3 专项训练效果

── 专项训练每日效果 ── skillExpGain = baseSkillRate * intensityMod * coachSpecialtyMod // 技术熟练度升级阈值（指数递增） threshold[lv] = 100 * 1.5^(lv-1) // lv1→2: 100exp, lv2→3: 150, lv3→4: 225, ... lv9→10: 3844 // 熟练度上限受少年期定型限制（成长线§4.6） newSkillLv = min(currentLv + upgrade, skillCap[p])

6.4 恢复训练效果

── 恢复训练每日效果 ── conditionGain = 25 * facilityMod * medicalStaffMod // Condition +conditionGain（上限100） loadReduction = 15 * medicalStaffMod // Load 直接削减（而非靠衰减） fatigueRisk = max(0, fatigueRisk - 0.15) // 疲劳风险系数下降 // 恢复训练不产生任何能力成长（growthDelta = 0）

7.3 ageDecay 与训练效率

训练效率天然受球员年龄影响（成长线 §9.2）：

年龄段ageDecay训练表现策略建议
8–15（青训期）×1.0满效率童子/少年期是训练黄金窗口，决定一生 Trainability 上限
16–22（青年期）×0.95微衰技术定型关键期，专项训练价值最高
23–28（巅峰期）×0.80下降能力值逼近 Peak，转向维持+专项

8训练伤病风险模型

8.1 每日伤病判定

训练结算是每日伤病判定的两个触发点之一（另一个是比赛结算）。训练伤病风险独立于比赛伤病。

── 训练伤病判定 ── trainInjuryChance[p] = baseInjuryRate // 基础率 0.3% * intensityRiskMod // light×0.6 ~ 极限×2.5 * loadRiskMod[p] // Load区段修正 §5.2 * durabilityMod[p] // Durability高→风险低 * ageRiskMod[p] // 老将风险更高 * facilityProtectMod // 设施伤病防护 §9 * medicalStaffMod // 医疗组防护 * sessionTypeRiskMod // 恢复×0.1 / 团队×0.7 / 专项×1.5 if (rand(seed) < trainInjuryChance): injury = rollInjury(seed, p) // 判定伤情等级（轻微/中度/重度）

8.2 伤情等级

等级概率缺阵影响
轻微（扭伤/拉伤）60%1–3 日Condition 暂降；不影响能力值
中度（肌肉撕裂/关节）30%4–14 日Condition 大幅下降；相关能力暂时 -3~5
重度（韧带/骨折）10%15–90 日赛季报销风险；Durability 永久 -0.1

8.3 训练特有伤病类型

过劳伤 高风险

13特殊训练模式

13.1 针对性训练（季后赛）

季后赛前可启动针对性训练，针对对手弱点集中突破：

  • 触发条件：季后赛系列赛确定对手后。
  • 效果：专项训练效率 ×1.3；可选择"针对对手"方向（如对手三分弱→己方三分专项加成）。
  • 代价：Load 增量 ×1.5；伤病风险 ×1.3。短期博弈。
  • 限制：每轮系列赛仅可启动 1 次，持续 3 日。

13.2 特训营（休赛期）

  • 触发：赛季间隔期。
  • 效果：集中 7 日特训，单项能力成长 ×2.0，但 Load 重置后重新累积。
  • 限制：每名球员每休赛期仅可参加 1 次特训营；需支付额外费用。
  • 风险：特训营有 5% 概率触发"特训伤"，影响赛季初状态。

13.3 心理训练

  • 效果：提升 Mental Fortitude（心理素质）和 Clutch IQ 成长，不提升身体能力。
  • 触发条件：需心理咨询师（教练组扩展角色）。
  • 适用：关键战前、连败后士气低落、年轻球员心理成长窗口。
  • 限制：每周仅可安排 2 次心理训练（避免过度干预）。

13.4 teaching 训练日

队内有 teaching 老将时，可安排"teaching 训练日"——老将不参加正常训练，转为指导年轻球员：

  • 年轻球员（23 岁以下）训练效率 +teaching × 2%。
  • 老将当日 Condition 不消耗（教学不耗体力）。
  • 特质觉醒概率 +teaching × 1%。
  • 每日最多 1 名老将进行 teaching，受影响年轻球员最多 3 名。

14训练与化学反应

14.1 团队训练对化学反应的驱动

团队训练是提升化学反应（Sim Engine §11）的主要主动途径。化学反应影响团队传球失误、篮板协同、防守协防等。

── 团队训练化学反应成长 ── chemGrowth = baseChemRate // 0.5/日 * intensityMod // normal×1.0 ~ heavy×1.3 * coachMod // 主教练战术加成 * rosterStabilityMod // 阵容稳定性：连续同阵容训练加成 * newPlayerPenalty // 新援加盟初期 chem 下降 // 化学反应上限 1.0；接近上限时成长递减 proximityMod = (1.0 - chem) < 0.2 ? (1.0 - chem) / 0.2 : 1.0

14.2 阵容稳定性与化学反应

阵容状态chem 影响恢复方式
连续 5+ 日同阵容训练chemGrowth ×1.2—
新援加盟chem -0.15团队训练恢复

14.3 训练侧重与战术适配

团队训练的战术执行度成长与当前预设战术（战术系统）挂钩：

  • 团队训练提升当前预设战术的执行度，执行度影响 Sim Engine 中战术修正的强度。
  • 切换预设战术后，原战术执行度衰减（-0.05/日），新战术从基础执行度开始。
  • 频繁切换战术会导致多个战术执行度都不高——鼓励经理确定战术体系后持续磨合。
  • 传承系统的"战术偏好遗产"（成长线 §10.2）让适配传统战术的球员训练效率 +10%。

16异常处理与边界规则

16.1 球员状态异常

异常状态训练处理
球员受伤中不可安排训练（强制 rest）；医疗组进行康复训练（不影响能力值）
球员被交易当日训练计划自动取消，新球队次日生效
球员退役训练计划移除；若转教练轨，转为 teaching 来源
球员停赛可正常训练（停赛不影响训练）
全队事件（如罢训）当日训练取消，Condition 不变，无成长

16.2 计划冲突处理

  • 同一球员多计划：系统取最后提交的计划，前者覆盖。
  • 比赛日+heavy 训练：系统自动降级为 normal，并通知经理。
  • Load 95+ 强制 rest：经理计划被系统覆盖为 rest，不可强制执行。
  • 青训苗子极限强度：永久禁用，系统拒绝提交。

16.3 结算异常

  • 结算失败：训练结算为纯函数，失败时回滚至结算前状态，重试。
  • 数据不一致：通过确定性 PRNG 重放验证——同 seed 同输入必须同输出。
  • 世界维护期：维护期内训练暂停，维护结束后补结算（仅成长，不补伤病判定）。

16.4 新经理引导

  • 新经理首赛季训练界面提供引导教程，推荐"均衡 normal"默认计划。
  • Load 系统首次触发警告时弹出说明面板。
  • 侧重/专项/teaching 等进阶功能在经理声望达到一定等级后解锁。
