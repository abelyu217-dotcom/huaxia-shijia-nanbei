System Design Document · v1.0

三身份系统设计 Triple Identity System · HWO

每位玩家同时持有三个身份——球队经理（主身份）、球员化身（自创 1 名球员）、职业人（11 职选一，可转职）。三身份共享同一账号资源池，构成去中心化的多人经济内循环：经理雇佣职业人、签约球员；球员接受合同出战；职业人提供服务赚取薪资。本系统定义三身份的数据模型、生命周期、流动规则与反套利机制。

1设计原则与架构

1.1 核心设计命题

三身份 = 一个玩家、三种角色、一套资源池。传统经理游戏玩家只是"上帝视角的经理"；本作让玩家同时成为劳动力（化身）与服务者（职业人），使每个玩家既是雇主又是雇员，构成无需 NPC 注资的去中心化经济。
  • 主身份常驻：经理身份始终存在且不可放弃；化身与职业人为"侧线身份"，可流动、可转职、可退役。
  • 资源池共享：三身份赚得的 Credits、声望、人脉均汇入同一账号；但合同/薪资分账——化身合同属化身，职业人佣金属职业人，避免资金无界混淆。
  • 身份互不碾压：化身再强也不能直接给本队刷分；职业人再顶级也不能替经理做阵容决策。三身份产出各自独立，仅通过"市场交易"互通。
  • 反套利优先：任何可能造成"自己跟自己交易获利"的路径必须被规则阻断（见 §10）。

1.2 三身份一览

身份数量核心产出流动性常驻性
① 球队经理 Manager1（固定）球队战绩、王朝、世界排名不可放弃；可被接管他队（赛季末）常驻
② 球员化身 Avatar1（自创）个人数据、合同薪资、名人堂可效力本队 / 跳出 / 回归 / 退役流动
③ 职业人 Professional1（选一职，可转职）受雇服务、佣金抽成、职业声望可被雇佣 / 应聘预设岗 / 转职流动

1.4 身份生命周期总览

注册创建经理
选职化身 + 职业人
并行三身份同时活动
流动化身跳出/转职

注册即创建经理身份；完成新手引导后解锁化身创建与职业人选职。此后三身份并行活动直至赛季/生涯节点触发流动或沉淀。任一身份的终态均不影响其他身份继续运行。

2身份一 · 球队经理（主身份）

经理是玩家的主身份与上帝视角，承担策划方案 §3.1 所述全部球队经营权。本节定义经理身份的数据结构与权力边界，避免与其他系统重复定义行为细节。

2.1 经理身份数据结构

ManagerHandle = { managerId: u64, teamId: u32, // 当前执教球队 hiredAt: Timestamp, history: [TenureRecord], // 执教履历（跨球队） powers: { roster: bool, // 阵容管理权 tactics: bool, // 战术权（战术系统） training: bool, // 训练权（成长线） transfer: bool, // 转会/合同权（经济系统） academy: bool, // 青训学院经营权 finance: bool, // 财务权 staff: bool, // 职员雇佣权（雇佣职业人） }, reputation: i32, // 经理声望（§11） }

2.2 经理权力与系统映射

权力对应系统说明
阵容/战术/训练战术系统 / 成长线 / Sim Engine直接操控本队球员的出场、成长、比赛执行。
转会/合同经济系统 §3-5签约自由球员（含他人化身）、跨经理交易、选秀。

青训/财务经济系统 §7 / 成长线经营青训学院、管理薪资空间与收支。

2.3 经理身份的接管与流动

赛季末窗口：经理可在赛季结算后的"接管窗口"申请跳槽到同世界空缺球队（被 AI 接管或玩家放弃的球队）。跳槽带走的是经理声望与人脉，不带走红名单球员（除非交易）。
  • 跳槽冷却：连续 3 个赛季不得跳槽，防止"经理游牧"破坏世界稳定。
  • 降级连带：若经理原球队降级，跳槽到高级别球队需支付"违约金"（从声望扣除）。
  • 不可放弃：经理身份不可注销；玩家离线后球队由 AI 代管（按玩家战术存档执行）。

3身份二 · 球员化身

每位玩家自创 1 名球员化身进入世界球员池。化身享有与所有球员相同的完整生涯弧线（成长线系统）与业余金字塔，是玩家"亲自养一个自己"的养成入口。化身是流动的劳动力——可效力本队、跳出、回归、退役。

3.1 化身创建参数

参数选项影响
年龄8–22 任选决定成长阶段入口、训练响应率基数、可效力层级上限
位置PG / SG / SF / PF / C注册不锁风格；影响战术槽位适配与轮换定位
球员风格终结型 / 3D / 组织型 / 空间型 / 蓝领 / 全能 / 锚点决定能力初始分布倾向与战术偏好遗产
球员性格冷血杀手 / 团队领袖 / 独狼 / 大心脏 / 玻璃心 / 老好人 等影响 AI 决策倾向、clutch 表现、化学反应、续约谈判
家庭背景体育世家 / 普通家庭 / 单亲 / 留学背景 / 体校出身 等影响初始 Fame、青训起点、业余金字塔初始层级、训练设施可及性（家庭系统）
天赋 Peak 不可指定：Peak 由系统在创建时按家庭背景与随机生成，玩家不可直接指定——保留迷雾与惊喜。同样的 Peak 下，风格+性格+家庭三者交织走出截然不同的生涯。

3.3 化身的流动机制

效力本队 默认
化身占本队一个名单+薪资，享受玩家亲自训练/战术倾斜。化身与经理身份的利益绑定最紧。
跳出本队 流动
化身主动跳出进入世界球员池，被其他经理签约。玩家失去直接控制权，化身转为 ai_controlled，但仍在世界内 sim 成长——玩家可"旁观其生涯"。
回归本队 召回
化身可被本队重新签回（若薪资空间允许）。回归后恢复 owner_controlled。合同期内不可单方面召回，需买断或等合同到期。
化身退役 沉淀
化身走完生涯（年龄/能力衰退触发）后退役进名人堂，时代标签可反哺本队传承。退役后化身不可复出，但玩家可创建新化身（受冷却）。

3.4 跳出决策与控制权交接

关键设计：化身跳出本队后，玩家不能远程操控化身在别队的表现——这是"流动劳动力"的本质。玩家只能旁观其 sim 生涯。这确保化身在他人队中是真实劳动力而非"玩家的卧底"。
  • 跳出条件：合同到期 / 主动买断 / 球员不满（性格触发，如独狼长期被弃用）。跳出需冷却 1 赛季，防止反复横跳。
  • AI 决策依据：跳出后的化身由 AI 按其性格 + 能力 + 战术偏好遗产自行决策出场与出手，与他队战术系统适配。
  • 旁观权限：玩家可订阅化身的比赛 PBP 推送、查看其 Box Score 与成长，但不能干预。
  • 利益冲突：当化身所在他队与本队交手时，玩家不得利用经理身份针对/放水——系统记录并校验（§10）。

3.5 化身创建/退役冷却

事件冷却说明
首次创建化身无新手引导后即可
化身退役后创建新化身1 赛季防止快速刷化身套利
主动注销化身2 赛季惩罚性冷却，避免随意弃号

4身份三 · 职业人系统总览

玩家从 4 线 × 11 职中选一作为第三身份。职业人可被其他球队经理雇佣，也可到游戏预设的 NPC 岗位应聘，提供服务赚取薪资/佣金。职业人身份是去中心化经济的服务供给侧。

4.3 两种上岗方式

① 被球队经理雇佣 玩家雇主
经理在"职员市场"发布岗位（如"招募球探"），职业人应聘；或职业人主动毛遂自荐。雇佣关系存续期间，职业人为该队服务并领薪。
② 应聘预设岗位 NPC 岗位
游戏在世界内预设若干 NPC 岗位（如联盟官方记者、预设 AI 球队的教练、青训学院训练师）。职业人可应聘这些岗位，获得稳定收入与声望，无需依赖玩家雇主。
设计意图：预设岗位保证职业人身份"即使无人雇佣也有事可做"，避免新世界初期玩家雇主稀少时职业人沦为摆设。预设岗位产出由 AI 模拟，质量随职业人技能/等级提升。

5职业人详细规格（11 职）

逐一定义每个职业的核心职能、产出物、产出公式、对其他系统的影响。产出公式中 skillRoll 表示职业技能检定（§6），lvl 为职业等级。

5.1 技术线（4 职）

球探 Scout

  • 职能：受雇为某队探查目标球员/青训苗子，产出 fog 收窄报告（迷雾系统）。
  • 产出物：ScoutReport——把目标球员的迷雾能力区间收窄（如三分从 ±15 收窄到 ±8）。
  • 产出公式：
    fogNarrow = baseNarrow(targetAge) + skillRoll(scouting) × 0.6 + lvl × 0.4 - distancePenalty
  • 系统影响：直接降低签约/选秀的信息风险；报告存档可被雇主查看。

助理教练 Asst. Coach

  • 职能：受雇提升某队训练效率/特定能力培养。
  • 产出物：TrainingBoost——目标训练方向的训练响应率加成。
  • 产出公式：
    trainEffMod = 1.0 + (skillRoll(coaching) × 0.15 + lvl × 0.01) × specMatch
    （specMatch：专长方向与训练方向匹配度 0.5–1.0）
  • 系统影响：影响成长线系统的训练响应率；经济系统 §7.2 教练组加成落地。

主教练 Head Coach 高级

  • 职能：受雇接管他队战术执行（玩家不亲任时，或 AI 球队聘请玩家执教）。
  • 产出物：TacticsExecMod——战术执行修正、轮换质量。
  • 声望门槛：需前一职业（助理教练）达到声望门槛方可转入（§8）。
  • 特殊：玩家以职业人·主教练身份执教他队时，不能同时用经理身份执教本队与之交手——触发利益冲突回避（§10）。

训练师 Trainer

  • 职能：受雇降低球员伤病风险、加速 condition 恢复。
  • 产出物：InjuryRiskMod / RecoveryRate。
  • 产出公式：
    injuryRiskMul = 1.0 - (skillRoll(training) × 0.20 + lvl × 0.015)
    recoveryMul = 1.0 + skillRoll(training) × 0.3 + lvl × 0.02
  • 系统影响：影响成长线伤病抗性与 Sim Engine 疲劳恢复。

5.2 商业线（3 职）

经纪人 Agent

  • 职能：代理球员（含他人化身）谈判合同，抽成。
  • 产出物：ContractNegotiation——为客户争取更高合同额/更好条款。
  • 抽成：合同总额的 5–10%（随技能/等级提升谈判力，抽成率固定）。
  • 产出公式：
    contractBonus = baseSalary × (skillRoll(negotiation) × 0.12 + lvl × 0.01)
  • 反套利：玩家不得代理本队化身/本队球员签异常合同（§10）。

商人 Merchant

  • 职能：运营赞助/周边，为球队拉赞助分成。
  • 产出物：SponsorDeal / MerchRevenue。
  • 产出公式：
    sponsorMul = 1.0 + skillRoll(commerce) × 0.25 + lvl × 0.02 × marketProsperity
  • 系统影响：经济系统 §6.3 赞助商 / §6.5 周边。

球馆运营 Arena Ops

  • 职能：受雇提升球馆收入与上座率。
  • 产出物：AttendanceBoost。
  • 产出公式：
    attendanceMul = 1.0 + skillRoll(operations) × 0.18 + lvl × 0.015
  • 系统影响：经济系统 §6.2 球票收入 / §7.4 球馆系统。

5.3 媒体线（2 职）

记者 Reporter

  • 职能：撰写赛事/转会报道，影响舆论与球员 Fame。
  • 产出物：Article——影响目标球员/球队的 Fame 与舆论倾向。
  • 产出公式：
    fameDelta = (skillRoll(writing) × 0.5 + lvl × 0.1) × tone × reach
    （tone: ±1 褒贬；reach: 发布渠道覆盖度）
  • 系统影响：球员 Fame 影响薪资/签约（经济系统）；舆论影响化学反应。

解说员 Caster

  • 职能：解说关键战，提升赛事曝光与球迷粘性。
  • 产出物：BroadcastBoost——提升单场赛事的曝光与球市热度。
  • 产出公式：
    exposureMul = 1.0 + skillRoll(casting) × 0.2 + lvl × 0.02

5.4 管理线（2 职）

联盟仲裁人 Arbiter 高级

  • 职能：裁决失衡交易申诉、仲裁合同纠纷。
  • 产出物：ArbitrationVerdict——对申诉交易作出裁决（通过/驳回/改判）。
  • 声望门槛：需高声望方可担任，确保裁决公正性。
  • 收益：案件费 + 官方津贴；裁决被多数申诉人认可则声望+，被推翻则声望−。

球员工会代表 Union Rep

  • 职能：代表球员利益，影响劳资规则与最低薪。

9三身份经济内循环

循环示意：玩家 A（经理）雇佣玩家 B（职业人·球探）→ B 为 A 产出报告领薪 → A 据报告签约玩家 C（球员化身）→ C 出战为 A 赢球 → C 经由玩家 D（职业人·经纪人）谈下份大合同 → D 抽成。每个玩家同时是 A/B/C，身份在循环中流动，构成去中心化的多人经济。

9.1 循环图

经理 A · 雇佣 → 职业人 B · 服务领薪 → 经理 A · 据报告签约 → 化身 C · 出战赢球 → 职业人 D · 经纪抽成 ↻

货币在三身份间流动，不依赖系统注资：经理付薪给职业人（货币从 A→B），化身合同薪资由雇主球队支付（球队→C），经纪人从合同抽成（C 的薪资→D）。整个循环是世界内封闭的劳动力+服务市场。

9.2 两大封闭市场

市场供给侧需求侧定价
劳动力市场球员化身池 + 自由球员 + 选秀池球队经理（签约出战）合同薪资（经济系统 §3）
职业人市场职业人身份（11 职）球队经理（雇佣）+ 预设岗位职员薪资/佣金（§7）
  • 世界内封闭：两市场均世界内封闭，球员/职业人不跨世界流通（保证公平与经济体量可控，策划方案 §4.1）。
  • 价格发现：薪资/佣金由供需决定；顶级职业人稀缺 → 高薪；球员过剩 → 薪资下行。

9.3 与经济系统的衔接

三身份的货币流动落地于经济系统的账户体系：经理薪资支出记入球队财务（§8），职业人收入记入个人钱包，化身合同薪资记入球队薪资空间（§5 工资帽）。本系统定义身份与流动规则，金额计算与工资帽约束由经济系统负责，避免重复定义。

9.4 声望互通

三身份声望汇入玩家整体"经理声望积分"，影响世界排名（§11）。但各身份声望独立计算：经理声望看战绩、化身声望看个人成就、职业声望看服务评价，三者加权汇总而非简单相加。

10利益冲突回避与反套利

核心风险：玩家同时持三身份，存在"自己跟自己交易获利"的套利空间。如：经理身份给自己化身开天价合同（球队资产→个人）；经纪人身份代理本队化身抽成（双重抽水）；仲裁人身份偏袒本队交易。所有此类路径必须被规则阻断。

10.1 反套利规则矩阵

风险场景套利路径阻断规则

10.2 自动校验机制

function checkConflict(accountId, transaction) { if (transaction.type == "avatar_contract" && transaction.avatar.ownerId == accountId && transaction.salary > marketAvg × 1.2) return "FLAG_REVIEW"; // 触发仲裁审查 if (transaction.type == "agent_represent" && transaction.client.ownerId == accountId) return "BLOCK"; // 直接阻断 if (transaction.type == "arbiter_case" && case.involvesAccount(accountId)) return "REASSIGN"; // 转交他人 }

10.3 审计与惩罚

  • 冲突日志：所有涉及自身账号的交易记入 conflictLog，可被仲裁人/官方审计。
  • 分级处理：BLOCK（直接阻断）→ FLAG_REVIEW（标记审查）→ REASSIGN（转交）。
  • 违规惩罚：查实套利则没收不当所得、扣除声望、严重者冻结相关身份 1 赛季。

11声望系统与积分汇总

三身份各有独立声望，加权汇总为经理声望积分（Manager Reputation Score），影响世界排名（策划方案 §3.6）。

11.1 三身份声望来源

身份声望来源计算口径

化身声望个人数据、全明星、名人堂、时代标签生涯成就累计；退役时结算名人堂资格

11.2 经理声望积分公式

managerScore = wM × norm(managerRep) + wA × norm(avatarRep) + wP × norm(proRep) + leagueTierBonus // 联赛层级加成 + dynastyBonus // 王朝成就加成 // 权重（经理为主，化身/职业为辅） wM = 0.55, wA = 0.25, wP = 0.20
权重设计：经理是主身份，权重最高；化身养成是长线情感钩子，权重次之；职业人是经济内循环润滑剂，权重最低但不可或缺。三者叠加使"全面发展"的玩家排名高于"偏科"玩家。

11.3 世界排名

  • 排名维度：联赛层级 + 战绩 + 化身成就 + 职业成就 + 王朝成就（策划方案 §3.6）。
  • 分层展示：世界总榜 / 联赛榜 / 同级榜，方便玩家定位。
  • 赛季重置：每赛季排名按上赛季结算分重排，新增本赛季动态分。

13AI 职业人决策

未被人接管的职业人岗位由 AI 职业人填充，随真实玩家增加逐步替换。AI 职业人需拟真决策，保证世界初期服务供给不断档。

13.1 AI 职业人生成

  • 等级分布：按金字塔分布，多数 3–5 级，少量 7–8 级，极少数 9–10 级（顶级稀缺）。
  • 技能分配：随机但有倾向（如 AI 球探偏苗子探查或职业评估之一支）。
  • 声望：与等级正相关，避免低级高声望的不合理组合。

13.2 AI 职业人行为规则

行为AI 决策依据
应聘岗位按等级/声望匹配可应聘岗位；高级 AI 优先应聘高薪岗
服务产出按技能点+等级+随机波动 sim 产出，与玩家职业人同公式
转职低概率转职（模拟职业流动）；满足声望门槛时可能晋升高级职业
挖角响应玩家高薪挖角时，AI 按当前合同剩余/薪资差距决定是否跳槽

13.3 AI 化身决策（跳出后）

玩家化身跳出本队后转为 ai_controlled，其比赛决策由 AI 按性格 + 能力 + 战术偏好遗产执行，与战术系统/Sim Engine 中其他 AI 球员一致。这确保化身在他队是真实劳动力而非玩家卧底。

14身份切换与并发规则

玩家同时持三身份，需明确"何时以哪个身份行动"及并发约束，避免身份混淆与操作冲突。

14.1 身份上下文

UI 通过身份上下文切换明确当前操作归属哪个身份。每个界面顶部显示当前身份标签，操作自动归属该身份。

身份上下文主要操作切换限制
经理（默认）阵容/战术/训练/转会/职员雇佣始终可切回；默认上下文
化身查看化身生涯/数据/合同；效力本队时训练侧重跳出后只读（旁观）；本队时可干预训练
职业人应聘/服务执行/技能升级/转职受雇任务有截止时间，需在窗口内执行

14.2 并发约束

  • 每日行动点：三身份共享每日行动点池（与每日制一致），防止一人三身份无限操作。经理操作消耗主体，化身/职业人操作消耗少量。
  • 时间锁：同一球员/职员同一时段只能被一个身份操作（如化身训练与经理战术布置不冲突，但化身合同谈判与经纪人服务不可同时进行）。
  • 交手回避：职业人·主教练身份执教他队时，遇本队交手自动 AI 代执教（§10）。

14.3 离线代管

  • 经理离线：球队由 AI 按玩家战术存档执行（战术系统 §14）。
  • 化身离线：效力本队时按经理设置 sim；跳出后始终 AI sim。
