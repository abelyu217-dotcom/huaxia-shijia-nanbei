1经济总览与核心命题

1.1 设计目标

HWO 的经济系统不是"账本"，而是博弈场。每个经理在有限薪资空间下做资源配置决策：签谁、放谁、投资什么、省在哪里。经济约束让"建队"成为真正的策略，而非简单堆砌强队。

1.2 核心命题

最健康的财务不是"少花"，而是"每一笔长约都有明确职责"。薪资空间是稀缺资源，花在核心球员身上的每一块钱都意味着别处少花一块。经济系统的乐趣来自"取舍"——你不可能同时拥有顶级核心、深厚板凳、一流球探和豪华球馆，必须选。

1.4 经济设计四原则

① 世界内封闭
每个世界是独立经济体，球员/货币/资源不跨世界流通。保证公平与经济体量可控。
② 服务端定价
球员薪资由服务端按能力+Peak+年龄+Fame+合同类型锚定，防止玩家间操纵或默契压价。
③ 付费不买强度
Credits/VIP 不产生薪资空间、不买球员强度、不买比赛结果。付费只买"快"与"美"。这是信任底线。
④ 天然通缩倾向
赛季结算消耗+球员退役流出>新秀注入，经济有轻微通缩倾向，防止薪资空间无限膨胀。

2.3 基础配额（BaseAllocation）

每赛季系统发放的基础薪资空间，确保所有球队有最低运营资金：

联赛层级基础配额转播分成说明
顶级联赛5,000×3.0最高转播分成，争冠球队的收入基础
次级联赛4,000×2.0冲击顶级的中坚层
第三级3,500×1.5发展中联赛
入门级3,000×1.0新经理起步，最低收入
设计意图：联赛层级差异制造升降级赌注——升级不只是荣誉，更是收入翻倍。顶级联赛球队天然有钱签更好的球员，形成"强者愈强"的正反馈，但奢侈税和赛季折旧构成刹车。

3球员薪资系统

3.1 薪资计算公式

球员薪资由服务端按以下公式锚定，玩家无法直接设价——只能选择"接受系统报价"或"放弃签约"。

BaseSalary = ratingToSalary(OverallRating) × AgeModifier × FameModifier × ContractTypeModifier // 能力→薪资映射（非线性，强者溢价） ratingToSalary(rating): 90–99 → 800–1,500/季 // 顶级球星，顶薪区 80–89 → 400–800/季 // 全明星级 70–79 → 200–400/季 // 主力首发 60–69 → 80–200/季 // 轮换球员 50–59 → 30–80/季 // 边缘/底薪 // 年龄修正（峰值在 24–28 岁） AgeModifier: 19–22 → 0.7 // 新秀红利期，低薪高性价比 23–25 → 0.9 // 上升期 24–28 → 1.0 // 巅峰期，全价 29–31 → 0.95 // 微降 32–34 → 0.75 // 老将折扣 35+ → 0.50 // 老将底薪区 // Fame 修正（球星溢价） FameModifier = 1.0 + Fame × 0.005 // Fame 0–100 → 1.0–1.5 // 合同类型修正 ContractTypeModifier: 新秀红利 → 0.4 // 前 4 年固定低价 底薪 → 0.3 // 联盟最低薪 中产 → 1.0 // 标准市场价 顶薪 → 1.3 // 溢价锁定核心 老将底薪 → 0.25 // 31+ 特例

3.2 合同类型详解

类型年限薪资水平特点适用场景风险
新秀红利 性价比 4 年（固定） 市场价的 40% 选秀后自动签订；前 4 年固定低价；第 3 年末球队选项（可提前续约或放走） 所有新秀 第 4 年后续约可能大涨
底薪合同 1–2 年 联盟最低薪（30–50/季） 无保障；裁员即释放空间 填充名单末端、短期补缺 随时可裁，无成本
中产合同 标准 2–4 年 市场价（200–400/季） 标准合同；部分保障（裁人付 50% 买断费） 主力轮换、首发级球员 长约后期球员衰退→薪资陷阱
顶薪合同 核心 4–5 年 市场价 ×1.3（800–1,500/季） 全保障；占用大量空间；需"明确职责"（核心/二当家）才能签 球队核心、全明星级 顶薪球员衰退=灾难性薪资陷阱

3.3 合同保障条款

条款效果适用合同博弈意义
全保障裁人仍需支付剩余全部薪资顶薪顶薪签约=重承诺，裁不掉
部分保障裁人支付剩余薪资的 50%中产可裁但有成本，需权衡
无保障裁人即释放全部空间底薪、短约灵活但球员忠诚度低
球队选项合同最后年球队可选择执行或放弃新秀红利第 4 年、中产最后年给球队"见好就收"的权利
球员选项合同最后年球员可选择执行或跳出顶薪（少数）球星留后路，球队有失去风险
交易否决权球员可否决被交易到指定球队顶薪+高 Fame 球员限制交易灵活性，需在签约时接受

3.4 续约机制

  • 提前续约窗口：合同最后一年中途可提前续约，价格按当前能力重新锚定（可能比到期后更便宜，如果球员还在上升期）。
  • 到期自由球员：合同到期后球员进入自由市场，原球队有优先续约权——可以匹配任何报价留住球员，但需在 24 小时内响应。
  • 伯德条款：效力 3+ 年的球员续约时可超帽签约（仅限原球队），代价是占用更多未来空间。这让"自己养出来的核心"比"挖来的球星"更值。

3.5 球员心仪目的地

自由球员签约不是纯竞价——球员有"心仪目的地"倾向，影响接受概率：

AcceptChance = base(报价 / 市场价) × DestinationScore × LoyaltyFactor DestinationScore = f( 球市规模, // 大球市+，小球市- 球队战绩, // 强队+，弱队- 联赛层级, // 顶级联赛+，入门级- 球馆档次, // 豪华球馆+，破旧球馆- 家乡偏好, // 球员家乡+（部分球员有） 核心地位承诺, // 承诺首发/核心角色+ 同乡球员 // 队中有同乡队友+ ) // 报价低于市场价 70% → AcceptChance 极低 // 报价高于市场价 130% → AcceptChance 接近 100%（但薪资空间吃紧）
博弈核心：弱队想签球星必须溢价（报价 ×1.3+），强队可以折价签（球星愿意降薪争冠）。这模拟了现实中的"球星投奔强队"现象，同时让弱队重建有出路——选秀+青训+溢价签自由球员。

4转会与交易系统

4.1 三大转会通道

① 自由市场 竞价
世界内共享球员池。自由球员接受多队报价，按 AcceptChance 概率选择。报价即承诺——提交后不可撤回。
② 跨经理交易 谈判
同世界内任意两经理可发起交易。报价→还价/拒绝→薪资平衡校验→双方确认。AI 经理按需求+价值+fog 评估。
③ 选秀签约 独占
选秀中被选中的新秀自动与球队签新秀红利合同，不可拒绝。这是获取廉价天赋的主要通道。

4.2 自由市场流程

1
球探评估期（赛季末，3 天）
自由球员名单公布。经理可花球探预算收窄目标球员 fog。未收窄 fog 的球员报价=盲赌（可能签来发现 Peak 很低）。
2
报价窗口（3 天）
经理对心仪球员提交报价（合同类型+年限+年薪）。报价即承诺——提交后不可撤回，球员接受则薪资空间立即冻结。三查：位置缺口/薪资空间/情报。
3
球员决策（1 天）
系统按 AcceptChance 公式计算球员对所有报价的接受概率。多队报价时按概率加权选择。球员可能因心仪目的地倾向拒绝最高报价。
4
原队匹配（1 天，如有优先续约权）
若球员原球队持有优先续约权，可匹配报价留住球员。不匹配则球员转会，原队无补偿。
5
签约生效
合同生效，薪资空间扣除。未签约球员进入"剩余自由球员池"，赛季中可随时签约（但选择越来越少）。

4.3 跨经理交易机制

4.4 交易筹码类型

筹码说明交易价值
现役球员最常见筹码。价值=能力+Peak+年龄+合同性价比按市场价

4.5 买断与裁员

  • 裁员：随时可裁，但按合同保障条款支付违约金（全保障=全薪，部分保障=50%，无保障=0）。
  • 买断：与球员协商降价解约。球员可能接受 60–80% 的剩余薪资一次性买断，释放部分空间。球员性格影响买断谈判难度。
  • 延期支付：买断费用可分 3 季摊销，缓解当季薪资压力（但总成本不变）。
  • 被裁球员：进入自由市场，其他球队可低价签（底薪），原队继续支付买断费用。

4.6 转会费机制

世界内转会费：自由市场签约无需转会费（球员已自由）；跨经理交易无现金补偿（纯球员/选秀权互换）。但在签约 AI 球队的球员时，需向 AI 球队支付解约金（Release Fee），金额=球员剩余合同总额的 50%。这让"从 AI 队挖人"有成本，防止玩家无成本扫荡 AI 队天赋。

5工资帽与奢侈税

5.1 工资帽类型

HWO 采用软帽+奢侈税模式：球队可以超过工资帽，但超帽部分受累进奢侈税惩罚。

线金额（每季）说明
工资帽 Salary Cap4,000球队总薪资的"建议上限"。超过此线触发奢侈税。新秀红利+老将底薪不计算在内。
奢侈税线 Luxury Tax Line5,000工资帽 + 25%。超过此线税率翻倍。
硬帽 Hard Cap6,500绝对上限。任何情况下球队总薪资不可超过此线（含买断摊销）。

5.2 工资帽可视化

安全区 (0–4,000)
奢侈税区 (4,000–5,000)
重税区 (5,000–6,500)

球队总薪资落点决定税率。安全区无税，奢侈税区累进，重税区税率翻倍，硬帽不可逾越。

5.3 奢侈税计算

── 累进奢侈税 ── OverCap = TotalSalary - SalaryCap // 超帽金额 LuxuryTax = tieredTax(OverCap): // 第一档：0 – 1,000（工资帽到奢侈税线） 0–1,000 → ×1.5 // 每超 1 元交 1.5 元税 // 第二档：1,000 – 2,500（奢侈税线到硬帽） 1,000–2,500 → ×3.0 // 税率翻倍 // 第三档：2,500+（接近硬帽） 2,500+ → ×4.0 // 惩罚性税率 // 例：总薪资 5,500 → OverCap = 1,500 // 第一档 1,000 × 1.5 = 1,500 // 第二档 500 × 3.0 = 1,500 // 总奢侈税 = 3,000（等于多付了一支顶薪的钱）

5.4 重复奢侈税（Repeat Tax）

连续 2 季以上超帽的球队，税率逐年递增：

连续超帽赛季数税率修正说明
第 1 季×1.0标准税率
第 2 季×1.3+30%
第 3 季×1.6+60%
第 4 季+×2.0税率翻倍——持续烧钱将受到惩罚
设计意图：重复奢侈税防止"土豪球队"长期靠烧钱垄断。争冠窗口期内超帽是合理的，但连续 3–4 季超帽会让税务成本失控，迫使球队在巅峰期后重建。这让"王朝"更难维持，增加联赛竞争平衡。

5.5 工资帽特例

特例效果条件
伯德特例可超帽续约本队效力 3+ 年的球员仅限原队续约自己养出来的球员
中产特例每季可用 1 个中产合同签约，不计入帽已超帽球队仍可签 1 个中产
底薪特例底薪签约不计入工资帽无限制
老将底薪特例31+ 老将底薪不计入工资帽仅限老将底薪合同
伤病特例球员赛季报销时可获得额外中产空间需医疗确认，仅替该球员

5.6 财务公平竞赛（FFP）规则

  • 连续亏损限制：连续 2 季亏损超过 1,000 的球队，禁止签约自由市场（只能签底薪和青训提拔）。
  • 强制清算：球队薪资空间归零且无法支付薪资时，系统强制裁掉最高薪球员（无保障优先），直至可运营。
  • 联赛最低运营金：赛季开始时薪资空间 < 1,000 的球队，系统发放应急贷款（下季偿还，利息 10%）。

  • 联盟统一谈判：转播收入由联盟统一谈判，按联赛层级分配给各队。
  • 层级系数：顶级 ×3.0 / 次级 ×2.0 / 第三级 ×1.5 / 入门级 ×1.0。
  • 季后赛加成：进入季后赛的球队额外获得转播加成（+50%），冠军 +100%。
  • 固定收入：转播分成在赛季初一次性发放，是球队财务的"底薪"——无论战绩如何都有一笔保底收入。

9防通胀与经济平衡

9.1 通胀风险

多人在线经济最大威胁：如果薪资空间可以无限累积，老玩家将比新玩家拥有压倒性财力优势，新玩家永远无法追赶，游戏死亡螺旋开始。防通胀是经济系统的生命线。

9.2 五大防通胀机制

机制原理效果
① 赛季结余折旧 每赛季末结余按 40% 折旧带入下季 存钱不如花钱；鼓励消费而非囤积；老玩家无法靠"攒"获得优势
② 球员自然流出 老将退役、合同到期离队、伤病退役 每季约 15–25% 球员从联盟流出；对应薪资空间被释放但不会累积
③ 奢侈税消耗 超帽球队缴纳的奢侈税"蒸发"（不回流联盟） 财富从富裕球队被消耗掉，防止强者愈强
④ 新秀注入固定量 每季选秀池新秀数量固定（按世界规模），不随玩家数量增加 天赋供给受限；竞价推高新秀价值；防止天赋过剩
⑤ 薪资服务端锚定 球员薪资由服务端按公式锚定，不可人为操纵 防止默契压价/阴阳合同/多开套利

9.3 经济平衡监测指标

指标健康区间干预措施
联盟平均薪资占用率75–90%>95%：提高奢侈税；<60%：降低基础配额
顶薪球员占比5–10%>15%：提高顶薪合同溢价；<3%：降低
自由市场流拍率15–30%>40%：降低球员薪资锚定基线；<10%：提高
新经理首季存活率>80%<70%：增加入门级基础配额或应急贷款
升降级收入差比1.5–3.0×>4×：缩小层级收入差；<1.5×：扩大

9.4 赛季重置流程

  1. 季后赛结束：发放赛事奖金。
  2. 合同结算：到期合同释放薪资空间；保障合同继续占用。
  3. 奢侈税结算：按超帽金额一次性扣除。
  4. 结余折旧：剩余薪资空间 × 0.6 带入下季。
  5. 基础配额发放：按下季联赛层级发放。
  6. 运营模块续费：教练/球探/学院/球馆等维护费自动扣除。
  7. 选秀 + 自由市场：新秀注入 + 自由球员签约。
  8. 赛季开始：新季薪资空间锁定，开始日循环。

10AI 经理经济行为

AI 经理是经济系统的"蓄水池"与"流动性提供者"。冷启动期世界内多数球队由 AI 控制，AI 必须表现出拟真的经济行为。

10.1 AI 经济决策模型

AI Decision = weighted( TeamNeed, // 位置缺口、能力短板 PlayerValue, // 球员能力 × Peak × 年龄 × 合同性价比 Fog, // AI 也有 fog，不会完美估值 CapSpace, // 当前薪资空间 RebuildPhase, // 重建/冲击/维持，影响花钱意愿 Personality // AI 性格：保守/激进/精明/摆烂 )

10.2 AI 经理类型

类型行为特征占比经济影响
争冠型愿意超帽；积极签自由球员；交易送选秀权换即战力20%消耗薪资空间；推高自由市场价格
精明型严格控制在帽下；只签性价比合同；培养新秀30%稳定中游；提供交易对手
重建型清理高薪老将；囤选秀权；最低运营投入20%释放球星到市场；提供交易买方
摆烂型最低薪资投入；不签自由球员；纯靠青训10%联赛底部；新经理可超越
激进型频繁交易；大胆签约；容易陷入薪资陷阱10%市场活跃度来源；偶有烂合同可捡
保守型极少交易；续约本队球员；稳定运营10%市场流动性低；阵容稳定

10.3 AI 交易评估

  • AI 按 TeamNeed + PlayerValue + Fog 评估交易提案，有"心理价位"。
  • AI 不会接受明显吃亏的交易，但 fog 未收窄时可能误判球员价值。
  • AI 会主动发起交易提案（当检测到位置缺口或冗余球员时）。
  • AI 经理的 fog 独立于玩家——双方都可能用 fog 未收窄的球员"骗"对方。

10.4 AI 经理随真实玩家替代

随着世界内真实玩家增加，AI 球队逐步被真人接管。新玩家可选择接管 AI 球队（继承其阵容/合同/财务状况），或从入门级新队起步。这保证了经济系统的"人密度"逐步提升。

11.3 经济场景示例

场景 A：争冠窗口期的奢侈税博弈

情境：你的球队连续 2 季进入季后赛，核心阵容（1 顶薪 + 2 中产）实力强劲。但续约核心后总薪资达到 5,200，超过奢侈税线。
决策：接受奢侈税争冠（本季税费约 1,500），还是交易走一个中产降回帽下？
博弈：争冠窗口可能只有 2–3 季；奢侈税+重复税 3 季后可能达到 ×1.6 税率；但交易走中产可能削弱战力错失冠军。
关键：这是"花钱买冠军窗口"的经典博弈——接受短期亏损换取冠军奖金 2,000 + Fame 加成 + 球迷热情暴增带来的长期收入。

场景 B：重建期的青训投资

情境：你的入门级球队战绩垫底，核心球员老化，薪资空间 3,500。
决策：交易走老将释放空间，将 700/季投入青训学院升级至 Lv4，靠选秀+青训重建。
博弈：3 季内战绩可能更差（球迷热情下降→收入减少），但 Lv4 学院 3 季后开始产出 Peak 可观的新秀红利球员（薪资 ×0.4）。
关键：短痛换长赢——重建期需要忍受 2–3 季的低收入和球迷热情低迷，但青训红利一旦兑现，性价比远超市场签约。

场景 C：合同陷阱脱困

情境：3 季前签下的顶薪球员（1,200/季，全保障，还有 2 年）因伤病衰退，能力从 88 降到 72，成为薪资陷阱。
选项：① 买断（付 80% = 1,920，分 3 季摊销 640/季）；② 交易（但对方不愿接手全保障衰退合同，需搭选秀权）；③ 留在队中当高薪替补。
博弈：买断释放空间但成本高；交易搭选秀权损失未来；留用占 1,200 空间但零成本。
关键：这就是"每笔长约都需明确职责"的教训——顶薪全保障合同是重承诺，签之前必须评估球员衰退风险。
