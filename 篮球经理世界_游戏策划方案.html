1游戏概述与定位

1.1 基本信息

中文名篮球经理世界
英文名Hoops World Online（缩写 HWO）
品类多人在线异步每日制篮球经理模拟（Web MMOM）
平台浏览器 + 移动端 PWA（移动优先设计）
商业模式F2P，Credits（账号资源）+ VIP（订阅），公平非 P2W
目标用户25–45 岁篮球爱好者、FM/FIFA 经理品类玩家、中文体育游戏用户
单日时长10–20 分钟（低单日粘性 · 高长留）
核心幻想接手末流球队 → 逐级攀升 → 围绕核心建一代王朝 → 退役传承

1.2 体验目标

  • 每日回流钩子：固定时钟结算 + 实时观战 + 赛事快报，制造"今天要看结果"的日常仪式感。
  • 长线王朝感：球员完整生涯可养成（童子→老将），核心退役后时代传承，跨赛季积累名人堂。
  • 多人对抗的紧张感：每场对手都是真实玩家或拟真 AI，升降级与选秀博弈带来真实赌注。
  • 公平信任：永不卖比赛结果与球员强度，sim 服务端权威执行。

2核心玩法循环

2.1 玩家动词

侦察 · 选秀 · 签约 · 交易 · 训练 · 排阵 · 战术 · 复盘 · 经营青训 · 传承

2.2 日循环

日循环：登录 → 看 Alerts/赛事快报 → 训练/球探/市场/战术操作 → 提交次日安排 → 10:00 结算看比赛（可实时观战 PBP） → 复盘 box score / PBP → 16:00 翻天（资源/状态/球探报告更新）→ 次日

2.3 四层时间结构

层级周期关键事件
日循环每天训练/球探/市场 → 提交 → 10:00 比赛 → 复盘 → 16:00 翻天
周循环每周（≈7 场）关键战、市场窗口、球探报告更新、青训苗子赛事
季循环每季（≈30 场常规赛 + 季后赛）常规赛 → 季后赛 → 升降级 → 选秀 → 自由市场 → 青训提拔
年代循环多季核心养成 → 巅峰 → 退役 → 时代传承 → 名人堂

2.4 赛季节奏

  • 常规赛：约 30 场，约 30 天（1 场/日）。
  • 季后赛：top 8 单淘汰，约 1 周。
  • 休赛期：升降级 → 选秀 → 自由市场 → 青训提拔 → 季前，约 5–7 天。
  • 赛季总长：约 6 周/季。一年约 8 季。

3玩家角色与目标系统

3.1 玩家身份

玩家以"主教练兼总经理"身份接手一支球队，拥有阵容管理权、战术权、训练权、转会/合同决策权、青训学院经营权、财务权。

3.2 目标分层

层级目标达成感来源
即时赢下今晚的比赛实时观战 + PBP 复盘
短期冲季后赛 / 升级 / 保级排名变化、升降级赌注
中期签下心仪球员 / 选秀抢人阵容成型、市场博弈胜出
长期建立王朝 / 夺冠 / 登顶奖杯、名人堂、世界排名
超长期核心退役传承 / 跨代王朝时代标签、传承遗产、青训血脉

3.3 成就与沉淀

  • 经理履历：跨赛季记录（战绩、冠军、升降级、传奇交易）。
  • 名人堂：退役核心进名人堂，跨存档可见。
  • 世界排名：跨联赛的经理声望积分（联赛层级 + 战绩 + 王朝成就）。

4多人在线世界与联赛结构

这是本作作为"多人在线游戏"的核心骨架，决定玩家如何被组织、如何对抗、如何流动。

4.1 世界（World）模型

世界 = 一个独立生态系统。玩家注册时选择或被分配到一个世界。每个世界自含完整联赛金字塔、共享球员池（自由球员 + 选秀池 + 青训苗子池）、独立经济与排名。世界之间球员不流通（保证公平与经济体量可控）。
  • 世界容量：每世界约 256–512 支球队（16 队/组 × 多组多级），随玩家增长开新世界。
  • 世界选择：按语言/时区/活跃度推荐；可付费迁移世界（受冷却限制，避免经济套利）。
  • AI 经理填充：未被人接管的球队由 AI 经理经营，阵容/战术/交易拟真，随真实玩家增加逐步替换。

4.2 联赛金字塔（每世界）

层级规模定位升降级
顶级联赛1 组 16 队世界之巅，争夺冠军戒指末 3 名降级
次级联赛2 组各 16 队冲击顶级各组前 2 升级 / 末 3 降级
第三级4 组各 16 队中坚层同规则
入门级（新经理起点）多组 16 队新经理从这里起步前 2 升级

新注册经理默认分配到入门级某组 AI 球队；可付费（Credits）选择中游球队，但不可选顶级球队（保护生态）。

4.3 全球时钟与异步结算

  • 比赛结算：每日 10:00（UTC+8）所有世界同时 sim 当日全部对阵。
  • 翻天：每日 16:00（UTC+8）资源/状态/球探报告翻页。
  • 提交截止：每日 09:30（UTC+8）截止次日安排，过后该日不可改。
  • 所有世界同步：保证选秀/自由市场/升降级在同一全球节点进行。

4.4 赛程与对阵

  • 组内双循环或单循环 + 跨组交叉，保证每队约 30 场常规赛。
  • 季后赛：组内 top 8 单淘汰（BO1 / 决赛 BO3）。
  • 关键战（同城德比、升降级生死战、冠军战）高亮，进入"赛事快报"。

4.5 升降级与赛季交接

  1. 常规赛结束 → 季后赛决出冠军。
  2. 按规则执行升降级（顶级末 3 降次级，次级前 2 升顶级，依此类推）。
  3. 休赛期：选秀 → 自由市场 → 青训提拔 → 季前热身。
  4. 新赛季重排赛程，开始下一季。

5球员系统（能力 · 迷雾 · Peak）

5.1 能力模型（精简至约 20 项，5 组）

组能力项说明
身体（6）Wingspan · Standing Reach · Speed · Vertical · Strength · AgilityEndurance 合并为隐含耐力属性；身体天赋先达峰先衰退。
投射（4）Mid-Range · Three-Point · Inside · Free ThrowRim Attack 作为"终结"并入 Inside 子维度。
防守与篮板（5）Steal · Perimeter D · Interior D · Off Rebound · Def ReboundLateral Speed 并入 Perimeter D 子维度。
控传（3）Dribbling · Passing · Post MoveCatching 弱化为隐含属性。
心智（4）Offensive IQ · Defensive IQ · Aggression · LeadershipDraw Foul 并入 Aggression 子维度。

能力"相互作用而非独立裁决"：好的终结者还需控运/体格/决策配合。

5.2 球员其他维度

Peak（天赋上限）
天生不可改的估值，带误差；动态因素决定能多接近它。
Condition（状态）
疲劳驱动；重分钟与长期不打都拉低。
Fame（声望）
联盟内外知名度，影响商业收入与续约难度。
Stats（数据）
近期与生涯数据；球探与球迷叙事素材。
Contract（合同）
类型/薪资/年限；影响薪资空间。
Traits（特质）
特殊能力标签（如"冷血杀手""玻璃人"），部分隐藏于迷雾。

5.3 The Fog（信息迷雾）

核心机制：不熟悉的球员，能力/Peak/特质均带 margin of error。球探报告"收窄"区间，不是"保证"真值；探针槽位与预算有限 → 信息不对称是玩法主源。
  • 可见估值（带误差区间）/ 真实值（隐藏，仅服务端）/ Peak 估值（带误差）。
  • 收窄来源：球探报告、探针、Watchlist 长期观察、对阵亲历。
  • 球探等级决定：偏差幅度、区间宽度、可见特质数量。

5.4 球员生成与位置

  • 位置是"注册"不是"评分"，不锁死风格；能否胜任某角色仍看能力+情境+体系。
  • 球员由服务端生成（虚构姓名库，致敬亚洲姓名风格，无真实球员版权风险）。

6成长阶段系统（生涯弧线 Career Arc）

球员从童子到老将的完整生涯成长线。固定天赋（Peak）是天生上限不可改；训练响应率、特质觉醒、伤病抗性、比赛经验、心理素质等动态成长因素受阶段赛事表现与玩家决策持续影响。

核心命题：Peak = 天花板（固定）；动态因素决定一个球员能多接近天花板、多快达到、能维持多久。成长线让"养成"成为可玩内容，而非纯 sim 背景。

6.1 五阶段

阶段年龄玩家干预入口影响的动态成长因素
童子8–12球探淘苗；青训预备名单；基础训练侧重训练响应率基数
少年13–15跳级决策；青训营定位；训练方向技术定型方向、伤病抗性雏形、特质倾向
青年16–18试训选择；提前参选；对位磨炼特质觉醒概率、选秀顺位、新秀红利、clutch 初值
成人19–30+战术/训练/合同/轮换（主线）技术熟练度、比赛经验、心理素质、巅峰长度
老将31+角色转换；退役时机；是否进教练轨经验传授（teaching）、传承遗产强度

6.2 动态成长因素

训练响应率 Trainability
每单位训练带来的成长量；童子/少年期基础决定一生上限。
特质觉醒 Trait Awakening
特殊能力觉醒概率与时机；青年期赛事强度催化。
伤病抗性 Durability
生涯伤病史基底；少年期过度训练埋下隐患。
比赛经验 Clutch IQ
关键球处理；青年/成人关键战累积。
心理素质 Mental Fortitude
状态稳定性、逆境响应；贯穿全生涯。
技术熟练度 Skill Mastery
技术动作稳定度；成人期重复使用强化。

6.3 设计要点

  • 早期决策的长尾效应：童子/少年选择 10+ 年后才完全显现——"当初那个决定害了他"的叙事钩子。
  • 双建队流派：自家青训学院 vs 球探+选秀外部路线。
  • 成人阶段=主线：玩家接手时球员多在青年/成人期。
  • 传承闭环：老将 teaching 强度反哺下一代青训苗子。

7业余梯队赛制金字塔（Grassroots Pyramid）

小学、初中、高中、大学四个学龄阶段，每阶段均设五层赛事金字塔：城市 → 省 → 国家 → 洲际 → 国际。与职业主线并行、由 sim 自动驱动；玩家以球探观察者与自家青训决策者双重身份介入，不直接执教青年队。

核心命题：金字塔高度 = 成长催化强度（clutch/心理/特质觉醒）+ 球探可见度 + 选秀行情；同时 = 伤病累积风险。让玩家在"拔苗助长"与"厚积薄发"间权衡。

7.1 赛制矩阵

层级小学 (8-12)初中 (13-15)高中 (16-18)大学 (19-22)
城市校际联赛/区赛市初中联赛市高中联赛校际邀请赛
省省少锦赛省运会 U15省高中联赛（CHBL 风格）省大学生联赛
国家全国少锦赛全国 U15 锦标赛全国高中联赛 / U17 国青选拔全国大学生联赛（CUBA 风格）
洲际—（不开放）东亚 U15 邀请赛亚青赛 U17 / U18亚洲大学生锦标赛
国际—（不开放）—（不开放）U17/U19 世青赛世界大学生运动会

7.2 玩家三种介入

① 球探现场
派球探去某层级赛事观察苗子，消耗预算收窄 fog；高层级报告更值钱但门票更贵。
② 青训苗子参赛
决定自家苗子是否报名更高层级赛事——收益催化成长，风险伤病疲劳。
③ 青训学院投入
投资青训设施/教练，提升苗子表现上限与晋升概率，长线建队流派核心。

7.3 设计要点

  • "伤仲永"机制：过早高强度参赛 → 短期 clutch 飙升但埋下伤病隐患、巅峰缩短。
  • 选秀行情业余溯源：选秀夜球探报告回溯完整金字塔履历。
  • 不喧宾夺主：sim 驱动 + 点状干预，界面以"赛事快报 + 球探报告"呈现。
  • 冷启动简化：首版只开放高中+大学两层，小学/初中后续补全。

8战术系统

战术是方向，不是遥控器——球员依据自身能力、情境、防守自行决策。

8.1 基础设置（新手友好）

进攻倾向（外线/平衡/内线）+ 防守倾向（压迫/平衡/收缩）+ 节奏（快/平衡/慢）三选即可用。

8.2 高级编辑器

  • 保存多套战术存档。
  • 设定首发与轮换逻辑（位置优先级、疲劳阈值、换人触发条件）。
  • 给球员分配战术槽位与角色（主攻点/3D/蓝领/第六人等）。
  • 条件规则：仅特定阵容/情境触发。
  • 换人逻辑：按比分/时间/犯规/疲劳自动调整。

8.3 本作新增战术纵深

半场调整 新增
中场依 box score 调整下半场倾向（限 2 处）。
Clutch 战术卡 新增
第四节最后 3 分钟/加时，指定关键回合战术（最后一攻、防守重点）。
对位针对性 新增
针对对手核心的防守策略（包夹/护筐/换防/放投）作为可指定战术槽。

8.4 Per-game 战术

可对任意赛程指定一次性战术，对手看不到你的私有设置。适用于关键战、季后赛、针对性备战。

8.5 轮换与疲劳

  • 轮换基于位置适配、耐力、对位、体系需求、板凳深度，而非纯评分。
  • 重用主力不自动正确——疲劳堆积、位置无替补、零件不契合都会拖垮全队。
  • 系统按设置与比赛进程执行换人；位置优先级决定顶替人选。

9比赛模拟引擎

设计铁律：sim-engine 为纯函数，输入相同则输出相同——可单测、可回放、可灰度调参、可防作弊。所有比赛在服务端权威执行，前端只读结果与 PBP。

9.1 回合结构

一场比赛 = 若干回合（约 100–110 回合/场）。每回合由决策树生成出手选择与结果。

单回合决策链：球权归属 → 控球者读取战术倾向+自身能力+情境 → 选择持球/传球 → 终结者读取对位+防守 → 决定出手类型与位置 → 投篮/罚球/失误判定 → 篮板争夺 → 球权转换。

9.2 出手决策权重

每回合出手类型由球员能力 × 战术倾向 × 对位 × 情境（比分/时间/疲劳）× 随机加权决定：

  • 战术倾向：外线/内线/平衡 影响三分 vs 内线的基线权重。
  • 球员能力：Three-Point 高的球员在"外线倾向"下更可能投三分；Inside 高的在"内线倾向"下更可能攻筐。
  • 对位：对手 Perimeter D 高 → 三分出手权重下降；Interior D 高 → 内线权重下降。
  • 情境：落后追分倾向外线、领先控节奏倾向内线低风险；Clutch 阶段按 Clutch 战术卡覆盖。
  • 随机：保证涌现性，拒绝"最优解套路"。

9.3 关键回合与叙事

  • 关键回合（lead change / clutch 最后 5 分钟 / 关键犯规 / 绝杀）高亮，生成"赛事快报"叙事摘要。
  • Clutch 战术卡在最后 3 分钟/加时覆盖默认战术，影响最后一攻方案与防守重点。
  • 半场调整：中场可依 box score 调整下半场倾向（限 2 处）。

9.4 输出产物

PBP 流
逐回合文字直播，含时间/比分/动作/球员。
Box Score
双方逐人数据（得分/篮板/助攻/抢断/盖帽/失误/犯规/正负值/命中率）。
赛事快报
3–5 句叙事摘要，进报纸流。
高光回放
关键回合可单独回看。

9.5 实时观战

sim 在 10:00 运行时通过 WebSocket/SSE 逐回合推送 PBP，玩家可"看直播"；错过可看回放与快报。这是把"等结果"变"看直播"的核心体验钩子。

10球探系统

10.1 三层信息获取

手段作用成本
Scout Report（球探报告）收窄候选名单的 fog 区间，不是保证真值球探预算
Probe（探针）对特定球员深度探查，提高精度探针槽位（稀缺）+ 预算
Watchlist（关注名单）长期跟踪，随时间自动收窄 fog关注槽位（有限）

10.2 收窄来源

  • 球探报告、探针、Watchlist 长期观察、对阵亲历（交过手自动收窄）。
  • 业余金字塔赛事：派球探去某层级赛事现场观察苗子，消耗预算收窄 fog。

10.3 球探等级

球探部门有等级，决定：估值偏差幅度、不确定区间宽度、可见特质数量。升级球探部门需投入（财务系统）。

10.4 资源约束制造博弈

设计意图：探针槽位与预算有限 → 资源分配博弈。花在"能改变决策"的地方，而非盲目探查所有人。信息即权力，但信息有成本。

11选秀系统

11.1 选秀池

  • 每季选秀池由服务端生成，含世界内所有达到参选年龄的青年球员（含金字塔赛事历练者）。
  • 新秀 Peak 估值带 fog，球探需投入才能看清。
  • 选秀顺位：按上赛季战绩倒序（垫底队优先，鼓励重建公平）。

11.2 选秀博弈四步

① 试训 Workout
对心仪新秀办试训，收窄 fog、提升好感度。
② 接近新秀
通过互动提升新秀对你的好感，影响被选中后的契合度。
③ 传闻中心 Rumor Mill
运作传闻，影响其他经理的判断与顺位预期。
④ 选秀夜
按顺位选人；经理间博弈抢人，传闻与迷雾决定最终归属。

11.3 选秀行情业余溯源

选秀夜球探报告回溯球员完整金字塔履历（"高中全国四强、U17 世青赛 MVP"），让生涯有连续叙事，也为经理判断提供线索。

11.4 多人博弈

同一选秀池被同世界所有经理共享，顺位交错。传闻中心可误导对手，自家情报不外泄——多人在线的选秀是一场心理战。

12转会、交易与合同

12.1 自由市场（Free Agency）

  • 报价即承诺：带价格的承诺，不是无限试探；下单前三查——位置缺口 / 薪资空间 / 情报（fog 未收窄别乱签）。
  • 自由市场为世界内共享，所有经理竞争同一批球员。
  • 球员有"心仪目的地"倾向（基于球市规模/战绩/家乡），影响接受概率。

12.2 跨经理交易（Trade）

项规则
范围同世界内任意两经理可发起交易
机制报价 → 对方接受/还价/拒绝；限时响应
平衡校验薪资需大致对等（工资帽规则），防套利
AI 经理AI 按"球队需求+球员价值+fog"评估，拟真博弈
否决明显失衡交易（如新秀换空气）系统可标记人工复核

12.3 合同类型

新秀红利
低薪高性价比，前 4 年红利期。
底薪
老将/边缘轮换，填充名单。
中产
主力轮换价位的标准合同。
顶薪
核心球员，占用大量空间，需"明确职责"。
老将底薪
31+ 老将特例，带 teaching 加成。

12.4 工资帽

  • 硬帽或软帽（待定），超帽受奢侈税惩罚。
  • 长约带"明确职责"才能签——健康的财务不是少花，而是每笔长约都有清晰定位。

13训练系统

13.1 训练是延迟投资

训练不会立即显现，需时间累积；过劳伤状态与 condition。训练响应率（Trainability）决定每单位训练的成长量，受童子/少年期基础影响。

13.2 生涯曲线

属性类达峰衰退
身体天赋（Speed/Vertical/Agility）早（约 23–26）早（约 30+）
技术（投射/控传/防守技巧）中（约 26–30）缓（约 33+）
经验（IQ/Clutch）晚（约 28–33）极缓（几乎不衰）

13.3 训练方向

  • 玩家可为球员指定训练侧重（如"强化三分""提升护筐"）。
  • 训练响应率随年龄与生涯阶段衰减；定型后可塑性下降。
  • 青训苗子训练方向影响技术定型（少年期的选择长尾影响）。

14财务与球馆

14.1 收入来源

  • 球票：受球馆容量与战绩/球市影响。
  • 转播/商业赞助：受联赛层级与球队 Fame 影响。
  • 球衣/周边：受核心球员 Fame 与球迷文化影响。

14.2 支出

  • 球员薪资（最大头）、教练组、球探部门、青训学院、球馆维护/升级、奢侈税（超帽）。

14.3 球馆投资

升级球馆扩容 → 球票收入↑；但前期投入大，需权衡现金流。球馆档次也影响自由球员"心仪目的地"倾向。

14.4 财务健康原则

核心：最健康的财务不是"少花"，而是"每一笔长约都有明确职责"。长线建队需平衡短期战力与未来空间。

15王朝与传承

15.1 时代标签（Era Tag）

核心球员退役后留下可继承的时代遗产：

战术偏好遗产
该核心时代的战术体系成为球队"传统"，新一代球员适配时有加成。
青训血脉
核心留下的青训理念提升后续苗子培养上限。
球迷文化 buff
核心时代积累的球迷基础提升球票与商业收入。

15.2 传承闭环

老将的 teaching 强度（经验传授）反哺下一代青训苗子 → 形成"一代核心 → 传承 → 下一代"的王朝循环。老将是否进教练轨影响 teaching 强度。

15.3 名人堂

  • 退役核心进名人堂，跨存档可见，沉淀经理成就。
  • 名人堂球员的"时代标签"可在新存档中作为可选传承起点（轻度 meta 进度）。

16社交与对抗层

多人在线的核心张力来自人与人。本节设计让对抗与社交自然涌现，而非强塞社交功能。

16.1 经理档案与履历

  • 每经理有公开档案：昵称、头像、执教履历（赛季战绩/冠军/升降级/传奇交易）。
  • 履历是"江湖地位"的体现，影响交易谈判中 AI 与玩家对你的判断。

16.2 对抗关系（Rivalry）

  • 自然生成：反复对阵且比分接近的两队，系统标记为"宿敌"，进入双方赛事快报高亮。
  • 德比：同城/同区球队自动德比标记。
  • 升降级生死战：决定升降级的关键对阵特殊高亮。

16.3 交易谈判

  • 同世界经理间报价/还价/拒绝，限时响应。
  • 谈判历史可追溯，"这笔交易谁亏了"成为社区谈资。

16.4 联盟内交流（v2）

  • 组内简易聊天/垃圾话频道（可选，可关闭）。
  • 赛季结束"颁奖"：社区票选最佳交易、最坑合同、最佳绝杀等。

16.5 世界排名与跨联赛声望

  • 跨联赛的经理声望积分 = 联赛层级 × 战绩 × 王朝成就。
  • 世界排名榜激励玩家冲击顶级联赛与多代王朝。

17经济系统

多人在线游戏的经济平衡是长线生命线。本节定义资源、流动与防通胀机制。

17.1 资源类型

资源获取用途是否影响强度
薪资空间（游戏内货币）球票/转播/赞助签球员/教练/球探/青训/球馆是（核心博弈资源）
球探预算球探部门等级球探报告/探针/金字塔现场间接（信息）
探针槽位固定 + VIP 加成深度探查特定球员间接（信息）
Credits（付费货币）充值外观/便捷/迁移世界否（红线）

17.2 球员价值锚定

  • 球员薪资由真实能力 + Peak 估值 + 年龄 + Fame + 合同类型锚定，服务端定价，防止玩家间操纵。
  • 自由市场报价由系统评估"市场价"，玩家在此基础上竞争。

17.3 防通胀与赛季重置

  • 赛季结算消耗：每季末部分薪资/资源随赛季清零或折旧，避免无限累积。
  • 球员自然流出：老将退役、自由球员离队、伤病退役构成天然回收。
  • 新秀注入：每季选秀池补充新鲜血液，维持生态活力。

17.4 AI 经理的经济角色

AI 经理是经济"蓄水池"：可被交易、可签自由球员、可被挖角，保证冷启动期玩家也有交易对手与市场流动性。

18商业化设计

铁律：Credits / VIP 均不影响比赛结果与球员强度。这是信任底线，与 Rim Attack 一致。

18.1 付费点

形态内容定位

18.2 红线清单（永不售卖）

18.3 F2P 友好

  • 所有影响强度的内容均靠游戏内行为获取，零氪可夺冠。
  • Credits/VIP 只买"快"与"美"，不买"强"。

19技术架构

19.1 总体架构

  • 前端：React + Vite + TypeScript + PWA（移动优先，离线可查看阵容/战术）。
  • 后端：Node 服务 + 关系型 DB（PostgreSQL，球员/联盟/合同）+ Redis（每日 sim 队列/缓存）。
  • 结算调度：Cron 每日 10:00（UTC+8）触发全世界 sim，16:00 翻天。
  • 实时观战：sim 运行时通过 WebSocket/SSE 逐回合推送 PBP。
  • 反作弊：sim 在服务端权威执行，前端只读结果；输入相同输出相同（纯函数）。

19.2 关键模块

sim-engine
回合级 PBP 生成，纯函数，可单测/回放/灰度调参。
scouting
fog 偏差与收窄逻辑。
league-scheduler
赛程 + 升降级 + 季后赛种子。
daily-settler
每日结算编排，全世界并行。
career-arc
生涯阶段与动态成长因素演化。
grassroots
业余金字塔赛事 sim 与晋升。
ai-manager
AI 经理决策（阵容/战术/交易/选秀）。
economy
薪资/合同/工资帽/防通胀。

19.3 性能与扩展

  • sim 任务分片并行（按世界/组分配 worker）。
  • PBP 推送用 SSE 长连接，按用户订阅频道分发。
  • DB 分世界分片，避免单库热点。

21数值设计总则

21.1 能力评分

  • 单项能力 1–99 量表；Peak 为该球员某项的理论上限估值。
  • 可见估值带 ±误差区间，球探等级越高区间越窄。

21.2 fog 收窄公式（示意）

可见区间宽度 = 基础宽度 × (1 − 收窄系数)，收窄系数 = f(球探等级, 探针投入, Watchlist 天数, 对阵次数)。

21.3 sim 平衡原则

  • 每项能力对结果有边际贡献，避免单一能力碾压。
  • 涌现性优先：拒绝"最优解套路"，随机项保证多样性。
  • 用海量自动对局回归测试校准：联赛层级间胜率差、得分分布、clutch 频率需落在合理区间。

21.4 成长曲线原则

  • 身体天赋先达峰（约 23–26）先衰退（约 30+）。
  • 技术持久（达峰 26–30，缓衰 33+）。
  • 经验几乎不衰（达峰 28–33）。
  • 训练响应率随年龄衰减；"伤仲永"：过早高强度参赛埋下伤病隐患。

  • v2：小学+初中金字塔补全；联盟内聊天/颁奖；更多世界。
  • v3：跨世界冠军杯（各世界顶级联赛冠军对决）；教练轨深度；王朝博物馆。
