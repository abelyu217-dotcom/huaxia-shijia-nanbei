1设计原则

核心定位：选秀是赛季末球员获取的最高潮事件，也是重建球队的核心希望窗口。它将球探系统一整个赛季的探查投入在此刻兑现——所有 fog 迷雾、所有报告、所有预算分配，都指向这一夜的决策。
① fog 兑现时刻 核心
选秀是球探系统的终极考试。一整个赛季的探查投入在此刻转化为决策依据。探得清的经理稳准选，探不清的经理只能赌。
② 顺位即资源 经济
选秀权是可交易资产。乐透抽签引入随机性，让垫底队也有惊喜。选秀权交易让"赢在当下"与"囤选秀重建"成为两种建队流派。
③ 行情即博弈 信息
选秀行情浮动——球员参选决策、试训表现、其他经理意图都会影响行情。经理在传闻中心博弈"谁会被先选走"。
④ 不可撤销 后果
选秀选中即签约锁定（新秀合同 4 年）。选错=占用名单+薪资空间 4 年。这是有长期后果的决策。

1.1 不做什么

  • 不做完全确定性顺位：乐透抽签为垫底队引入希望，避免"摆烂=必然状元"的恶性循环。
  • 不做选秀后退货：选中即签约，不可退选、不可换。选错的代价是真实的。
  • 不做跨世界选秀：选秀池世界内封闭，每个世界独立 sim 生成与选秀。
  • 不做经理直接定价：新秀合同由服务端按顺位锚定（经济系统 §3.2），经理只能选人不能议价。

3选秀池生成

选秀池在休赛期 DAY 4 由服务端 sim 生成，世界内封闭。

3.1 生成来源

来源占比说明
青训苗子达龄参选~50%各国/地区青训体系 19 岁达龄苗子（成长线 §2 青年→成人转换）
大学球员参选~30%大学金字塔球员 19-22 岁参选（成长线 §3.4 大学特殊）
海外/国际球员~15%国际赛事金字塔球员参选（§12）
提前参选者~5%17-18 岁提前参选的青年期球员（成长线 §6.1，放弃剩余成长）

3.2 生成规则

  • 规模：每世界每赛季约 60 人入选选秀池（2 轮 × 30 顺位，对齐联赛规模）。
  • Peak 分布：遵循成长线 §5.2 的 Peak 档位分布——S 档 0.5%、A 档 5%、B 档 20%、C 档 50%、D 档 24.5%。S 档每世界每赛季 0-1 人。
  • 能力初值：按 Peak 档位与年龄生成初值（成长线 §6 成长计算引擎）。19 岁参选者能力低于 22 岁参选者，但 Peak 上限可能更高。
  • 履历生成：每个新秀附带完整业余金字塔履历（成长线 §3.5 选秀行情业余溯源），用于叙事与行情计算。
  • 确定性：选秀池生成使用世界 seed + 赛季号的确定性 PRNG，支持回放审计。

3.3 Peak 档位与选秀价值

档位Peak 区间概率选秀价值说明
S 档 世代级90-990.5%状元/榜眼级每世界每赛季 0-1 人。能力上限可支撑王朝核心。球探争夺焦点。
A 档 全明星80-895%乐透区（前14）争冠队核心或二当家。高 Peak 估值，选秀行情好。
B 档 首发级70-7920%首轮中后段合格首发。性价比最高的档位——B 档+完美发展≈A 档+一般发展。
C 档60-6950%次轮/落选轮换边缘。需培养或作为交易添头。
D 档50-5924.5%落选名单填充或淘汰。
关键洞察：B 档+完美发展 ≈ A 档+一般发展。这让选秀决策有趣——你是赌 S 档新秀的天花板（fog 最宽风险最大），还是选 B 档新秀稳妥发展？Peak 的迷雾（球探系统 §3）让这个选择充满风险。

4选秀顺位与乐透

4.1 顺位结构

选秀共 2 轮 60 顺位（对齐世界联赛 30 队规模）：

  • 首轮：1-30 顺位。前 14 为乐透区，15-30 为季后赛队倒序。
  • 次轮：31-60 顺位。全部按战绩倒序（无乐透）。
  • 顺位归属：原始归属=战绩倒序（战绩最差=最高顺位）；当前持有者可被交易（§9）。

4.2 乐透抽签（前 14 顺位）

乐透抽签为非季后赛队（14 支战绩最差队）引入随机性，避免"摆烂=必然状元"。

── 乐透抽签 ── // 14 支非季后赛队按战绩倒序分配组合数 // 战绩越差，组合数越多（但非必然状元） lotteryOdds = [ 1号签(最差): 250 组合 (25%状元), 2号签: 199 组合 (19.9%), 3号签: 156 组合 (15.6%), 4号签: 119 组合 (11.9%), 5号签: 88 组合 (8.8%), 6-14号签: 递减至 5 组合 ] // 抽签：抽 3 个组合确定状元/榜眼/探花 // 未中签队按战绩倒序填充 4-14 顺位 // 确定性 PRNG：world seed + season 号

4.3 乐透结果示例

示例：战绩最差队有 25% 状元概率，但仍有 75% 概率不是状元——最差可能滑到第 5 顺位。战绩第 5 差的队有 8.8% 概率抽中状元惊喜。这种随机性让垫底重建队保有希望，同时抑制恶意摆烂。

4.4 顺位交易对乐透的影响

  • 乐透抽签基于原始归属队的战绩，而非当前持有者。
  • 若 A 队将首轮签交易给 B 队，抽签仍按 A 队战绩确定组合数，结果归 B 队。
  • "前 N 顺位保护"条款：若该签落在保护顺位内，归原队；否则归交易方（§9.3）。

5选秀日程（DAY 1-12）

5.1 完整日程表

日事件说明
DAY 1常规赛结束战绩锁定；选秀顺位原始归属确定
DAY 2-3季后赛进行季后赛队顺位待定（按季后赛成绩倒序 15-30）
DAY 4选秀池生成服务端 sim 生成 ~60 人选秀池；公布名单与履历
DAY 5-6联合试训所有选秀池球员集体浅探（球探系统 §11.1）；每队 1 次免费，fog 各收窄 ±3
DAY 5-10单独探查窗口经理可派球探针对顺位目标深探（球探系统 §11）；试训邀请/体检/心理评估探针可用
DAY 7退选截止提前参选者可在此前退选回大学（§11）
DAY 9乐透抽签前 14 顺位抽签；公布最终首轮顺位
DAY 10选秀权交易截止选秀夜前最后交易选秀权机会
DAY 11选秀夜逐顺位选择；选中即签约锁定
DAY 11-12签约入队新秀合同自动签订；入队名单；青训提拔并行

5.2 选秀夜流程

状元签持有队
10:00 前提交选择 → 10:00 结算
锁定选择 → 下一顺位队
10:00 前提交 → ...逐顺位执行... → 60 顺位完成
  • 同步提交：为避免串行等待，所有球队在 10:00 前同步提交"按顺位的偏好列表"（含条件分支）。
  • 结算逻辑：10:00 按顺位 1→60 依次结算。每顺位取该队偏好列表中未被选走的最高位球员。
  • 超时默认：若某队未提交，系统按 draftStock 行情自动选择最高行情球员。
  • 即时签约：选中即自动签订新秀合同（§10），不可拒签。

6选秀探查窗口

选秀探查是球探系统（§11）在选秀期的应用，窗口为 DAY 5-10。

6.1 联合试训（DAY 5-6）

  • 免费集体浅探：所有选秀池球员 fog 各收窄 ±3，每队 1 次。
  • 全员覆盖：联合试训覆盖全部 ~60 人，但收窄幅度小（±3）。
  • 基础信息：联合试训后所有球员的基础身体数据（身高/体重/速度）揭晓真实值。
  • 目的：为经理提供选秀池全貌，识别需深探的目标。

6.2 单独探查窗口（DAY 5-10）

  • 球员探查：针对顺位目标球员深探，fog 收窄按球探系统 §4.2 标准。
  • 潜力探查：专攻 Peak fog（球探系统 §4.3），选秀前最关键的投入。
  • 探针可用：试训邀请（全能力 ±6）、医疗体检（Durability ±2）、心理评估（MF/ClutchIQ ±3）。
  • 预算集中：选秀探查投入可能占赛季球探预算 40%。这是球探系统的"决战时刻"。

6.3 探查策略

策略预算分配适合
集中深挖80% 预算投入 3-5 个顺位目标高顺位队（前 5）；每签必中
广撒网浅探预算分散探查 15-20 人中后段首轮；备选方案多
捡漏探查少量预算探查次轮目标 + 落选雷达次轮队；寻找被低估球员
跳过探查不投入选秀探查，靠联合试训基础无首轮签队；省钱用于转会窗

7选秀行情系统

选秀行情（draftStock）是动态浮动的预测值，反映球员被选走的大致顺位。行情受多种因素影响，是经理"传闻中心博弈"的核心。

7.1 行情初始值

── 选秀池生成时的初始行情 ── draftStock = baseStock(peakTier) // S=99, A=85, B=70, C=55, D=40 + amateurRepMod // 业余金字塔履历加成 + ageMod // 19岁标准；22岁+5（成熟度高）；17岁-10（风险） + positionDemandMod // 位置稀缺性（当届中锋少→中锋行情+） + rand(seed) * 5 // 随机扰动 // 注意：peakTier 对经理是隐藏的（fog），但行情反映了"共识估值" // 经理可通过行情反推球员大致 Peak 档位（但仍有 fog）

7.2 行情浮动因素

因素影响触发时机
联合试训表现±5~10DAY 5-6
单独试训表现±3~8DAY 5-10
退选/参选变动其他球员行情连带调整DAY 7 退选截止前
伤病/体检结果-10~30（重大伤病）探查期间
其他经理探查热度±3~5（多人探查→行情↑）探查窗口
媒体传闻±2~5随机事件

7.3 行情与预测顺位

── 预测顺位计算 ── projection = rankByDraftStock(draftPool) // 按 draftStock 降序排名即预测顺位 // 但行情 ≠ 真实价值 // 经理可能基于自己的 fog 报告选低于行情的球员（捡漏） // 也可能选高于行情的球员（基于 fog 判断行情低估）

7.4 传闻中心博弈

信息不对称博弈：行情是"共识估值"，但每队有自己的 fog 报告。经理 A 可能探得某球员 Peak 比行情高，想"捡漏"；但若经理 B 也探到了，就会抢先选。经理需推测"谁也在探我的目标"——这就是传闻中心博弈。反球探（球探系统 §12.3）可发现他队探查意图。

8选秀决策

8.1 决策输入

输入来源作用
fog 报告球探系统各球员能力/ Peak 估值区间；特质线索
选秀行情本系统 §7共识估值；预测谁会被先选走

8.2 偏好列表提交

选秀夜前，经理提交"按顺位的偏好列表"，支持条件分支：

── 偏好列表示例 ── preferenceList = [ { pickNumber: 3, // 本队持第3顺位 ranking: ["张浩然", "李明轩", "王梓睿"], // 偏好排序 fallback: "bestAvailable" // 列表内全被选走则选最高行情 }, { pickNumber: 28, // 本队另有第28顺位 ranking: ["陈思远", "刘天宇"], condition: "if 陈思远 available else tradeDown" // 条件：若目标不在则尝试向下交易 } ]

8.3 决策博弈维度

赌天花板 vs 稳即战 风险
选 S/A 档新秀赌 Peak（fog 宽风险大）；选 B 档新秀稳妥发展。前者可能是王朝基石也可能是水货，后者性价比高但天花板低。
需求 vs 最优可用 策略
按球队需求选缺的位置；还是选"最优可用球员"（BPA）。前者补短板，后者积累资产。
选人 vs 交易 资产
选中后留用；或选中后立即交易换即战力/未来签。"选即换"是重建队积累资产的手段。
捡漏 vs 抢人 信息
基于 fog 报告选低于行情的球员（捡漏）；或担心被抢而提前选（抢人）。信息优势转化为选秀优势。

9选秀权交易

选秀权是可交易资产（经济系统），可在赛季中或选秀窗口前交易。

9.1 交易类型

10.3 第 3 年末球队选项

  • 提前续约：若新秀表现出色，第 3 年末可提前续签长约（避免第 4 年后成为自由球员被抢）。
  • 放走：若新秀表现不佳，第 3 年末可放弃第 4 年选项，球员成为自由球员。
  • 全额保障：前 3 年合同全额保障；第 4 年为球队选项（非保障）。
  • 续约大涨：第 4 年后续约可能按市场价大涨（新秀红利结束）。这是建队薪资规划的关键节点。
设计意图：新秀合同是建队性价比最高的资产——4 年低价锁定一名球员。选中 S/A 档新秀=4 年低价拥有王朝核心，这是选秀权的核心价值。但选错=4 年占用名单+薪资空间的负担。这放大了选秀决策的后果。

11提前参选与退选

参选决策由成长线（§6.1 阶段转换）驱动，选秀系统处理参选/退选流程。

11.1 参选年龄规则

年龄参选类型说明
17-18 岁提前参选放弃剩余青年期成长（特质觉醒+clutch）；选秀行情可能低 3-5 位；不可回退
19 岁标准参选青年→成人转换的标准节点
20-22 岁延迟参选留在大学/海外多打 1-3 年，能力更成熟但 Peak 可能更低
22+ 岁超龄参选行情偏低（成长空间小）；多为即战型轮换

11.2 退选机制（仅提前参选者）

  • 退选窗口：DAY 7 退选截止前，提前参选者（17-18 岁）可退选回大学/青训。
  • 退选条件：未签约新秀合同（选秀夜前均可退选）。
  • 退选后果：球员回到业余体系继续成长；次年可再参选。
  • 不可退选：19+ 岁标准参选者不可退选（已转换阶段）。

11.3 参选决策博弈（球员化身视角）

当玩家以球员化身身份参选时（三身份系统），参选时机是关键博弈：

  • 提前参选（17-18 岁）：早入职业拿薪资，但放弃成长窗口，行情低。
  • 标准参选（19 岁）：平衡点，成长与薪资兼顾。
  • 延迟参选（20-22 岁）：能力更成熟，行情高，但 Peak 可能被透支。
  • 参选决策由玩家做出，非自动——这是球员化身生涯的关键节点。

12国际新秀与海外球员

12.1 国际新秀来源

  • 国际赛事金字塔（成长线 §5）：洲际/国际层级赛事的球员可参选。
  • 海外联赛：非本国青训体系的海外球员（占选秀池 ~15%）。
  • 语言/文化适配：国际新秀入队后有适配期，化学反应成长慢（×0.7 直到适配完成）。

12.2 海外球员选秀权

  • 选中后保留权：选中海外球员后，球队持有其签约权（不限期）。
  • 暂不签约：球员可继续在海外发展，球队保留未来签约权。
  • 签约时机：球员准备好入队时，球队可激活签约权。
  • 交易签约权：海外球员签约权可交易。

12.3 国际探查难度

距离惩罚：国际新秀的球探探查有更高 distancePenalty（球探系统 §3.3），fog 更难收窄。这让国际新秀选秀风险更高，但也可能捡漏（其他球队也探不清）。情报网络分支球探对国际探查有加成。

13落选秀与双向合同

选秀池 ~60 人选完后，未选中的球员成为落选秀。

13.1 落选秀处理

  • 进入自由球员池：落选秀自动进入自由球员池（freeAgentPool），可被任何球队签约。
  • 双向合同：落选秀可签双向合同（Exhibit 10 类型）——低薪、非保障、可在主队与附属队之间流动。
  • 落选雷达：球探系统可在选秀前探查可能落选的目标，为落选后快速签约做准备。

14选秀叙事与回溯

选秀不只是数值事件，更是叙事高潮。每个新秀附带完整业余履历，选秀夜生成叙事报告。

14.1 选秀叙事报告

示例叙事报告：「张浩然 · 18 岁 · PG —— 初中全国 U15 四强、高中省赛 MVP、全国高中联赛八强、U17 世青赛替补出场均 12 分 5 助攻。国际赛事经验丰富但出场时间有限，clutch 样本不足。身体天赋已接近 Peak，技术定型偏组织型，投射天花板存疑。第 3 顺位被 [球队名] 选中。」

14.2 选秀回溯

  • 10 年后回溯：球员退役时，选秀报告回溯完整生涯弧线——从 U15 四强到联赛 MVP，或从乐透新秀到水货出局。
  • 选秀重排：赛季末系统生成"选秀重排"——按当季表现重新排序，让经理回顾"如果重来会怎么选"。
  • 选秀档案：每届选秀的完整记录（顺位、选择、行情、fog 报告）永久存档，供回溯与统计。

14.3 选秀名场面

  • 捡漏名场面：低顺位选中的球员成为球星，生成"XX 顺位捡到宝"叙事。
  • 水货名场面：高顺位选中表现不佳，生成"XX 顺位水货"叙事。
  • 交易名场面：选秀夜重大交易改变格局，生成叙事。
  • 名场面进入球员/球队的时代标签（成长线 §10.2 传承），影响王朝叙事。

16异常处理与边界规则

16.1 选秀异常

异常处理
球队名单已满（15 人）选中后必须裁员腾位；若不裁则新秀进入自由球员池（失去签约权）
薪资空间不足签新秀同上，必须裁员释放空间；否则失去签约权
球队未提交偏好列表系统按行情自动选择最高行情球员
选秀权交易后该签保护触发顺位归原队；交易方获得次年补偿签（递延保护）
选秀池人数不足 60末位顺位空选（自动跳过）
选秀池人数超 60按 draftStock 截取前 60 人

16.2 球员异常

  • 新秀选秀前受伤：仍可被选中（合同按原顺位）；伤病在签约后揭示。这是探针（医疗体检）的价值。
  • 新秀拒签：新秀不可拒签（选中即签约，强制）。仅海外球员可暂不签约（保留权）。
  • 新秀选秀后立即退役：极罕见；合同作废，顺位不补偿。

16.3 跨世界隔离

  • 每个世界独立 sim 生成选秀池、独立乐透、独立选秀夜。
  • 选秀权不可跨世界交易。
  • 选秀结果不跨世界同步（各世界时区/节奏可能不同）。
