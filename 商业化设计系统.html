1设计原则与铁律

核心铁律：Credits / VIP 均不影响比赛结果与球员强度。这是信任底线。零氪玩家可以夺冠，付费玩家不能凭付费赢比赛。付费只买"快"（便捷）与"美"（外观），永不买"强"（数值）。

1.1 四设计原则

① 公平优先 铁律
竞技公平是 HWO 的生命线。任何影响比赛 sim、球员能力、薪资空间、选秀顺位的内容永不售卖。一旦突破，信任崩塌不可逆。
② 价值在体验 变现
付费价值来自体验增强——好看的球衣、便捷的操作、个性化的球馆。这些让游戏更"好玩/好看"，但不让玩家更"能赢"。
③ 零氪可玩 友好
所有影响强度的内容均靠游戏内行为获取。零氪玩家与付费玩家在"能赢"上完全平等，差异只在"好看/方便"。
④ 防套利 边界
Credits 不与游戏内经济（薪资空间/转会费）互通。世界迁移受冷却限制。防止付费成为套利工具破坏世界内经济平衡。

1.2 与策划方案 §18 的关系

策划方案 §18 已建立商业化框架：付费点表、红线清单、F2P 友好原则。本系统是 §18 的深化实现，补全 Credits 完整用途体系、VIP 三级权益、外观商城目录、便捷服务定价、防套利机制、付费转化漏斗、反 P2W 审计。数值与原则沿用 §18，本系统聚焦"怎么卖、卖什么、怎么防套利"。

4.3 VIP 权益边界

关键约束：VIP 所有权益都是"便捷"与"外观"——更多战术存档槽=方便管理，不增加战术效果；更多 Watchlist=方便跟踪，不收窄 fog；外观折扣=省钱买好看，不买强度。VIP 黑卡的"每日 Credits 返利"只能买外观/便捷，不能买强度。VIP 永不提供任何 sim/能力/fog 加成。

5.2 外观获取方式

  • Credits 购买：主要获取方式。
  • VIP 限定：金卡/黑卡有专属外观（不单独售卖）。
  • 成就解锁：部分外观通过游戏内成就解锁（如夺冠解锁冠军纪念球衣）。
  • 赛季奖励：每赛季末按成绩发放限定外观（季后赛球队专属）。

5.3 外观不影响收入

关键设计：球馆"主题皮肤"与球馆"等级"严格区分——主题皮肤只改视觉（地板颜色/灯光），不改容量/收入/FA 吸引力。玩家买了豪华主题皮肤但球馆仍是 Lv1，收入不变。外观是纯视觉个性化，与经济系统完全隔离。

6便捷服务

便捷服务让游戏更"方便"但不更"强"——多存几套战术、多跟踪几个球员、保存回放。

6.1 便捷服务定价

服务免费额度额外购买VIP 含影响强度
战术存档槽3100 Credits/槽蓝+2/金+5/黑+10否
球探 Watchlist20+球探等级×580 Credits/槽蓝+3/金+8/黑+20否
观赛回放存档5 场50 Credits/场蓝+5/金+15/黑+50否
赛后报纸去广告——所有 VIP否
批量操作——金卡+否

6.2 便捷的边界

  • 战术存档槽：只是多存几套预设战术，不增加战术效果或可选战术种类。
  • 球探 Watchlist：只是多跟踪几个球员，不收窄 fog 或增加探针。
  • 观赛回放：只是保存回放，不影响比赛结果。
  • 批量操作：只是减少点击次数，不改变操作可做的事。
原则：便捷服务让"能做的事更方便做"，但不让"不能做的事变成能做"。零氪玩家能做的一切，付费玩家也能做——只是更快/更多存档。

7.2 迁移规则

  • 带走的：球队（球员/合同）、青训苗子、 Credits 余额、VIP 状态、外观物品、经理档案。
  • 不带走的：原世界的排名/王朝记录（留档但不影响新世界）、原世界人脉关系（标记"远"）、原世界薪资空间（新世界重置）。
  • 新世界起始：按新世界联赛层级重新计算起始收入/薪资空间；经理传奇档案声望加成生效（王朝系统 §11.3）。

7.3 防套利

关键防套利：迁移不带走薪资空间——防止玩家在富世界攒钱后迁移到穷世界当富翁。Credits 与游戏内经济（薪资空间）完全隔离——Credits 不可兑换薪资空间，薪资空间不可兑换 Credits。这是付费与竞技的防火墙。

8初始球队选择

8.1 默认分配

新注册经理默认分配到 T4 入门级某组 AI 球队——从底层起步，体验完整成长。

8.2 付费选择

  • 价格：300 Credits。
  • 可选范围：T3 或 T4 的中游 AI 球队（跳过底层冷启动）。
  • 不可选：T1/T2 球队（保护生态——顶级球队不可付费获取）。
  • 不可选：已有真人经理的球队（避免抢占）。

8.3 公平性保障

公平设计：付费选择只是"跳过冷启动"——从 T3 中游起步比 T4 底层快一些，但不提供任何数值优势。T3 中游球队的球员/薪资/球馆与免费分配的 T4 球队按各自世界标准生成，付费不获得更强阵容。顶级球队（T1/T2）永不付费可选——这是"花钱不能买顶级平台"的红线。

9红线清单与反 P2W 审计

9.1 红线清单（永不售卖）

红线项说明审计方式
比赛结果不可买胜负/sim 随机sim 引擎审计（纯函数+确定性 PRNG）
球员强度不可买能力/Peak/特质能力变更日志审查
薪资空间不可直接买游戏内货币 Credits 与薪资空间隔离审计
选秀顺位不可买顺位提升选秀 PRNG 审计
球探信息不可买 fog 收窄/探针fog 变更日志审查
训练加速不可买训练响应/成长加速训练响应审计
顶级球队不可付费获取 T1/T2 球队初始球队选择审计

9.2 反 P2W 审计机制

  • 代码审计：所有 Credits/VIP 消费入口需通过"红线审查"——确认不触及红线项。
  • 日志审计：所有付费操作记录日志，可追溯是否有红线违规。
  • 玩家举报：玩家可举报疑似 P2W 行为；运营团队核查。
  • 定期审计：每季度全量审计付费与竞技的隔离性。

9.3 信任承诺

信任底线：HW0 的商业模型建立在"公平非 P2W"的信任上。一旦突破红线（如开始卖球员强度），信任崩塌不可逆——玩家会流失且不会回来。因此红线是绝对的，不可因短期营收压力突破。宁可少赚，不可卖强。

10防套利机制

10.1 Credits 与游戏内经济隔离

── 付费与竞技的防火墙 ── // Credits 不可兑换薪资空间 convertCreditsToCapSpace(credits): return "FORBIDDEN" // 薪资空间不可兑换 Credits convertCapSpaceToCredits(cap): return "FORBIDDEN" // 世界迁移不带走薪资空间 migrateWorld(accountId, targetWorld): credits = getCredits(accountId) // 带走 capSpace = resetForNewWorld(targetWorld) // 重置 // Credits 余额跟随，但不可用于新世界的薪资空间

10.2 外观不可转让

  • 外观物品绑定账号，不可交易/转让给其他玩家。
  • 防止用 Credits 买外观再转卖套利。

10.3 三身份反套利延伸

  • 经理不能给化身开高薪合同（三身份 §10）。
  • 经理不能以经纪人身份代表自己化身（三身份 §10）。
  • 付费不改变这些反套利规则——Credits 不能绕过三身份反套利。

10.4 世界迁移冷却

  • 同语言区 180 天冷却；跨语言区 365 天。
  • 防止频繁迁移套利（如在不同世界间倒卖球员——但球员不可跨世界交易，故此风险已阻断）。

11付费转化漏斗

11.1 转化漏斗

注册 → 新手引导 → 首赛季体验 → 外观诱惑 → 便捷需求 → 首充（¥6） → VIP 试用 → VIP 订阅 → 长期付费

11.2 转化节点设计

节点触发目标
外观诱惑首赛季后展示限定外观（冠军球衣/球馆主题）激发个性化需求
便捷需求战术存档槽/Watchlist 不够用时提示激发便捷需求
首充¥6 入门包（低门槛）；首充额外赠送外观破冰首充
VIP 试用首充后赠送 7 天 VIP 金卡体验体验 VIP 便捷
VIP 订阅试用结束后引导订阅转化为稳定订阅

11.3 非付费玩家的价值

关键认知：零氪玩家不是"流失用户"——他们是 HWO 生态的基础。零氪玩家填充世界、构成竞争、提供社交价值。没有足够的零氪玩家，付费玩家也留不住（没人陪玩）。因此 F2P 友好不是慈善，是商业策略——零氪可夺冠确保生态繁荣，付费玩家才有付费动力。

12.2 大氪用户的边界

关键约束：即使是大氪用户（VIP 黑卡+大量 Credits），也不能获得任何竞技优势。大氪用户的"特权"仅限外观/便捷/迁移——他们可以最漂亮、最方便、最自由迁移，但在"能赢"上与零氪完全平等。这是公平非 P2W 的底线——大氪是"最好的客户"但不是"最强的玩家"。

14.2 联动原则

联动原则：商业化系统与所有游戏系统的联动仅限"便捷"与"外观"——更多存档槽、更多 Watchlist、更好看的皮肤。任何触及"强度"的联动（fog/能力/薪资/顺位/训练）都是红线。商业化是游戏体验的"装饰层"，不是"加速层"。

  • 世界迁移：迁移完成前可退；完成后不可退。

  • 未成年人保护：未成年人充值限制（按地区法规）。
