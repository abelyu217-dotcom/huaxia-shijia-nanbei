1. 战略定位与竞品对标

1.1 一句话结论

HWO v1.1 的主干（27 项属性 + 核心球员 + 分级联赛）与 RimAttack 撞车。必须靠 Avatar 化身（玩家即球员）与 三身份职业（收缩至 5 个）拉开身位，同时把 BasketPulse 的 63 天赛季节奏与 社区治理抄过来。HWO 已有 fog 系统和交易/选秀框架——比策划建议书预估的要好，但缺国家化、职员、传承、财政数据模型和赛季日历。

1.2 三条战略判断

#判断依据行动
1撞车警告RimAttack 同样 27 项属性、同样「核心球员 = 人」、同样分级联赛靠 Avatar 自创 + 三身份职业 + 中文原生社区差异化
2最大机制空白 = 信息层RimAttack 用 fog 把数值游戏变成信息决策；HWO 已有 fog.ts 但未全链路接入把 fog 从「球探模块」提升为「全局信息层」
3最大规模风险 = 容量写死BP 美国一国 401 队/15 级；HWO 一国仅 24 队引入 L3 动态分组，按活跃玩家数自动开/并组

6. 双季后赛机制

学 RimAttack：常规赛后分 top 8 / bottom 4 两组，上游争冠、下游既保级又争更好选秀顺位。直接解决 HWO L1「只有前 8 进季后赛、后 4 无所求」的死区。

6.1 争冠组（前 8）

  • 八强 → 四强 → 决赛，BO3（三局两胜）
  • 冠军：获国际 World League 资格 + 奖金 + 声望
  • 亚军：获国际 World League 资格

6.2 保级组（后 4）

  • 半决赛 → 决赛，BO3
  • 保级组最后 2 名：直接降入 L2
  • 保级组倒数第 3：参加降级附加赛（vs L2 季后赛冠军）
  • 保级组冠军：获得更好选秀顺位（倒数第 1 → 选秀第 1 顺位，以此类推）

6.3 升降级规则

8. 球员属性体系（27 项）

8.1 属性分组（修正：状态与隐藏不与固定属性并列）

策划建议书指出：HWO v1.1 把状态 4 项与隐藏 3 项与固定属性并列是不合理的。RimAttack 的 27 项全是固定属性，状态是独立维度。修正：27 项固定属性 + 状态/隐藏作为独立维度。
类别项数属性
身体4speed / strength / jumping / stamina
进攻7close / midRange / threePoint / drive / post / passing / handle
防守4perimeterD / interiorD / steal / block
精神5iq / clutch / loyalty / leadership / workEthic
篮板2offRebound / defRebound
运动5vertical / agility / endurance / wingspan / standingReach
固定属性合计27 项（对齐 RimAttack 的 27 项，但分组不同）
独立维度项数说明
状态属性4fatigue / health / mood / form — 动态变化，不纳入 OVR
隐藏属性3injuryTendency / potential / loyaltyGene — 不直接显示

8.2 OVR 计算

OVR = Σ(属性权重 × 属性值) / Σ权重
权重按位置差异化（PG 重传球控球，C 重内线防守篮板）
OVR 0-99，每 20 分一档（0-39 红 / 40-59 橙 / 60-79 黄 / 80-99 蓝）

8.3 成长机制

  • 年龄曲线：身体 18-25 巅峰、30+ 下降；技术 23-28 巅峰；精神只增不减。
  • 训练：敬业度 + 训练师效率影响每周成长。训练按周设重点（学 RimAttack）。
  • 比赛经验：出场时间越多，球商/关键球增长越快。
  • 潜力上限：属性不能超过 potential，potential 由选秀/球探评估（带 fog）。

    members.push(random([father, mother]))
  else:
    members.push(father, mother)
  // 兄弟姐妹（40% 有 1 个，15% 有 2 个）
  siblingCount = weightedRandom([0:45%, 1:40%, 2:15%])
  // 配偶（28 岁+，60% 已婚）
  if age >= 28 and random() < 0.6:
    members.push(spouse)
